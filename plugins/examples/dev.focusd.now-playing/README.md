# 正在播放（示例）

换歌时在岛上提示正在播放的歌曲。

## 怎么用

- 安装并启用后，切换歌曲时岛上会提示歌名和歌手。
- 运行命令「显示正在播放」可以随时看一次。

## 权限

- `island:notify`：在岛上显示提示。
- `media:read`：读取正在播放的媒体信息。这是敏感权限，第一次读取时岛上会先问你是否允许。

## 示例演示了什么

敏感权限的使用前确认、订阅媒体变化事件、岛上提示。

## English

Shows the song that just started playing on the island. Reading media is a sensitive permission, so the island asks you the first time.
