# GitHub Issues（示例）

在岛上列出一个公开仓库里还没关闭的 issue。

## 怎么用

- 在插件设置里填写仓库，格式是 `owner/name`，例如 `TixXin/fly-island`。
- 岛上会多一个页面列出未关闭的 issue，点一条就在浏览器里打开。
- 运行命令「立即刷新」可以马上更新；平时按设置里的间隔刷新，只在页面打开时才去请求。

## 设置

- **仓库**：要查看的公开仓库。
- **刷新间隔（分钟）**。

## 说明

不需要 GitHub 令牌，所以只能看公开仓库，并受 GitHub 匿名访问的频率限制。

## English

Lists the open issues of a public GitHub repository on an island page; click one to open it in the browser. No token needed; set the repository in the plugin's settings.
