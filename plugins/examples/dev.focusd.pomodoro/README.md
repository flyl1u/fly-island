# 番茄钟（示例）

在岛上计时一个番茄钟，结束时提醒你休息。

## 怎么用

- 按 **Ctrl+Alt+P** 开始，或者在待办上右键选择「为这条待办开始番茄钟」。
- 计时显示在岛上的「番茄钟」页面和折叠条上。
- 一轮结束后岛上会提示，可以点「再来一轮」。完成的轮数保存在插件存储里，重启后还在。

## 设置

- **每轮时长（分钟）**：默认 25。

## 权限

- `island:notify`：在岛上显示结束提示。
- `todos:read`：读取你右键的那条待办的标题。

## 示例演示了什么

命令与全局快捷键、待办右键菜单、状态模板页面、折叠条状态文字、插件存储。

## English

Starts a pomodoro with Ctrl+Alt+P or from a todo's right-click menu. The countdown shows on its island page and the collapsed bar, and the island tells you when it ends. Finished rounds are kept in plugin storage.
