## 更新内容

**四个新插件**（默认未安装，到插件市场安装）

- **居中时钟**：收起的小岛中央显示时间、日期和星期。默认情况下，运行中的 Agent、歌词和进行中的待办优先显示。原始贡献：[@SeanWang114514](https://github.com/SeanWang114514)（#143）。
- **中转站额度**：添加 New API / Sub2API 账号，在 Agent 页查看余额额度环。原始贡献：[@yiumanlenong](https://github.com/yiumanlenong)（#141）。
- **Apple Music 歌词**：新增可选的歌词来源。原始贡献：[@YTC0408](https://github.com/YTC0408)（#98）。
- **截图标注**：框选截图、标注、贴图、文字识别和图片翻译。默认使用系统离线 OCR；约 30 MB 的增强 OCR 资源只在你点击下载后启用。原始贡献：[@Philipfanw](https://github.com/Philipfanw)（#128）。

**Agent 额度环**

- 图标和额度环稍微放大。
- 鼠标悬停在环上任意位置，立即显示额度提示；有两项额度时一起列出。
- 上下两段弧都从右向左消耗。
- Antigravity 的额度环改为上半圈显示 5 小时额度，下半圈显示周额度。

**其他**

- **细线模式**：贴边收起后的唤出区域缩小，减少误触。
- **新安装的默认设置**：首次安装时采用一套调整过的外观与行为默认值。已有用户的设置保持不变。

## What's new

**Four new plugins** (not installed by default; add them from the plugin market)

- **Centered clock**: Shows the time, date and weekday in the middle of the collapsed island. By default, running agents, lyrics and active todos take priority. Original contribution: [@SeanWang114514](https://github.com/SeanWang114514) (#143).
- **Relay quota**: Add New API / Sub2API accounts and see a balance ring on the Agent page. Original contribution: [@yiumanlenong](https://github.com/yiumanlenong) (#141).
- **Apple Music lyrics**: An optional lyrics source. Original contribution: [@YTC0408](https://github.com/YTC0408) (#98).
- **Screenshot annotation**: Region capture, annotation, pinned images, text recognition and image translation. The system's offline OCR is used by default; the enhanced OCR files (about 30 MB) are used only after you choose to download them. Original contribution: [@Philipfanw](https://github.com/Philipfanw) (#128).

**Agent quota rings**

- Slightly larger icons and rings.
- Hovering anywhere on a ring shows the quota hint right away, listing both quotas when there are two.
- Both arcs now drain from right to left.
- The Antigravity ring shows the 5-hour quota on top and the weekly quota below.

**Other**

- **Line mode**: A smaller area brings the tucked island back, so it opens less often by accident.
- **Defaults for new installs**: A fresh install starts with an updated set of appearance and behavior defaults. Existing settings are unchanged.
