## 更新内容

- **自动更新更省心**：发现新版本后在后台下载好，小岛收起且一段时间没有操作时自动安装并重新打开。等待安装期间，收起的小岛和待办图标上都有小红点。安装失败后点「重试」会重新检查、下载再安装。
- **新版本下载失败时自动换镜像**：连不上 GitHub 时，依次通过 ghfast.top、gh-proxy.com 下载同一个安装包，安装前仍校验签名。
- **音乐控制更省 CPU（issue #65）**：播放器每秒推送进度时不再每次都完整读取状态，有播放会话时也不再每次打开音频设备读取音量峰值。
- **播放器可以归档**：设置 →「音乐」的播放器顺序里，可以把不用的播放器归档。归档后它不再出现在顺序里，小岛也不再跟随它；点「恢复」放回顺序末尾。
- **记住上次的页面**：展开小岛时回到上次离开的页面。
- **点击收起的小岛去对应的地方**：点 Agent 灯打开 Agent 页，点中间的文字回到上次的页面；音乐波形和文件中转仍打开各自的页面。
- **Agent 按钮跟随胶囊样式**：页面按钮选「胶囊」时，展开小岛页头左侧的 Agent 按钮也画成同色胶囊，颜色跟随 Agent 状态。
- **页面文字颜色**：设置 →「外观」→「颜色」可以单独设置展开页的文字颜色，只改文字，图标、勾选框和进度条保持原色。修改时小岛会展开让你看到效果。
- **整体外观预设**：把当前外观的全部设置存成一个预设（最多 8 个），之后一键套用，再接着微调。
- **贴顶的玻璃小岛更贴合**：液态玻璃和磨砂玻璃贴在屏幕顶端时，顶边两侧不再有分离感。
- **展开更稳**：展开大小为 100% 时，展开页不再单独占一个图层，减少展开时文字先糊后清和抖动。
- **剪贴板全选不含收藏**：全选按钮改为「全选（不含收藏）」，批量删除不会误删收藏的内容。
- **网易云进度插件自动安装**：支持的网易云版本会在后台自动装好进度插件（最多一次管理员确认，不动网易云进程）。被安全软件拦截时，可以选择「手动放入」，按提示把文件拖进网易云目录。
- **DSH 工具审批显示为等待你确认**：DSH 等你批准工具调用时，小岛显示「等待用户」并提醒，不再一直显示运行中。余额只保留两位小数。
- **统一使用新名字 Fly Island**：拒绝审批的提示、诊断窗口和通知标题等用户看得到的地方都改用 Fly Island。待办导出默认存到「文档\Fly Island」，已有「文档\FocuSD」时继续用原来的文件夹。

## What's new

- **Smoother automatic updates**: a new version downloads in the background and installs itself, then reopens the island, while the island is collapsed and idle. While an update waits, the collapsed island and the todo button show a red dot. Retrying a failed install now checks, downloads and installs again.
- **Downloads fall back to mirrors**: when GitHub is unreachable, the same installer is downloaded through ghfast.top and then gh-proxy.com; its signature is still checked before installing.
- **Less CPU for music control (issue #65)**: players that report their position every second no longer trigger a full state read each time, and the output level is no longer read from the audio device on every read while a player session exists.
- **Archive players**: in Settings → Music, archive a player you do not use. It leaves the order and the island stops following it; Restore puts it back at the end.
- **Remembers the last page**: the island opens on the page you left.
- **Clicks on the collapsed island go where you expect**: the agent light opens Agents, the text in the middle opens the last page; the music wave and the file shelf open their own pages as before.
- **Agent button follows the capsule style**: with capsule page buttons, the Agent button at the left of the expanded header becomes a capsule too, coloured by the agent's status.
- **Page text colour**: Settings → Appearance → Colours can set the text colour of the expanded pages. Only text changes; icons, checkboxes and progress bars keep their colours. The island opens while you change it so you can see the result.
- **Whole-look presets**: save every appearance setting as a preset (up to 8), apply one later and keep adjusting from there.
- **Glass islands sit flush on the top edge**: with Liquid or Frosted glass attached to the top of the screen, the two sides of the top edge no longer look detached.
- **Steadier expansion**: at 100% expanded size the page no longer gets its own layer, so text no longer goes from blurry to sharp and the panel jitters less while opening.
- **Clipboard Select all skips favourites**: the button now reads "Select all (excl. favorites)", so a bulk delete cannot remove favourites.
- **NetEase progress plugin installs itself**: on supported NetEase Cloud Music versions the progress plugin is installed in the background (at most one administrator prompt, without touching NetEase). When security software blocks it, "Place manually" walks you through dragging the file into the NetEase folder.
- **DSH tool approvals show as waiting for you**: when DSH waits for you to approve a tool call, the island shows it as waiting and alerts you instead of showing it as running. The balance keeps two decimals.
- **The new name Fly Island everywhere you see it**: the denied-approval message, diagnostics window and notification titles now say Fly Island. Todo exports go to Documents\Fly Island by default, or keep using Documents\FocuSD if it already exists.
