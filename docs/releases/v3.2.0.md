## 更新内容

- **浅色主题与跟随系统**：设置 →「外观 → 风格」新增「配色」，可选深色、浅色和跟随系统，默认深色（就是原来的样子）。浅色是单独设计的一套，不是简单换成白底：文字、图标、边框、阴影和强调色都重新调过。小岛、设置、剪贴板和翻译窗口都会跟着变。
- **把小岛调成白色也看得清**：文字的深浅现在看小岛实际的背景色。在深色主题下把背景改成白色，文字会自动变深，不会再白字配白底。
- **液态玻璃和磨砂玻璃**：「外观 → 风格」新增「质感」，可选经典、液态玻璃和磨砂玻璃，深色、浅色各有一版。液态玻璃底色很淡，边缘有亮边和高光；磨砂玻璃是乳白或烟灰的底，带一圈柔和的亮边。玻璃只是视觉效果，不会模糊小岛后面的桌面。
- **自动更新开关**：设置 →「关于」新增「自动更新」，默认开启。开启时启动后检查一次，之后每 6 小时检查一次，失败会自动重试；下载好后，等小岛收起并且 2 分钟没人碰，会自己安装并重启。关闭后只在「关于」里手动检查。「关于」页一直能看到更新状态、「检查更新」和「立即安装」，关掉待办页的用户也能更新。
- **代理设置里有 SOCKS 时也能检查更新**：系统代理按协议分开写、里面带 `socks=` 时，以前会被当成错误的地址导致更新检查失败，现在会正确选出 HTTP 代理。
- **网易云插件安装失败时说清原因**：以前只显示「Plugin helper exited with 1」，现在会说明是被安全软件拦截、网易云装在网络盘或映射盘上、文件被占用，还是目录里刚出现了别的加载器。上次安装中断留下的临时文件也会先清理掉，不再让下次安装失败。
- **装了 MyDockFinder 等顶部栏时小岛仍在屏幕最上沿**：小岛只给 Windows 自己的顶部任务栏让位，第三方 Dock 或菜单栏不再把它挤到下面，也不会盖住它。
- **关闭设置窗口不再停顿**：点设置窗口的关闭按钮后，窗口会立刻消失，不再停一下才关掉。剪贴板独立窗口也一样。

## What's new

- **Light theme and follow system**: Settings → Appearance → Style has a new Color scheme option: Dark, Light or System, with Dark (the look you know) as the default. Light is designed on its own rather than a white background swapped in: text, icons, borders, shadows and accents are all retuned. The island, Settings, the clipboard window and the translation window all follow it.
- **A white island stays readable**: text now takes its tone from the island's actual background. Pick a white background in the dark scheme and the text turns dark instead of staying white on white.
- **Liquid glass and frosted glass**: a new Material option under Appearance → Style offers Classic, Liquid and Frosted glass, each in a dark and a light version. Liquid glass has a very faint base with a bright edge and highlights; frosted glass has a milky or smoky base with a soft bright edge. The glass is a visual style only and does not blur the desktop behind the island.
- **Automatic updates switch**: Settings → About has a new Automatic updates switch, on by default. When on, the island checks at startup and then every 6 hours, retrying after failures; once an update is downloaded it installs and restarts by itself after the island has been collapsed and untouched for 2 minutes. When off, you check by hand on the About page. About always shows the update status with Check now and Install now, so you can update even with Todos turned off.
- **Update checks work with a SOCKS entry in the proxy settings**: a per-protocol system proxy that included `socks=` used to turn into an invalid address and make update checks fail; the HTTP proxy is now picked out correctly.
- **NetEase plugin install errors explain themselves**: instead of only "Plugin helper exited with 1", you now see whether security software blocked it, NetEase is on a network or mapped drive, a file was in use, or another loader just appeared in the folder. Temporary files left by an interrupted install are cleaned up first, so they no longer make the next install fail.
- **The island stays at the very top with MyDockFinder and similar bars**: the island only makes room for Windows' own top taskbar, so third-party docks and menu bars no longer push it down or cover it.
- **Closing Settings no longer lingers**: the Settings window disappears as soon as you click close instead of pausing first. The standalone clipboard window does the same.
