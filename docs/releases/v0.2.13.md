## 更新内容

- 重新设计媒体控制面板：放大左侧封面，曲名和歌手显示在封面下方，右侧展示流动波形及上一首、播放／暂停、下一首。
- 波形随播放和音量起伏，暂停时收成细线；移除进度条、随机和循环播放按钮，以及主面板中的媒体源名称，保留媒体源优先级设置。
- 新增「多任务流动」设置，可按设定秒数轮换展示未完成任务，默认关闭。
- 新增「无操作时自动收起到屏幕边缘」设置，可自定义闲置秒数，默认关闭；使用边缘收起而非最小化。
- QQ 邮箱自动检查间隔从 60 秒缩短至 5 秒，复用连接，阅读正文不再阻塞新邮件检测。
- 合并设置页的更新入口，保留「查看最新版本」的文字和动效，支持检查、下载和安装更新。

## 安装包

- `fly-island_0.2.13_x64-setup.exe`：Windows x64 EXE 安装包。
- `fly-island_0.2.13_x64_en-US.msi`：Windows x64 MSI 安装包。
- `.sig`、`latest.json`：签名和应用内更新清单。
- `SHA256SUMS.txt`：安装包的 SHA-256 校验值。

v0.2.12 用户可在设置中检查更新；v0.2.11 及更早版本需手动安装一次以启用应用内更新。

## What's new

- Redesigned media controls with larger cover art, track details below the cover, and a flowing waveform above previous, play/pause and next controls.
- The waveform responds to playback and audio levels and settles into a line when paused. Removed seeking, shuffle, repeat and the source name from the main panel; source priority settings remain available.
- Added optional rotation through pending tasks with a configurable time per task. Disabled by default.
- Added optional idle tucking to the screen edge with a configurable delay. Disabled by default.
- Reduced QQ Mail's automatic check interval from 60 to 5 seconds, reused connections, and moved message reading off the inbox synchronization queue.
- Unified the update entry under “View latest release”, keeping its hover effect and in-app check, download and installation flow.

## Downloads

- `fly-island_0.2.13_x64-setup.exe`: Windows x64 EXE installer.
- `fly-island_0.2.13_x64_en-US.msi`: Windows x64 MSI installer.
- `.sig` and `latest.json`: signatures and in-app update manifest.
- `SHA256SUMS.txt`: installer SHA-256 checksums.

Users on v0.2.12 can update from Settings. Users on v0.2.11 or earlier must install this release manually once to enable future in-app updates.
