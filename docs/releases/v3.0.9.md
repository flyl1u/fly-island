## 更新内容

- **贴边收起更顺滑**：「细线」样式收起时，岛屿会缩成一根短线，唤出时再长回原样；「隐藏」样式会随窗口一起淡出、淡入，不再一下子出现或消失。收到消息时，收起的岛会先弹出来显示预览，预览结束后再收回去。
- **额度环统一**：Claude Code、Codex、DeepSeek Harness 和 WorkBuddy 的额度环在任何状态下都一样大，都画内外两圈。窗口过了重置时间、暂时不知道用量时，会显示一整圈淡色，不再缩成一圈细底色。WorkBuddy 改用青绿色，DeepSeek Harness 换成玫红色。
- **会话按最近活动排序**：会话列表默认按最后活动时间排序，最新的排在最前。之前选的是「状态优先」的话，会自动改成「最近活动」一次，之后仍可在会话列表的「排列会话」里换回来。
- **WorkBuddy 会话**：点一下 WorkBuddy 会话，会直接打开 WorkBuddy 里对应的对话。在 WorkBuddy 里看过的会话会记为已看，标题不再一直高亮。

## What's new

- **Smoother edge tucking**: with the Line style the island shrinks into a short bar when it tucks and grows back when you bring it out; with the Hidden style it fades out and in with the window instead of snapping. A tucked island now comes out to show a message preview and tucks back once the preview ends.
- **Consistent quota rings**: the Claude Code, Codex, DeepSeek Harness and WorkBuddy rings are the same size in every state and all draw an inner and an outer ring. When a window has passed its reset time and usage is not known yet, the ring shows as a faint full circle instead of shrinking to a thin track. WorkBuddy is teal now and DeepSeek Harness rose.
- **Sessions sorted by latest activity**: the sessions list now puts the most recently active session first by default. If you had it set to Status, it switches to Recent once; you can change it back under Arrange sessions above the list.
- **WorkBuddy sessions**: clicking a WorkBuddy session opens that conversation in WorkBuddy. Sessions you have looked at in WorkBuddy count as seen, so their titles no longer stay highlighted.
