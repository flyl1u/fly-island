## 关于这个版本

这是 0.3.2 的第二个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **会话状态灯**：Agent 页、提醒和收起条上的会话环用同一套颜色：红色是等你确认或出错，黄色是 AI 回复里在问你（问题、计划、「要的话我来做」），绿色是正在运行（包括在等它自己开的后台任务或子 Agent），灰色是已完成。看过的会话不再提醒。还在问你的会话过一会儿会再提醒一次。
- **在岛上回答提问**：Claude Code 用选项问你问题时，可以直接在岛上选（需要在 设置 → AI Agent 打开在岛上审批并点「安装/修复」）。
- **Agent 页面**：
  - 显示「正在压缩上下文」（点一次「安装/修复」后生效）。
  - 显示 Codex 的用量；可以按文件夹或提示词隐藏会话；可以手动移除会话；能列出 SSH 服务器、开发容器里通过钩子报告的会话。
  - 可选的「回复状态标记」：让 Claude 在回复末尾标出是在等你还是已做完，状态灯更准（默认关闭）。
  - Codex 的子 Agent 不再显示成单独的空会话；Codex 0.148 及以上，新会话的第一轮不再等约 1 秒（点一次「安装/修复」后生效）。
- **收起条**：会话环取代原来的蓝色会话数；可选显示 Claude 用量双环；中心图案和 Codex 宠物（随 Agent 状态变化）。
- **日历（新）**：日历页显示今天的日程和下一个会议，支持 CalDAV 和 ICS 订阅链接，标出节假日，带时间的待办也会出现在日历上。
- **多显示器**：设置 → 通用 → 位置 →「显示在」可选主显示器、鼠标所在的显示器或活动窗口所在的显示器。
- **设备提示**：耳机、蓝牙音频连接和断开，蓝牙电量低，插拔电源时岛上有提示。
- **歌词**：新增酷狗和网易云来源，带翻译，可以按歌曲调整偏移；酷狗歌词逐字高亮；没找到中文歌词时提示去酷狗或网易云。
- **设置窗口重新整理**：
  - 每页改成分组列表，开关用统一的强调色。
  - QQ、微信、邮箱合成一个「消息」页；插件扩展和插件市场合成「插件」页。
  - 「更新」并进「关于」，关于页新增「重置所有设置」和「退出岛屿」。
  - 外观页最上面有按当前设置画出的岛屿预览。
- **无障碍**：Windows 设置了减少动画时，岛屿动画会收敛；键盘操作时有清楚的焦点框。
- **其他修复**：悬停卡片不再挡在鼠标下面；待办重新导入的备份只保留最新三份。

## About this release

This is the second beta of 0.3.2. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **Session lights**: the Agent page, alerts and the collapsed bar's session ring share one set of colours: red when a session waits for your approval or failed, yellow when the AI's reply asks you something (a question, a plan, "shall I do it?"), green while it works (including waiting for a background task or subagent it started), grey when done. Sessions you have looked at stop alerting; one still asking you is reminded once more after a while.
- **Answer questions on the island**: when Claude Code asks you a question with options, pick the answer on the island (turn on approving on the island under Settings → AI Agent and click "Install / repair").
- **Agent page**:
  - Shows when a session is compacting its context (after clicking "Install / repair" once).
  - Shows Codex usage; hide sessions by folder or prompt text; remove a session by hand; lists sessions reported by hooks on SSH servers and dev containers.
  - An optional reply status marker: Claude ends each reply saying whether it waits for you or is done, which makes the lights more exact (off by default).
  - Codex subagents no longer show as empty sessions of their own; with Codex 0.148 or later a new session's first turn no longer waits about a second (after clicking "Install / repair" once).
- **Collapsed bar**: a session ring in place of the blue session count; an optional Claude usage double ring; a centre pattern and Codex pets that follow the agents' state.
- **Calendar (new)**: today's events and the next meeting from CalDAV and ICS subscription links, holidays marked, and todos with a time on the calendar.
- **Multiple displays**: Settings → General → Position → "Show on" picks the primary display, the one under the pointer, or the one with the active window.
- **Device alerts**: headphones and Bluetooth audio connecting and disconnecting, low Bluetooth battery, and plugging the charger in or out.
- **Lyrics**: Kugou and NetEase sources with translations and a per-song offset; Kugou lyrics light up word by word; a hint to try Kugou or NetEase when a Chinese song has no lyrics.
- **Settings window reorganised**:
  - Every page is a grouped list, and switches share one accent colour.
  - QQ, WeChat and Mail are one Messages page; installed plugins and the market are one Plugins page.
  - Updates moved into About, which also gains Reset all settings and Quit.
  - The Appearance page opens with a preview of the island drawn from the current settings.
- **Accessibility**: island motion calms down when Windows asks for less animation, and keyboard focus is clearly visible.
- **Other fixes**: hover cards step out from under the pointer; only the newest three todo reimport backups are kept.
