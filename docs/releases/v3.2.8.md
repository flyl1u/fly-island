## 更新内容

- **插件市场正式开放**：「设置 → 插件」里可以一键安装内置插件，装上后就是小岛的一部分，卸载后对应内容随之消失；安装时自动打开它对应的开关和额度环。
  - **时间与天气**：在收起的小岛上显示当前时间和天气，两者各有独立开关；天气在插件设置里搜索城市，每 30 分钟刷新一次。
  - **聊天插件：钉钉、飞书、企业微信**：客户端任务栏闪烁时小岛弹出提醒，点提醒或标签可以直接打开客户端。
  - **Agent 插件：Cursor、Kimi Code、Hermes**：会话和 Claude Code、Codex 等进入同一个列表，状态灯、提醒、提示音都和原有 Agent 一致；Kimi Code、Z Code 还有额度环。
- **岛上的排列更自由**：「设置 → 外观 → 岛上的排列」拖动时其他项实时让位，往左往右都能一次拖过好几项；状态灯和文字分开，可以各自摆放；拖进下方的盒子就不在岛上显示，拖回来即可恢复。预览岛跟随你当前的主题、材质、字体和圆角。
- **收起的岛可以更紧凑**：「外观 → 大小」新增「两侧留白」，调节时岛实时变化；收起高度最低可以设到 26px。
- **配置一键导出 / 导入（#87）**：「设置 → 通用 → 备份与迁移」把设置、待办、笔记和插件偏好导出成一个文件，在另一台电脑导入后无缝衔接；密钥和窗口位置不会导出。
- **待办与每日笔记文件互相编辑（#88）**：「设置 → 待办」里打开后，在每日 Markdown 文件里改待办，小岛上的列表跟着变，反过来也一样；两边同时改出冲突时会把两份都另存，不会丢内容。默认关闭。
- **音乐快捷键**：「设置 → 音乐」可以给播放 / 暂停、上一首、下一首设置全局快捷键，默认不设置。
- **托盘图标**：右键菜单跟随界面语言，新增显示 / 隐藏岛屿、检查更新等选项；不想看到托盘图标可以隐藏，隐藏后再次启动 Fly Island 会打开设置，方便找回。
- **颜色预设更完整（#95）**：预设会连同「展开后的文字」颜色一起保存，色块显示全部四种颜色；删除预设需要再点一次确认。
- **邮件可以复制了**：在邮件正文里拖选文字，松开鼠标后选区保留，可以直接复制。
- **文件中转更简洁**：去掉了底部的操作提示，文件少时页面不再留出空白的一行，清空按钮放在右下角。
- **贴边更稳**：贴边前先校准小岛的位置，减少部分电脑上贴边后小岛往下偏移的情况。

## 已知限制

## What's new

- **The plugin market is open**: install built-in plugins in one click from Settings → Plugins. An installed plugin becomes part of the island, uninstalling removes what it added, and installing one turns on its switch and quota ring.
  - **Time and weather**: the current time and weather on the collapsed island, each with its own switch. Search for your city in the plugin's settings; the weather refreshes every 30 minutes.
  - **Chat plugins: DingTalk, Feishu, WeCom**: when the client flashes in the taskbar the island shows a reminder; clicking it or the tab opens the client.
  - **Agent plugins: Cursor, Kimi Code, Hermes**: their sessions join Claude Code, Codex and the rest in one list, with the same status light, alerts and sounds; Kimi Code and Z Code also get quota rings.
- **Arrange the island freely**: in Settings → Appearance → On the island, other items make way as you drag, several at a time in either direction. The status light and the text are now separate items. Drop an item in the box below to take it off the island, and drag it back to restore it. The preview follows your theme, material, font and corners.
- **A more compact collapsed island**: Appearance → Size has a new Side space setting that the island follows as you change it, and the collapsed height can go down to 26px.
- **Export and import your setup (#87)**: Settings → General → Backup & transfer saves your settings, todos, notes and plugin preferences to one file to import on another computer. Keys and window positions are not exported.
- **Edit todos in the daily note file too (#88)**: turn it on in Settings → Todos, and todos changed in the daily Markdown file show up on the island and the other way round. If both change at once, both versions are saved so nothing is lost. Off by default.
- **Music shortcuts**: Settings → Music can set global shortcuts for play / pause, previous and next. None are set by default.
- **Tray icon**: its menu follows the interface language and adds show / hide island and check for updates. You can hide the tray icon; launching Fly Island again then opens Settings so you can bring it back.
- **Complete color presets (#95)**: presets also save the open page's text color, their swatches show all four colors, and deleting one asks you to confirm.
- **Copy from mail**: text you select in a mail stays selected when you let go, so you can copy it.
- **A cleaner file shelf**: the hint line at the bottom is gone, a few files no longer leave an empty row, and Clear sits in the bottom-right corner.
- **Steadier tucking**: the island checks its position before tucking, which keeps it from shifting down on some computers.

## Known limitations

- DingTalk, Feishu and WeCom only say that a new message arrived, without its content.
- Z Code shows its quota ring only; Cursor and Hermes have no quota ring.
