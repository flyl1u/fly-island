## 更新内容

- **修复从旧版本升级时安装中断**：3.2.9 的安装包在覆盖已安装的旧版本时，会弹出「Error opening file for writing ... media-plugins\BetterNCMII.dll」并停在半路，应用内自动更新也会卡住。现在会正确装回原来的安装目录；如果原目录已经被移动或删除，就装到默认位置。
- 3.2.9 的其余更新内容见 [v3.2.9 说明](https://github.com/flyl1u/fly-island/releases/tag/v3.2.9)。

## What's new

- **Upgrading from an older version no longer stops halfway**: when the 3.2.9 installer replaced an installed older version it showed "Error opening file for writing ... media-plugins\BetterNCMII.dll" and stopped, and in-app updates got stuck too. It now installs back into the existing folder, or into the default location if that folder has since been moved or deleted.
- For everything else that changed in 3.2.9, see the [v3.2.9 notes](https://github.com/flyl1u/fly-island/releases/tag/v3.2.9).

## Downloads

- `fly-island_3.2.10_x64-setup.exe` for the Windows x64 EXE installer.
- `fly-island_3.2.10_x64_en-US.msi` for the Windows x64 MSI installer.
- `.sig`, `latest.json` and `SHA256SUMS.txt` provide installer signatures, the in-app update manifest and checksums.
