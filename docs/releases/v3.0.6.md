## 更新内容

- **导航按钮图标样式**：设置中可把岛屿展开态的六个小按钮从胶囊切换为图标，默认仍是胶囊。
- **待办进度**：待办列表显示完成进度条；过去的待办移到日历中。
- **微信消息摘要（实验性，默认关闭）**：在「设置 → 消息 → 微信提醒」中开启后，有新消息时岛屿显示联系人和消息摘要，点击可唤回微信并打开对应会话。
  - 这是非官方功能，会临时修改微信进程中的辅助功能标志，可能导致客户端异常、升级后失效或触发微信账号限制。
  - 开启摘要后，点微信右上角「×」收起微信，摘要仍会显示。可选开关「最小化时隐藏微信任务栏图标」，默认关闭。
  - 摘要只保存在本机内存中，不会写入磁盘。

## What's new

- **Icon style for island buttons**: in Settings you can switch the six small buttons on the expanded island from capsules to icons. Capsules remain the default.
- **Todo progress**: the todo list shows a completion progress bar, and past tasks move to the calendar.
- **WeChat message previews (experimental, off by default)**: turn it on under Settings → Messages → WeChat reminders. When a new message arrives, the island shows the contact and a message preview. Click it to bring WeChat forward and open that conversation.
  - This is an unofficial feature. It temporarily changes an accessibility flag in the WeChat process and may cause client instability, stop working after a WeChat update, or lead to account restrictions.
  - With previews on, clicking WeChat's close button (×) minimizes WeChat and previews keep working. An optional switch, "Hide the WeChat taskbar button when minimized", is off by default.
  - Previews are kept only in memory on this device and are not written to disk.
