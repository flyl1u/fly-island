## 关于这个版本

这是 0.3.1 的测试版，会通过应用内更新推送给所有 0.3.0 用户。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **邮箱**：不再只支持 QQ 邮箱，163、126 以及大多数学校和公司邮箱都可以连接。最多可以同时连接 5 个邮箱，每个邮箱一个标签页，显示各自的状态和未读数；连接时可以填写 IMAP 服务器（不填则使用 `imap.<域名>`）。之前连接的 QQ 邮箱会自动保留。
- **关于页**：第一次打开时自动检查一次更新，有新版本时直接显示它的更新说明（按界面语言显示中文或英文）。自己编译的版本也能检查和安装更新了。
- **新安装的默认设置**：第一次安装时使用一套整理过的外观和行为设置，「重置外观」也恢复到这套设置。已经保存的设置不受影响。
- **插件**：岛屿开始信任新插件索引仓库 [focusd-plugins](https://github.com/TixXin/focusd-plugins) 的签名，为以后让外部作者上架插件做准备。插件市场暂时仍从原来的位置读取。
- 修复邮箱错误提示里多出来的空格。

## About this release

This is a beta of 0.3.1, delivered by in-app update to everyone on 0.3.0. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **Mail**: no longer QQ Mail only. 163, 126 and most school and company mailboxes can be connected. Up to five mailboxes at once, each in its own tab with its status and unread count; the connect form takes an optional IMAP server (empty means `imap.<domain>`). A QQ mailbox you already connected is kept.
- **About page**: checks for updates once when first opened and shows the notes of a new version in the interface language. Builds you compile yourself can check for and install updates too.
- **Defaults for new installs**: a first install starts with a curated look and behavior, which "Reset appearance" also returns to. Saved settings are not changed.
- **Plugins**: the island now trusts signatures from the new plugin index repository, [focusd-plugins](https://github.com/TixXin/focusd-plugins), in preparation for plugins from outside authors. The market is still read from its current place.
- Fixes stray spaces in mail error messages.

## Downloads

- `fly-island_0.3.1-beta.1_x64-setup.exe`: Windows x64 EXE installer.
- `*.msi`: Windows x64 MSI installer (its internal MSI version is 0.3.1.1, because MSI versions must be numeric).
- `SHA256SUMS.txt`: SHA-256 checksums for both installers.
