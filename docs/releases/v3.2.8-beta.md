## 测试版说明

这是测试版，只有在「设置 → 关于 → 测试版」里主动下载的用户才会收到，正式版用户不受影响。想回到正式版，在同一处点「还原到正式版」即可。

本测试版在 3.2.7 的基础上开放 **插件市场**，欢迎试用并反馈问题。

## 更新内容

- **插件市场**：「设置 → 插件」里可以一键安装内置插件，装上后就是小岛的一部分，卸载后对应内容随之消失。
- **聊天插件：钉钉、飞书、企业微信**：装上后消息页出现对应标签。客户端任务栏闪烁时小岛弹出提醒，顶栏铃铛亮红点，点提醒或标签可以直接打开客户端；「设置 → 消息」里可以单独开关每个客户端，监听出错时会显示原因。
- **Agent 插件：Cursor、Kimi Code、Hermes**：装上后它们的会话和 Claude Code、Codex 等进入同一个列表，卡片、状态灯、归档、等待确认和完成提醒、提示音、折叠时显示会话标题都和原有 Agent 一致，点会话可切到对应窗口；「设置 → AI 会话 → 会话来源」里可以单独开关。
- **Agent 插件额度环：Kimi Code、Z Code**：Kimi Code 显示 5 小时和 7 天额度，Z Code 显示编程套餐额度（没有套餐时显示体验额度）。和原有 Agent 一样可以在「额度环」里勾选，额度到达设定比例或重置时也会弹出提醒。
- **安装即可用**：安装插件时自动打开它对应的开关和额度环，不用再去设置里找。

## 已知限制

- Z Code 目前只有额度环，还不能显示会话。
- Cursor 和 Hermes 没有额度环：新版 Cursor 把登录信息加密保存，暂时读不到用量；Hermes 可以接多家模型，本身没有统一的套餐额度。
- 钉钉、飞书、企业微信只提示「有新消息」，不显示消息内容。

## About this beta

This is a beta. Only users who download it from Settings → About → Beta get it; stable users are not affected. To go back, choose "Restore stable release" in the same place.

On top of 3.2.7, this beta opens the **plugin market**. Please try it and tell us what you find.

## What's new

- **Plugin market**: install built-in plugins in one click from Settings → Plugins. An installed plugin becomes part of the island; uninstalling removes what it added.
- **Chat plugins: DingTalk, Feishu, WeCom**: each adds a tab on the Messages page. When the client flashes in the taskbar the island shows a reminder and the header bell gets a red dot; clicking the reminder or tab opens the client. Each client has its own switch in Settings → Messages, which also shows why listening failed, if it did.
- **Agent plugins: Cursor, Kimi Code, Hermes**: their sessions join Claude Code, Codex and the rest in one list, with the same cards, status light, archiving, waiting and done alerts, sounds and collapsed session titles; clicking a session brings its window forward. Each has its own switch under Settings → AI sessions → Session sources.
- **Agent plugin quota rings: Kimi Code, Z Code**: Kimi Code shows its 5-hour and 7-day limits, Z Code its Coding Plan (or the trial balance without a plan). Like the built-in agents they can be ticked under Quota rings and raise usage alerts when a limit reaches your level or resets.
- **Ready once installed**: installing a plugin also turns on its switch and quota ring.

## Known limitations

- Z Code shows its quota ring only; its sessions are not listed yet.
- Cursor and Hermes have no quota ring: recent Cursor versions store the sign-in encrypted, so usage cannot be read for now, and Hermes works with many model providers and has no single plan to show.
- DingTalk, Feishu and WeCom only say that a new message arrived, without its content.

## Downloads

- `fly-island_3.2.8-beta_x64-setup.exe` for the Windows x64 EXE installer.
- The file ending in `_x64_en-US.msi` for the Windows x64 MSI installer.
- `.sig`, `latest.json` and `SHA256SUMS.txt` provide installer signatures, the in-app update manifest and checksums.
