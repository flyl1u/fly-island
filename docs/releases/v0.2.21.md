## 更新内容

- 设置默认在小岛内部打开，保留通用、外观、通知、集成与关于分类。
- 在「通用」中新增「独立设置窗口」开关，开启后单独打开设置；关闭后回到小岛，重启后记住选择。
- 小岛设置入口、托盘设置入口和保存目录提示遵循同一窗口偏好。
- 沿用已有数据目录和存储键；窗口切换不清空待办、每日笔记、归档、预设或剪贴板收藏。

---

## What's new

- Settings now opens inside the island by default, retaining all existing categories.
- Added “Open settings in a separate window” under General. Turn it off to move settings back into the island. The choice survives restarts.
- The island, tray and missing export directory prompt follow the same window preference.
- Existing data directories and storage keys are retained. Switching settings windows preserves todos, notes, archives, presets and clipboard favorites.
