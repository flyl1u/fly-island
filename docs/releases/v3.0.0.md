## 更新内容

这是一次大版本更新：加入了 AI Agent、歌词、文件中转等新功能，同时把设置精简到每页只剩几项，让小岛保持轻量、上手即用。感谢 [@TixXin](https://github.com/TixXin) 和 Louis 在 #47 中的贡献，本版本挑选了其中的部分功能。

### 新功能

- **AI Agent**：显示 Claude Code 和 Codex 会话的运行状态；点击会话直接打开对应的对话（Claude / Codex 桌面版、VS Code / Cursor 扩展），终端里运行的会话会切到对应标签页。
- **在岛上审批**：Agent 请求权限时可以直接在岛上允许或拒绝。
- **额度环**：Claude（橙色）和 Codex（蓝色）的剩余额度，外圈 5 小时、内圈 7 天。
- **歌词**：音乐页和收起的岛上显示同步歌词；可以拖动调整多个播放器的优先顺序。
- **文件中转**：把文件拖到岛上暂存，再拖到其他程序；显示系统图标和图片缩略图。
- **邮箱**：支持多个邮箱，邮件可以在岛上阅读，带附件和网页正文。
- **待办**：可以把待办安排到以后的某一天；有新版本时，待办列表顶部会出现一条更新待办，点一下即可重启安装。
- **翻译**：支持多家翻译服务，可以设为在岛上打开。
- **跨屏跟随、游戏模式、贴边隐藏**。

### 界面

- 重新设计了小岛的外形：Apple 风格的连续圆角，岛内所有卡片的圆角统一。
- 重做了音乐页和文件中转页；展开和收起改为弹簧动画，更顺滑。
- 设置默认在小岛内打开，可在「通用 → 独立设置窗口」中改为单独窗口；每页只保留常用选项。
- 外观中可以选择展开后的大小（小 / 中 / 大）。
- 顶部圆点悬停时显示页面名称。

### 升级须知

- 精简掉的设置项会恢复为默认值；样式预设和主题导入导出暂不提供。
- 液态玻璃外观暂时关闭，统一使用经典外观。
- 待办、笔记、归档、剪贴板收藏和邮箱等数据保留不变。

## What's new

A major update: AI Agent status, lyrics and a file shelf join the island, while Settings is trimmed to a few options per page so the island stays light and easy to pick up. Thanks to [@TixXin](https://github.com/TixXin) and Louis for their work in #47, from which this release takes a selection of features.

### New

- **AI Agent**: see the state of your Claude Code and Codex sessions. Click one to open that conversation (Claude / Codex desktop apps, VS Code / Cursor extensions); sessions in a terminal switch to their tab.
- **Approve on the island**: allow or deny an agent's permission request right on the island.
- **Quota rings**: remaining Claude (orange) and Codex (blue) quota, 5-hour window outside, 7-day window inside.
- **Lyrics**: synced lyrics on the music page and on the collapsed island; drag to set the order of your players.
- **File shelf**: drop files on the island and drag them into another app later, with system icons and image previews.
- **Mail**: several mailboxes, with mail you can read on the island, attachments and HTML bodies included.
- **Todos**: schedule a todo for a later day. When an update is ready, a todo at the top of the list restarts into it.
- **Translation**: several translation services, and an option to open it on the island.
- **Follow across screens, game mode, edge tucking.**

### Look and feel

- A new island shape with Apple-style continuous corners, matched by every card inside it.
- Rebuilt music and file shelf pages; expanding and collapsing use spring motion and feel smoother.
- Settings opens inside the island by default (General → Separate settings window moves it out), and each page keeps only the common options.
- Choose the expanded island's size (Small / Medium / Large) under Appearance.
- Hovering a page dot shows the page's name.

### Before you upgrade

- Settings that were removed go back to their defaults; style presets and theme import/export are not available for now.
- The Liquid glass look is paused for now; the classic look is used.
- Todos, notes, archives, clipboard favorites and mailboxes are kept.
