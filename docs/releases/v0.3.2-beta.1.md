## 关于这个版本

这是 0.3.2 的第一个测试版，只推送给在 设置 → 更新 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **在岛上审批（实验功能，默认关闭）**：Claude Code 或 Codex 要你确认一个命令时，可以直接在岛上点「允许 / 拒绝 / 本会话始终允许 / 到终端处理」，不用切回终端。在 设置 → AI Agent 里点「安装/修复」并打开「在岛上审批」后生效；Codex 还要在它的 /hooks 里信任新钩子；auto 模式自己批准的操作不会弹出。卡片显示时可用 Ctrl+Alt+Y / N / T 允许、拒绝、交回终端。不打开时审批和以前完全一样。等 2 分钟没人选，或者你在终端按了 Esc，会自动交还终端。**这项功能还没在真机上完整验证过，遇到问题请关掉开关并反馈。**
- **Agent 弹出提醒**：
  - 会话开始、完成、出错或等你确认时，收起的岛屿会自动展开，只显示这一个会话，几秒后收起。会话窗口已在前台或游戏勿扰时不弹。
  - 完成和出错的提醒会显示 AI 最后的回复（最多 3 行，去掉了 Markdown 符号）。
  - 设置 → AI Agent → 弹出提醒：每种事件可单独开关；「会话开始」可选每一轮 / 只在新会话 / 不弹。
- **Agent 音效**：新增「声音」设置页，会话开始、完成、出错、等待确认时可以播放音效，可以导入自己的音效文件或整包导入音效包。
- **Agent 页面**：
  - 顶部显示 Claude 的 5 小时、7 天用量（需要 claude-hud 状态栏保存的用量文件）。
  - 跑完还没看过的会话保持高亮；会话卡片标出非默认的权限模式和正在运行的子 Agent 数；运行中的会话显示你最近的指令和正在调用的工具。
  - 在 Windows Terminal 里能切到会话所在的标签页；VS Code 安装配套扩展后能切到会话的终端。
  - 退出时还开着提问的会话，不再一直显示「等待确认」。
- **岛屿外观**：圆角默认改为「方圆」（更饱满的超椭圆圆角），可在 外观 → 尺寸与位置 → 圆角样式 切回「圆角」。修了聚焦和展开时顶部过渡弧的接缝。
- **系统提示**：调节音量或亮度时岛上显示当前值；有程序在用摄像头或麦克风时岛上有提示。
- **音乐**：音乐页显示同步歌词（支持网易云音乐，显示为简体中文）；没在播放时停止波形和音量检测，更省电。
- **QQ / 微信**：不管安装在哪个目录都能找到。
- **插件**：剪贴板、文件中转、消息的右键菜单可以出现插件的条目；插件可以修改自己的设置、控制媒体的进度、音量、随机、循环和封面，并能收到文件中转和锁屏、睡眠、空闲事件。插件开发 SDK 和脚手架 0.3.0。

## About this release

This is the first beta of 0.3.2. It reaches only users who chose the Beta channel under Settings → Updates, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **Approve on the island (experimental, off by default)**: when Claude Code or Codex asks you to approve a command, you can answer on the island (Allow, Deny, Always allow for this session, or Handle in terminal) without switching to the terminal. Click "Install / repair" under Settings → AI Agent and turn on "Approve on the island"; Codex also needs the new hook trusted in its /hooks, and actions auto mode approves by itself never show a card. While a card shows, Ctrl+Alt+Y / N / T allow, deny or hand it back. With the switch off, approvals work as before. After two minutes without an answer, or when you press Esc in the terminal, the request goes back to the terminal. **This has not been fully tested on real machines yet; if anything goes wrong, turn the switch off and let us know.**
- **Agent pop-up alerts**:
  - When a session starts, finishes, fails or waits for you, a collapsed island opens showing just that session, then closes after a few seconds. Not while the session's window is in front or game mode keeps the island quiet.
  - Finished and failed alerts show the AI's last reply (up to three lines, Markdown marks removed).
  - Settings → AI Agent → Pop-up alerts: a switch for each event; session starts can alert every turn, for new sessions only, or never.
- **Agent sounds**: a new Sounds settings page plays a sound when a session starts, finishes, fails or waits for you. Import your own sound files or whole sound packs.
- **Agent page**:
  - Claude's 5-hour and 7-day usage at the top (needs the usage file the claude-hud status line keeps).
  - Finished sessions you have not looked at stay bright; session cards mark a non-default permission mode and running subagents; working sessions show your latest prompt and the tool in use.
  - Switches to the session's tab in Windows Terminal, and to its terminal in VS Code with the companion extension.
  - A session you quit while it was asking you something no longer stays "Waiting".
- **Island look**: corners are now squircles (fuller superellipse corners) by default; switch back to round under Appearance → Size & position → Corner style. Fixed seams between the island and its top-edge fillets.
- **System indicators**: the island shows the volume or brightness when you change it, and a hint while an app uses the camera or microphone.
- **Music**: synced lyrics on the music page (NetEase Cloud Music supported, shown in Simplified Chinese); the waveform and audio meter stop while nothing plays, saving power.
- **QQ / WeChat**: found wherever they are installed.
- **Plugins**: plugin entries in the clipboard, shelf and message right-click menus; plugins can change their own settings, control seek, volume, shuffle, repeat and the cover, and receive shelf and lock / sleep / idle events. Plugin SDK and scaffold 0.3.0.
