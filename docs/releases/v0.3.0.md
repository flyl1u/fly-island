## 关于这个版本

这是 [TixXin/fly-island](https://github.com/TixXin/fly-island) 发布线的第一个版本。它从上游 0.2.14 分出来独立开发，应用内更新从此只读取本仓库的 Release，并使用本仓库自己的签名密钥。

- 直接覆盖安装即可，待办、笔记和设置都会保留。应用标识没有改，所以不能和上游版本同时安装。
- 安装包没有代码签名。Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

- **插件**：新增插件市场，可在里面安装、更新、卸载插件，市场索引经过签名校验。插件可以在岛上显示自己的页面和状态文字，也可以发通知、添加全局快捷键和待办右键菜单。读取剪贴板、消息、媒体、文件架和待办都要单独授权，第一次使用敏感权限前会在岛上询问。另外提供插件开发模式、SDK、CLI 和脚手架。
- **Agent 页面**：列出最近的 Claude Code / Codex 会话，岛上显示正在运行的会话数，等待授权的会话也会标出来。
- **翻译**：翻译成为岛上的一个页面。可以填入剪贴板内容、自动翻译、翻译选中文字，新增硅基流动（SiliconFlow）翻译服务。
- **快捷键**：所有快捷键集中到一个「快捷键」设置页，可以改，有冲突时会提示。用 Alt+数字切换展开页面。
- **游戏模式**：岛屿所在屏幕上有全屏游戏时自动收起。
- **空闲收起**：收起后岛上不再露出内容，鼠标移上去只滑出岛屿、不展开面板，移开后可以自动收回（延迟可调，默认 0.5 秒）。
- **设置窗口**：每个设置都放到它所属的页面，「关于」页内容更完整。窗口按 820×860 打开，在小屏幕上自动缩小，并记住上次的位置。
- **待办**：待办、笔记和归档从浏览器存储迁移到 `todos.json` 文件，旧数据会自动迁移。
- 展开后的面板和收起时的岛屿使用同样的纯色背景。

## About this release

This is the first release of the [TixXin/fly-island](https://github.com/TixXin/fly-island) line. It branched from upstream 0.2.14 and is developed independently. In-app updates now read only this repository's releases and use this repository's own signing key.

- Install over your current version. Todos, notes and settings are kept. The app identifier is unchanged, so it cannot be installed next to the upstream build.
- The installers are not code-signed. If Windows SmartScreen shows "Unknown publisher", choose "More info → Run anyway".

## What's New

- **Plugins**: a plugin market to install, update and uninstall plugins, with a signed index. Plugins can show their own pages and status text on the island, send notifications, and add global shortcuts and todo context-menu commands. Reading the clipboard, message alerts, media, the file shelf and todos each needs its own permission, and the island asks before a sensitive permission is first used. Also adds a plugin development mode, an SDK, a CLI and a scaffold.
- **Agent page**: lists recent Claude Code / Codex sessions, with a running count on the island and a mark on sessions waiting for permission.
- **Translation**: translation is now an island page. It can fill in the clipboard, translate automatically and translate the selection. Adds SiliconFlow as a translation service.
- **Shortcuts**: every shortcut is on one Shortcuts page, can be changed, and conflicts are reported. Alt+number switches expanded pages.
- **Game mode**: the island tucks away while a full-screen game runs on its screen.
- **Idle tuck**: a tucked island no longer shows its content. Hovering slides out only the island, without opening the panel, and it can tuck again after the pointer leaves (adjustable delay, 0.5 s by default).
- **Settings window**: each setting sits on the page it belongs to, and the About page is filled out. The window opens at 820×860, shrinks to fit small screens, and remembers its last position.
- **Todos**: todos, notes and archives moved from browser storage to a `todos.json` file. Old data is migrated automatically.
- The expanded panel uses the same flat background as the collapsed island.
