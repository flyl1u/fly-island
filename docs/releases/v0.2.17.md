## 更新内容

- 设置改为独立窗口，按通用、外观、通知、集成、关于分类；岛屿上的设置入口恢复为原来的灰色小点，也可从托盘打开。

- 设置窗口关闭重开后，继续同步主窗口的更新下载进度和安装入口；保留启动后台下载、待办提示更新的功能。
- 保留原有经典外观与已保存的外观偏好，拖离顶部后的折叠岛屿改为上下对称的胶囊形，鼠标命中区域同步调整。
- 修复 Ctrl+Space 剪贴板快捷键匹配，并调整托盘打开设置的窗口创建方式，避免阻塞与重复创建。

## What's new

- Settings now opens in its own window, grouped into General, Appearance, Notifications, Integrations and About. The original gray settings dot is restored on the island, and Settings remains available from the tray.
- Frontend code and Windows services are organized by feature, with storage fallbacks, type checks, linting and regression tests to support future maintenance.
- Reopening Settings restores the main window's update progress and install action. Startup background downloads and the update task remain available.
- The classic appearance and saved preferences are preserved. The detached collapsed island now uses a symmetric capsule with matching mouse hit boundaries.
- Ctrl+Space clipboard shortcut matching is fixed. Settings creation from the tray is moved off the menu handler and serialized to avoid blocking and duplicate windows.

Thanks to [@TixXin](https://github.com/TixXin) for the modularization and independent Settings window work in [PR #36](https://github.com/flyl1u/fly-island/pull/36). This update builds on that approach and reuses part of the module extraction implementation, adapted to the current main branch with compatibility fixes and regression coverage. The relevant implementation commits retain co-author credit.
