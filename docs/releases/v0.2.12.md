## 更新内容

- QQ 邮箱正文支持内嵌图片，优先显示 HTML 排版，并改善布局表格的显示。
- 远程邮件图片默认拦截，可在阅读页手动允许加载。
- 修复单段 HTML 邮件和分批返回的内嵌图片读取问题，图片失败时保留正文。
- 设置页新增检查更新、下载、安装和自动重启，下载进度在切换页面后仍会保留。
- 发布包内置维护者公钥，更新安装包经过签名校验。

### 首次启用应用内更新

v0.2.11 及更早版本需要先手动下载安装本版本，后续版本可在设置中检查更新。

## What's new

- Read HTML email with inline images and improved layout tables.
- Remote email images stay blocked until you choose to load them.
- Fixed single-part HTML messages and split inline-image responses; failed images no longer discard the message text.
- Check, download and install updates from Settings, with progress preserved when switching pages and an automatic restart after installation.
- Release builds include the maintainer's public key and verify signed update packages.

Users on v0.2.11 or earlier must install this release manually once to enable future in-app updates.
