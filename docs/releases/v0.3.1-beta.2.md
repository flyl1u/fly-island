## 关于这个版本

这是 0.3.1 的第二个测试版。从这个版本起，测试版只推送给选择了测试通道的用户，或者到 Release 页面手动下载安装的用户；稳定版用户不会收到。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **更新页**：设置里新增独立的「更新」页面。
  - **更新通道**：可选「稳定版」或「测试版（beta）」。选测试版会提前收到测试版本，正式版本发布时也照常收到；从测试版切回稳定版不会降级，会一直留在当前版本，直到出现更新的正式版本。安装了测试版又没有手动选过通道的，默认留在测试通道。
  - **自动检查**：启动 20 秒后检查一次，之后每 6 小时检查一次，并显示上次检查成功的时间。可以关闭。
  - **新版本提醒**：有新版本时，岛上的设置按钮会出现一个小圆点，点击直接打开更新页。
  - **跳过这个版本**：不再提醒这个版本，但仍可手动安装，之后的新版本照常提醒。
  - 「关于小岛」页保留一张卡片，点击进入更新页。
- **新安装的默认设置**：第一次安装时使用一套整理过的外观和行为设置，「重置外观」也恢复到这套设置。已经保存的设置不受影响。
- **邮箱**：
  - 可以在设置页里添加和管理邮箱。
  - 断开邮箱前会先确认（断开会删除授权码，需要重新生成）。
  - 某个邮箱的后台连接崩溃后会自动重启，不再一直卡在「连接中」。
- **设置**：QQ、微信和邮箱在侧栏的「消息」分组里各有一个设置页。
- **插件**：
  - 插件卡片把内存分成运行环境（例如 PowerShell）和插件本身两部分，CPU 很低时显示「CPU 空闲」。
  - 修复插件宿主的多个问题：
    - 一个不读输入的插件不会再卡住所有插件。
    - 撤销敏感权限后立即停止推送数据。
    - 同时到达的多条消息都会送达。
    - 下架名单不会被旧数据覆盖。
    - 市场不会把插件换成更旧的版本。
    - 开发模式插件的页面能正常显示。
  - 插件的风险提示写明了插件能读到电脑上保存的密码和授权码。
  - 用 `fly-island-plugin dev` 调试插件时，需要在本地 API 插件里打开「允许修改」。

## About this release

This is the second beta of 0.3.1. From this version on, betas reach only users who chose the beta channel or install them by hand from the Releases page; users on the stable channel are not offered them. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **Updates page**: Settings has its own Updates page.
  - **Update channel**: Stable or Beta. On Beta you get betas early and still get every final release. Switching back to Stable never downgrades: you stay on your current version until a newer final release comes out. A beta install where no channel was ever chosen stays on Beta.
  - **Automatic checks**: 20 seconds after launch, then every 6 hours, with the time of the last successful check. They can be turned off.
  - **Reminder**: when a new version is out, the island's settings button shows a dot; clicking it opens the Updates page.
  - **Skip this version**: stops the reminders for that version. It can still be installed by hand, and later versions remind as usual.
  - About keeps a card that leads to the Updates page.
- **Defaults for new installs**: a first install starts with a curated look and behavior, which "Reset appearance" also returns to. Saved settings are not changed.
- **Mail**:
  - Mailboxes can be added and managed on the settings page.
  - Disconnecting a mailbox asks first, because it deletes the authorization code.
  - A mailbox whose background connection crashes restarts by itself instead of staying at "connecting".
- **Settings**: QQ, WeChat and mail each have their own page under a new Messages group.
- **Plugins**:
  - Plugin cards split memory into the runtime (such as PowerShell) and the plugin itself, and show "CPU idle" when CPU use is very low.
  - Fixes in the plugin host:
    - A plugin that stops reading its input no longer stalls every plugin.
    - Revoking a sensitive permission stops its data at once.
    - Messages that arrive together are all delivered.
    - Stale data cannot undo a revocation.
    - The market never rolls a plugin back to an older version.
    - Development plugins' pages show up.
  - The plugin warning says plainly that plugins can read passwords and codes saved on the computer.
  - Debugging with `fly-island-plugin dev` now needs "allow changes" turned on in the Local API plugin.
