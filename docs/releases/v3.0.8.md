## 更新内容

- **用户交流群**：「设置 → 关于」新增用户交流群，点一下就能看到微信群二维码；遇到问题、想要新功能，都可以来群里问问、聊聊。没点开过之前，设置按钮、侧栏「关于」和交流群那一行会有红点提示。
- **关于页更简洁**：只留下交流群、Star 和打赏作者三行。去掉了「查看最新版本」（小岛启动时会自动检查并下载更新，待办里会出现更新按钮）、「历史版本」（在下方的更新日志里看）和「反馈问题」（改到交流群里）。打赏作者的图标换成了粉色。
- **修复调颜色时闪烁**：在独立设置窗口里拖动岛屿背景色或亮点颜色时，颜色不再来回闪，松手后再改也能正常生效。
- **微信跳转**：从岛上跳到一个已经打开着的微信会话时，不会再把它关掉。
- **翻译页滚动条**：原文框和译文改用和每日笔记一样的细滚动条，不再是白色的系统滚动条。

## What's new

- **Community group**: Settings → About now has the user community group. Click it to see the WeChat group's QR code; questions and feature ideas are welcome there. Until you open it, red dots on the settings button, on About in the sidebar and on the group row point the way.
- **A simpler About page**: just three rows now, the community group, Star and Support the author. Removed the update row (the island checks and downloads updates at startup and offers them in the todo list), History (see the changelog below) and Report a problem (ask in the group instead). The Support the author icon is pink now.
- **Colours no longer flicker while you pick them**: dragging the island background or status light colour in the separate settings window no longer flickers, and later changes take effect as expected.
- **WeChat jumps**: jumping from the island to a WeChat chat that is already open no longer closes it.
- **Translation scrollbars**: the source box and the result use the same thin scrollbar as the daily note instead of the white system one.

- `.sig`, `latest.json` and `SHA256SUMS.txt` provide installer signatures, the in-app update manifest and checksums.
