- **DSH 官方余额**：最近使用第三方模型时，仍可读取已配置的 DeepSeek 官方余额；同时存在官方 API key 和账号凭据时优先使用 API key，自定义接口的保护保持生效（#137，感谢 [@yiumanlenong](https://github.com/yiumanlenong)）。

## What's new

- **Notebook Battery plugin**: Install it from the plugin market to show charge or remaining time on the collapsed island, with inverted or translucent readouts. Open the battery page for current, full and design capacity, battery health, and up to 24 hours of charge history from the current session. Computers without a built-in battery show no battery entry. By [@QXiaoLingShang](https://github.com/QXiaoLingShang), with integration by [@flyl1u](https://github.com/flyl1u) (#126).
- **Persistent WorkBuddy sign-in**: Credentials larger than the Windows Credential Manager entry limit are now saved in chunks, keeping credits available after a restart. Existing credentials remain readable. A server rejection with no recoverable credentials offers sign-in immediately (#136, thanks [@yiumanlenong](https://github.com/yiumanlenong)).
- **DSH official balance**: A recent session using a third-party model no longer hides an available DeepSeek official balance. An official API key takes priority over account credentials; custom endpoint protections remain in place (#137, thanks [@yiumanlenong](https://github.com/yiumanlenong)).
