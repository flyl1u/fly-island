## 关于这个版本

这是 0.3.1 的第三个测试版，只推送给在 设置 → 更新 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **Agent 页面**：
  - 点一个会话，会把它所在的窗口切到前台（按会话的进程查找，任何终端或编辑器都可以）；在 Orca 里还会切到这个会话的终端标签页。第一次使用前请在 设置 → AI Agent 里点一次「安装/修复」；已经开着的会话需要 /resume 或重开后才能切换标签页。
  - 每个会话显示它运行在哪里（Orca、Windows Terminal、VS Code、Codex 等），带该程序的图标。设置 → AI Agent → 会话来源 可选「图标和名称 / 只显示图标 / 只显示名称 / 不显示」。
- **邮箱**：可以在岛上写邮件、回复邮件，查看附件并保存到「下载」文件夹，阅读时可以标为已读；IMAP 服务器一栏可以带端口。
- **翻译**：翻译窗口显示正在使用的服务和模型；对较慢的自建网关和中转服务，请求最多等 30 秒。
- **插件**：
  - 插件市场改从新的索引仓库 [focusd-plugins](https://github.com/TixXin/focusd-plugins) 读取，外部作者可以提交插件。市场里能看到插件的 README 和版本历史，标出「已验证」的发布者；插件包可以带作者签名，更新必须来自同一位作者。
  - 可以单独为某个插件选择接收预发布版本。
  - 设置 → 快捷键 新增「插件快捷键」：可以改插件命令的快捷键、关闭它，或者给没有快捷键的命令设一个。
  - 插件可以在用到时再申请权限（可选权限），岛上会询问你；答复可以在插件设置页撤销。
  - 插件设置页新增「调用记录」：插件最近 200 次调用了哪些接口、结果如何，不记任何数据内容。
  - 插件卡片只显示插件自己占用的内存，总量和 PowerShell / Node.js 的部分在鼠标悬停时显示；不再显示 CPU 和启动时间（CPU 过高的提醒保留）。每个插件可以设置内存上限，只按插件自己的占用计算。
  - 网页或其他程序可以通过 `focusd://plugin/<插件 id>/...` 链接唤起插件，第一次前会询问你。
  - 插件开发：SDK 和脚手架 0.2.0（作者签名、`view.patch` 增删条目、可选权限）。

## About this release

This is the third beta of 0.3.1. It reaches only users who chose the Beta channel under Settings → Updates, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **Agent page**:
  - Clicking a session brings its window forward (found from the session's process, so it works in any terminal or editor); in Orca it also switches to the session's terminal tab. Click "Install / repair" once under Settings → AI Agent first; sessions that were already open need /resume or a restart before the tab switch works.
  - Each session shows where it runs (Orca, Windows Terminal, VS Code, Codex, ...) with that program's icon. Settings → AI Agent → Session source offers icon and name, icon only, name only, or none.
- **Mail**: write and reply to mail from the island, see attachments and save them to Downloads, and mark a message read while reading it. The IMAP server field accepts a port.
- **Translation**: the translation window shows the service and model in use, and requests wait up to 30 seconds for slower self-hosted gateways and relays.
- **Plugins**:
  - The plugin market now reads the new index repository [focusd-plugins](https://github.com/TixXin/focusd-plugins), where outside authors can submit plugins. The market shows each plugin's README and version history and marks verified publishers; packages can carry an author signature, and updates must come from the same author.
  - Each plugin can opt in to its pre-release versions.
  - Settings → Shortcuts has a new "Plugin shortcuts" section: change a plugin command's shortcut, turn it off, or give one to a command that has none.
  - Plugins can ask for permissions when they need them (optional permissions); the island asks you, and you can revoke the answer on the plugin's settings page.
  - A plugin's settings page has a "Calls" list: the island APIs it called in its last 200 calls and how each ended, without any of the data.
  - Plugin cards show only the plugin's own memory; the total and the PowerShell / Node.js share are in the hover. CPU and start-up time are gone from the cards (the high-CPU warning stays). Each plugin can have its own memory limit, counted on its own share.
  - Web pages and other apps can open a plugin with a `focusd://plugin/<plugin id>/...` link; the island asks you the first time.
  - For plugin authors: SDK and scaffold 0.2.0 (author signatures, view.patch add / remove, optional permissions).
