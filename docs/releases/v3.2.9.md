## 更新内容

- **贴边圆角重做**：岛身和两侧圆角现在是同一条轮廓，交界处不再有台阶，快速拖动「贴边圆角」的范围滑块时也一样；液态玻璃、磨砂玻璃的材质回到 3.2.8，圆角里不再出现竖向亮边，展开后顶部也不再有横向的颜色分界。
- **页面按钮新增「图标加文字」**：「设置 → 外观 → 页面按钮」可选第三种样式，每个按钮左边图标、右边名称；放不下时自动收紧间距、略微缩小字号，默认宽度下中英文都能完整显示。
- **插件可以直接开关**：插件市场里已安装的卡片左下角多了开关，关掉后插件不生效、设置原样保留，再打开就恢复，不用再靠卸载来停用。卡片改为名字和作者在图标右边。
- **时间与天气**：有了单独的设置栏目；城市可以一键定位（开了代理时按网络位置可能不准，会提示你手动搜索）；城市搜索按人口和行政级别排序，不再被同名小地方挤掉；选好的城市会一直保存，不会在重新打开小岛后丢失。
- **Z Code**：额度读取更稳，国内改用 open.bigmodel.cn；可以手动填写 Coding Plan API Key，设置收成一行，点「设置」在弹窗里填写，界面上只显示 Key 的后四位。
- **WorkBuddy 不再动不动就掉登录**：网络波动、页面加载慢不会再被当成登录过期，也不会清掉保存的登录信息；后台会在过期前自动续期，重启小岛或电脑后不用重新登录。只有服务器连续明确拒绝时才提示重新登录。
- **剪贴板**：从微信、浏览器复制的图片在历史里显示为图片。
- **微信提醒**：不再提醒公众号、订阅号、服务号等官方账号的消息。
- **开机自启**：能识别在任务管理器里被禁用的状态；开机自启时推迟首次更新检查，开机更轻快。

## 已知限制

- WorkBuddy 登录后最长能保持多久由 WorkBuddy 服务器决定；服务器撤销会话或要求重新验证时仍需重新登录。
- 钉钉、飞书、企业微信仍只提示「有新消息」，不显示消息内容。

## What's new

- **Reworked attached corners**: the island and its two shoulders are now one outline, so there is no step where they meet, even while you drag the attached-corner size slider quickly. Liquid and frosted glass look as they did in 3.2.8, with no vertical rim line inside the shoulders and no horizontal colour edge across the top of the open island.
- **Icons & labels page buttons**: Settings → Appearance → Page buttons has a third style with an icon and a name on every button. When space runs short the spacing tightens and the text gets slightly smaller, so all names fit at the default width in Chinese and English.
- **Turn plugins on and off**: installed cards in the plugin market have a switch. Turning a plugin off stops it but keeps its settings, and turning it back on restores it, so you no longer have to uninstall it. Names and authors now sit beside the icon.
- **Time and weather**: its own settings page; locate your city in one click (with a proxy the network location may be off, and you are told to search instead); city search ranks by population and administrative level; the chosen city stays saved when you reopen the island.
- **Z Code**: steadier quota reading, using open.bigmodel.cn in mainland China; you can enter a Coding Plan API key in a single row that opens a dialog, and only its last four characters are shown.
- **WorkBuddy stays signed in**: network hiccups or a slow page no longer count as an expired sign-in or clear the saved sign-in. It is renewed in the background before it expires and survives restarting the island or the computer. You are asked to sign in again only after the server clearly refuses it more than once.
- **Clipboard**: images copied from WeChat or a browser show as images in the history.
- **WeChat alerts**: messages from official accounts, subscriptions and service accounts no longer alert.
- **Start with Windows**: recognises when Task Manager has disabled it, and delays the first update check when starting with Windows.

## Known limitations

- How long a WorkBuddy sign-in can last is up to WorkBuddy's server; you still need to sign in again when it revokes the session or asks you to verify.
- DingTalk, Feishu and WeCom still only say that a new message arrived, without its content.
