## 更新内容

- **Agent 提示音更安静**：只在你交代的任务做完、等你审批、有问题要你回答时才响或弹出；后台任务结果、子会话汇报等自动续上的回合，以及压缩上下文、额度变化都不再响。
- **收起的岛**：没点「开始」的待办不再压过 Agent 会话；有运行中的会话或歌词时先显示它们。
- **自动收起时间**：展开后多久自动收起，可以在设置里自己选。
- **翻译入口**：翻译改成左侧的页面胶囊，去掉了原来的按钮；翻译界面去掉绿色，改为中性灰白。
- **音乐**：进度条可以拖动跳转；在播放器里调整进度后，歌词会立刻跟上。
- **待办**：编辑折成多行的待办时，显示全部内容。
- **快捷键**：录制更可靠；按下的组合被其他程序占用（例如音乐、聊天软件的全局快捷键）时会明确提示换一个，不再悄悄保留旧的快捷键。
- **邮件**：正文图片按网页邮箱的方式显示大小；顶部按钮靠在一起，去掉了含义不清的图片按钮。
- **设置**：新增游戏模式开关；SMTC 封面提示更醒目；去掉测试版更新通道，统一使用正式版。
- **文件中转**：页面和胶囊去掉薄荷绿，改为中性色。

待办、笔记、归档、剪贴板收藏和已有设置继续保留。

## What's new

- **Quieter agent sounds**: the island sounds or pops up only when a task you gave is done, waits for your approval, or has a question for you. Turns the agent continues on its own (background results, side-session reports), compacting and quota changes stay quiet.
- **Collapsed island**: a todo you have not started no longer outranks agent sessions; running sessions or lyrics come first.
- **Auto-collapse delay**: choose how long the open island waits before collapsing.
- **Translation**: now a page capsule on the left instead of a separate button, and the translation window uses neutral greys instead of green.
- **Music**: drag the progress bar to seek; lyrics follow seeks made in the player.
- **Todos**: editing a todo that wraps shows all of its lines.
- **Shortcuts**: recording is more reliable, and a combination another program already uses (such as a music or chat app's hotkey) now says so instead of quietly keeping the old keys.
- **Mail**: images in mail are sized like in a web mail client; the top buttons sit together and the unclear image button is gone.
- **Settings**: a game mode switch, a clearer SMTC hint for covers, and the beta update channel is gone; everyone gets stable updates.
- **File shelf**: neutral colours instead of mint on the page and its capsule.

Your todos, notes, archives, clipboard favorites and existing settings are preserved.
