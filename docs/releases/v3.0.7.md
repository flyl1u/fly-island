## 更新内容

- **待办倒计时（设置 → 待办 → 番茄钟，默认关闭）**：开启后“开始”左边多一个怀表。直接点“开始”只开始任务；点怀表设好分钟数（1–240），再点里面的 ▶ 才开始倒计时。每项待办各记各的时长，新待办从 15 分钟起。时间到时岛屿展开并响一次，可选“完成”或“再来一轮”。
- **拖动排序更顺手**：拖动待办时其他行实时让位、平滑滑动，松手有落位动画，按 Esc 取消。修复了往下拖时偶尔卡住的问题。
- **网易云精准进度**：网易云自带的系统媒体控制不报告进度，在网易云里拖动进度后岛屿歌词会错位。现在可以一键启用随安装包附带的开源插件 InfLink-rs 与 BetterNCM（GPL-3.0），不用下载；网易云开着也能装，装好后可一键重启网易云生效，也能一键卸载。
- **播放器兼容性提示**：岛屿会说明进度为什么不同步以及怎么解决（QQ 音乐版本过低、酷狗没开系统播放控制、网易云缺插件等）。提示浮在播放器上，不挤占封面和歌词；同一个问题只自动弹出一次，收起后右上角的图标可以再打开。「设置 → 音乐 → 播放器兼容性」列出所有检测到的播放器。
- **进度估算与歌词校准**：播放器不报告进度时，进度条标为“估算”；在播放器里拖动进度后，点一句歌词就能把进度校准到那一句。
- **消息卡片**：QQ 和微信消息改成一条一张的圆角卡片，显示来源图标、联系人、时间和最多三行内容；微信排在消息来源的第一位。
- **微信免打扰会话**：设了免打扰的会话只在有人 @你 时提示，@所有人 不再提示。
- **页面按钮**：消息按钮移到页面按钮那一排；页面按钮默认显示为图标，之前选了胶囊的保持不变。
- **DeepSeek Harness**：Agent 页显示 DSH 桌面版（含社区版）的会话，额度环显示钱包余额。
- **数字输入**：设置里的数字改为 − 数值 + 的步进器，可长按连续调整，也可以直接输入。
- **关于页更新日志**：「设置 → 关于」可以查看每个版本的更新内容。
- **关于作者**：移到设置侧栏「关于」下面，点一下直接打开作者的网站。

## What's new

- **Todo countdown (Settings → Todos → Focus timer, off by default)**: a watch appears left of Start. Start alone just starts the task; set the minutes (1–240) in the watch and press its ▶ to start a countdown. Each todo keeps its own duration, and new todos start at 15 minutes. When time is up the island opens and rings once, offering Done or Another round.
- **Smoother drag to reorder**: other rows make room and slide in real time while you drag, the row eases into place when dropped, and Esc cancels. Fixes rows occasionally getting stuck when dragged downward.
- **Precise NetEase progress**: NetEase's own system media controls report no progress, so lyrics drifted after seeking in NetEase. You can now enable the open-source InfLink-rs and BetterNCM plugins (GPL-3.0) bundled with the app in one click, with nothing to download. It installs while NetEase is running, restarts NetEase in one click to take effect, and uninstalls in one click.
- **Player compatibility tips**: the island explains why progress isn't syncing and how to fix it (QQ Music too old, Kugou's system media controls off, NetEase missing the plugin, and so on). Tips float over the player without squeezing the cover or lyrics, pop up only once per issue, and reopen from the icon in the corner. Settings → Music → Player compatibility lists every detected player.
- **Estimated progress and lyric calibration**: when a player reports no progress, the progress bar is marked as estimated; after seeking in the player, click a lyric line to recalibrate to it.
- **Message cards**: QQ and WeChat messages are now one rounded card each, with the source icon, contact, time and up to three lines of text. WeChat comes first among message sources.
- **Muted WeChat chats**: muted chats only notify when someone mentions you, not for @all.
- **Page buttons**: the messages button joins the page button row, and page buttons default to icons. A saved capsule choice is kept.
- **DeepSeek Harness**: the agent page shows sessions from DSH desktop apps (including community builds), and the ring shows wallet balance.
- **Number inputs**: numbers in Settings use a − value + stepper. Hold to repeat or type directly.
- **Changelog in About**: Settings → About now shows what changed in every version.
- **About the author**: now an entry under About in the Settings sidebar that opens the author's site directly.
