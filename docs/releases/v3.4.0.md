## 更新内容

- **插件市场正式开放**：MiniMax Code、设备电量与音频、护眼提醒可以直接安装。安装时显示下载进度，下载或校验阶段可以随时取消；已安装的插件排在最前面。插件卡片换上了品牌图标和手绘图标，作者显示 GitHub 头像。
- **新插件**：CodeBuddy 会话（作者 [@yiumanlenong](https://github.com/yiumanlenong)）、Google Antigravity 会话与额度（作者 [@lilipeng0615-cyber](https://github.com/lilipeng0615-cyber)）、Telegram 消息提醒（作者 [@baiyu0111](https://github.com/baiyu0111)）。
- **插件设置归类**：插件的设置不再堆在「插件」页，按类型放进独立栏目、「AI Agent」或「消息」页。
- **设备电量与音频 0.2.0**：读取器改用 Rust 重写，安装包从约 12.8 MB 缩小到约 0.6 MB。作者 [@Anobod1119](https://github.com/Anobod1119)。
- **护眼提醒 0.3.0**：岛内可以直接操作倒计时，全屏时自动暂停。作者 [@zloghs](https://github.com/zloghs)。
- **收起态切换**：鼠标放在岛上滚动滚轮，可在 Agent、待办、歌词之间切换；切走后有新的 Agent 任务开始时，会先显示约 2.5 秒再切回来。
- **自动长度**：收起长度可以按内容自动调整，并设置最短和最长值（160–720），消息预览变长时平滑过渡。
- **贴边**：浏览器在前台时可自动贴边（感谢 [@SeanWang114514](https://github.com/SeanWang114514)，#118）；右键收起态可贴边，并新增「永远不自动贴边」；播放媒体时不贴边。
- **外观**：空闲文字可自定义；颜色设置改为 2×2 排列；岛上的排列预览按实际宽度显示。
- **修复**：WorkBuddy 官方积分读取（感谢 梁耀文 [@yiumanlenong](https://github.com/yiumanlenong)，#124）；已结束的 Agent 会话不再显示在收起态；Antigravity 任务状态更新更及时；全屏程序退出后岛屿出不来；细线模式悬停展开死循环；拖动后展开抽搐；选城市后天气不出现。
- **其他**：在线歌词匹配更准（#117）；剪贴板文件条目显示系统图标；可导出本地脱敏诊断包。

## What's new

- **Plugin market is open**: MiniMax Code, Device Battery & Audio, and Eye Care can now be installed. Installs show download progress and can be cancelled while downloading or verifying; installed plugins are listed first. Plugin cards use brand or hand-drawn icons, and authors show their GitHub avatars.
- **New plugins**: CodeBuddy sessions (by [@yiumanlenong](https://github.com/yiumanlenong)), Google Antigravity sessions and quota (by [@lilipeng0615-cyber](https://github.com/lilipeng0615-cyber)), and Telegram message alerts (by [@baiyu0111](https://github.com/baiyu0111)).
- **Plugin settings, organized**: Plugin settings no longer pile up on the Plugins page; each goes to its own page, AI Agent, or Messages.
- **Device Battery & Audio 0.2.0**: The reader is rewritten in Rust, shrinking the package from about 12.8 MB to about 0.6 MB. By [@Anobod1119](https://github.com/Anobod1119).
- **Eye Care 0.3.0**: Control the countdown right from the island; it pauses during full-screen apps. By [@zloghs](https://github.com/zloghs).
- **Collapsed island switching**: Scroll over the island to switch between Agent, Todo and lyrics. When a new Agent task starts after you switched away, the island shows it for about 2.5 seconds, then switches back.
- **Auto length**: The collapsed length can follow its content within a minimum and maximum (160–720), with smooth transitions for message previews.
- **Edge tucking**: Tuck automatically while a browser is in front (thanks [@SeanWang114514](https://github.com/SeanWang114514), #118); right-click the collapsed island to tuck, with a new "Never tuck automatically" option; no tucking while media plays.
- **Appearance**: Customizable idle text, a 2×2 color layout, and arrangement previews at their real width.
- **Fixes**: WorkBuddy official credits (thanks [@yiumanlenong](https://github.com/yiumanlenong), #124); finished Agent sessions no longer linger on the collapsed island; faster Antigravity task updates; the island not returning after a full-screen app exits; a hover loop in thin-line mode; jitter when expanding after a drag; weather missing after choosing a city.
- **Other**: Better online lyric matching (#117), real system icons for clipboard file entries, and a local, redacted diagnostics export.
