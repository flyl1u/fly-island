## 关于这个版本

这是 0.3.2 的第三个测试版，只推送给在 设置 → 关于 → 版本 里选择了「测试版」通道的用户，以及到 Release 页面手动下载安装的用户；稳定版用户不会收到。选测试版的用户正式版本发布时也照常收到；切回稳定版不会降级。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。

## 更新内容

- **SSH 远程（新）**：设置 → AI Agent → SSH 远程 列出 `~/.ssh/config` 里的主机，也可以按地址（用户、主机、端口）手动添加。打开的主机每 20 秒通过 SSH（仅密钥登录）读取上面的 Claude Code 和 Codex 会话，Agent 页按电脑分组显示；点远程会话会按标题和文件夹找到连着它的终端标签或编辑器窗口。不会改写 `~/.ssh/config`。
- **手机推送（新）**：设置 → AI Agent → 提醒 → 手机推送，会话等你确认、完成或出错时推送到 Bark（官方服务器或自建 bark-server），默认只在离开电脑 5 分钟后推送。设备密钥保存在 Windows 凭据管理器里。默认关闭。
- **Agent 页面**：
  - 新增卡片和紧凑两种布局；可选的卡片光效（流光边框或渐变）；归档动画可选「消散」。
  - 会话行显示 AI 的任务清单进度（如「2/5 步」）和仍在运行的后台任务数。
  - 能分辨已退出的会话（本机和 SSH 远程都算），可以在设置里隐藏它们。
  - 看过的会话、手动移除的会话在重启岛屿后不再重新亮起。
  - 在终端里回答了权限请求后，岛上的审批卡片会立刻消失，不再等到 2 分钟超时（需要点一次「安装/修复」）。
  - 新选项：终端在前台时也在岛上弹审批卡片（默认关闭）。
  - 提醒展开的单会话视图，点岛屿外面会收起；卡片处理完后岛屿也会自动收起。
- **声音与用量**：新增上下文快满、会话完成后 5 分钟未读（默认关闭）、用量偏低、用量重置几种提示音；Claude 或 Codex 的 5 小时 / 7 天用量达到设定比例（默认 80%）时在收起条上提示一次。Claude 用量环可以改为显示剩余量。
- **插件**：
  - 插件市场有了单独的页面，卡片一行两个、按类别分组，已安装的不再重复列出。
  - 插件市场新增音效包类别，以及系统监控插件（CPU、GPU、内存、网络、电池，可在收起条上显示指标列）。
  - 插件可以在收起条上显示「标签 / 数值」小格和进度环，可以改写 Agent 页显示的推理强度名称。
  - 启动后才启用的插件会立即启动，不再等到下次重启。
- **设置窗口**：侧边栏重新整理，带搜索，各分组都可以折叠；AI Agent 有了自己的分组；切换页面时有淡入动画；窗口默认宽 1080。外观页的预览按实际样子画出岛屿和展开后的 Agent 会话列表。
- **默认值调整**（只影响没改过这些设置的用户）：岛屿默认改为纯黑（#000000），更贴合屏幕的黑边和刘海；没做完的待办默认顺延到第二天。
- **其他**：托盘菜单跟随界面语言；岛屿展开、收起的动画过程中文字不再模糊；「回复状态标记」移到「安装/修复」下面并设为推荐。

## About this release

This is the third beta of 0.3.2. It reaches only users who chose the Beta channel under Settings → About → Version, or who install it by hand from the Releases page; users on the stable channel are not offered it. Beta users still get every final release, and switching back to Stable never downgrades. Install over your current version. Todos, notes, settings and connected mailboxes are kept.

## What's New

- **SSH remote (new)**: Settings → AI Agent → SSH remote lists the hosts in `~/.ssh/config`, and you can add one by address (user, host, port). For each host switched on, the island reads its Claude Code and Codex sessions over SSH (key login only) every 20 seconds, and the Agent page groups sessions by computer. Clicking a remote session finds the terminal tab or editor window connected to it by title and folder. `~/.ssh/config` is never written.
- **Phone push (new)**: Settings → AI Agent → Alerts → Phone push sends a Bark notification (Bark's server or your own bark-server) when a session waits for you, finishes or fails, by default only after 5 minutes away from the computer. The device key is kept in Windows Credential Manager. Off by default.
- **Agent page**:
  - Card and compact layouts; optional card light effects (a sparkle frame or a gradient wash); a "dissolve" archive animation.
  - Session rows show the AI's task list progress (e.g. "2/5 steps") and how many background tasks are still running.
  - Sessions that have quit are recognised, locally and over SSH, and can be hidden in Settings.
  - Sessions you have looked at or removed stay quiet after the island restarts.
  - An approval card goes away as soon as you answer the request in the terminal instead of waiting out the 2-minute limit (after clicking "Install / repair" once).
  - New option: show approval cards on the island even while the terminal is in front (off by default).
  - A click outside the island closes an alert's one-session view, and the island closes again once the last card is answered.
- **Sounds and usage**: new sounds for context nearly full, a finished session left unread for 5 minutes (off by default), usage running low and usage reset. When Claude's or Codex's 5-hour or 7-day usage reaches the set level (80% by default), the collapsed island says so once. The Claude usage ring can show what is left instead of what is used.
- **Plugins**:
  - The plugin market has its own page, with two cards a row, grouped by category, and installed plugins no longer listed again.
  - New market category for sound packs, and a system monitor plugin (CPU, GPU, memory, network, battery, with optional columns on the collapsed bar).
  - Plugins can show label-over-value cells and a progress ring on the collapsed bar, and rename the effort the Agent page shows.
  - Plugins enabled after startup start right away instead of at the next restart.
- **Settings window**: a reorganised sidebar with search, where every group folds; AI Agent has its own group; pages fade in when switching; the window opens 1080 wide. The Appearance preview draws the island as it really looks, including the expanded Agent session list.
- **New defaults** (only for settings you never changed): the island is pure black (#000000), matching the screen's black bezel and notch; unfinished todos carry over to the next day.
- **Other**: the tray menu follows the interface language; text no longer blurs while the island opens and closes; the reply status marker sits under "Install / repair" and is recommended.
