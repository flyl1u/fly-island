## 更新内容

- QQ 邮箱优先使用 IMAP IDLE 服务器推送，新邮件到达即可开始同步，减少等待下一轮检查的时间。
- 缓存最近邮件的邮件头，后续只补取新邮件的邮件头，并使用 STATUS 直接查询未读总数，减少大收件箱的重复扫描和传输。
- 手动刷新、暂停接收和断开连接可及时中断后台等待；服务器不支持或拒绝推送时自动回退到 5 秒轮询。
- 补查同步过程中到达的新邮件，并为推送结束、断线和重连保留超时保护，避免漏掉通知或长时间卡住。

## What's new

- QQ Mail now prefers IMAP IDLE server notifications, starting synchronization when the server reports new mail instead of waiting for the next polling cycle.
- Cached recent message headers are reused. Only new headers are downloaded, and STATUS retrieves the unread total without enumerating every unread message.
- Refreshing, pausing and disconnecting interrupt background waits promptly. Servers without working IDLE support fall back to five-second polling.
- Changes arriving during synchronization trigger an immediate follow-up. Timeout protection covers IDLE termination and reconnecting.
