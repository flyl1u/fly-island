## 更新内容

- **游戏模式不再打扰游戏**：开着游戏模式全屏游戏时，鼠标移到屏幕上沿不会再唤出贴边的小岛，也不会抢走前台、把游戏切回桌面。
- **游戏模式下仍可弹出通知**：「设置 → 通用 → 游戏模式 → 仍显示通知」可单独设置弹出秒数，只显示、不抢焦点、鼠标照常穿透到游戏，默认关闭。
- **悬停与点击更可靠**：修复贴边隐藏一次后悬停不再自动展开、展开后擦过边缘就收起、部分区域点不了等问题；展开方式为「鼠标悬停」时，悬停在贴边的小岛上会直接展开整个岛屿。按快捷键打开剪贴板时不需要再按住等动画结束。
- **开机自启更轻**：开机启动时错峰启动非必要服务，第一次显示不抢焦点，降低开机卡顿；剪贴板复制、收藏等操作移到后台线程。
- **播放音乐时 CPU 大幅下降**：媒体与音量读取改为常驻线程并缓存设备，暂停或没有媒体会话时停止高频电平读取。
- **玻璃材质重做**：液态玻璃和磨砂玻璃会实时模糊岛屿身后的画面（窗口、视频都会跟着变化）；「设置 → 外观 → 主题 → 背景模糊」可调强度，调节范围更大。身后画面太亮或太暗时自动加深色调，文字始终看得清；文件中转、翻译等面板在玻璃上不再是深色块。截图和录屏里仍能看到小岛。收起动画不再掉帧。
- **自适应通知**：「设置 → 消息」开启后，长消息会把小岛撑宽撑高，直接在岛上读完，超出上限后滚动阅读；最大宽度、最大高度和停留时间都可调，默认关闭。
- **通知文字可选中复制**：邮件、QQ、微信通知的发件人和正文都可以用鼠标拖选、Ctrl+C 复制，点文字不会再直接跳转（打开应用用右上角的按钮）；鼠标停在通知上或还有选中的文字时它不会收走；邮件页的主题和信息行也能选中复制。
- **待办结束前提醒**：「设置 → 待办」开启后，开始计时时可选择提前几分钟提醒；到点时待办文字闪烁、时间变红，打开提示音时响三声。默认关闭。
- **Agent 后台任务正确显示**：Claude Code 的后台命令或子 Agent 还在跑时，小岛继续显示该会话并保持不收起，全部结束后正常收起。已安装 hook 的用户请到「设置 → Agent」点一次「安装 / 修复」。
- **Ctrl + 滚轮切换页面**：「设置 → 通用 → 展开与收起」开启后，在展开的小岛上按住 Ctrl 滚动滚轮即可切换页面，默认关闭。
- **外观更多可调**：新增「展开圆角」（8–96）「收起圆角」（0–40，两者分开调）和「圆角形状」，拖动时岛屿实时预览；贴边样式为「露边」时可调露出高度；左侧亮点的颜色现在会跟随设置实时变化。
- **设置重新整理**：同一功能的开关和子项放在一起，分组与文案更清楚，所有设置项和已保存的选择保持不变。
- **翻译**：翻译快捷键可以单独关闭；新增免密钥的 Google 翻译和 MyMemory，查个单词不用再配大模型。
- **剪贴板**：可按文本、图片、文件筛选，支持复制文件；独立窗口可设置「点击窗口外时关闭」，备注随窗口宽度完整显示；存储位置可以自选文件夹，切换时自动迁移旧数据。
- **待办保存路径可直接选择文件夹**：输入框旁的文件夹按钮打开系统文件夹选择框，选中即保存。
- **卸载更干净**：卸载时勾选「Delete the application data」会同步移除写入 Codex 和 Claude Code 配置的 hook，保留你自己的其他配置。
- **插件开发规范公开**：插件功能尚未上线，但「设置 → 插件」现在可以查看插件开发规范，欢迎先按规范开发并提交 PR（需附嵌入小岛后的录屏演示、作者、联系方式和 GitHub 链接）。
- **新用户上手**：第一次启动时，待办里有一条「你好，在这里写下点什么吧」，文件中转里有一份简短介绍，小岛不再空荡荡。
- **待办可设置一次显示几条**：「设置 → 待办 → 一次显示几条」，和剪贴板一样，超过后在列表里滚动。
- **剪贴板按钮更好认**：顶栏的剪贴板按钮显示为图标加「剪贴板」文字。
- **通用设置重新整理**：位置挪到展开与收起后面，「这些时候不贴边」并到贴边隐藏下面，只在开启自动贴边时显示。
- **打开翻译不再往下冲**：岛内翻译页打开时内容不再先上移再滑下来。
- **完整消息预览按长度自适应**：短消息不再撑满整个岛屿宽度，岛屿按消息长短伸缩。
- **切页更清晰**：切换页面时文字不再先模糊再变清晰。
- **英文设置侧边栏修复**：英文界面下设置侧边栏不再出现横向滚动条。

## What's new

- **Game mode stays out of your game**: in a full-screen game with game mode on, moving the mouse to the top edge no longer brings out the tucked island or takes focus away from the game.
- **Notifications in game mode (optional)**: Settings → General → Game mode → "Still show notifications" shows previews for a separate number of seconds, without taking focus and with clicks passing through to the game. Off by default.
- **More reliable hover and clicks**: fixes hover-to-expand stopping after one edge tuck, the island collapsing when the cursor brushes its edge, and areas that could not be clicked. With hover to expand, hovering over the tucked island now opens it fully. The clipboard shortcut no longer needs to be held until the animation ends.
- **Lighter launch at startup**: non-essential services start in stages after a boot launch and the first show no longer takes focus. Clipboard copy, favourite and similar actions run in the background.
- **Much lower CPU while music plays**: media and volume reads use one long-lived thread with cached devices, and fast level reads stop when playback is paused or no media session exists.
- **Rebuilt glass materials**: Liquid and Frosted glass now blur whatever is behind the island, live, adjustable over a wider range in Settings → Appearance → Theme → Background blur. Over a very bright or dark backdrop the tint deepens so text stays readable, and panels such as the file shelf and translation no longer show as dark boxes on glass. The island still shows in screenshots and recordings. Collapsing no longer drops frames.
- **Adaptive notifications**: turn on in Settings → Messages to let long messages widen and heighten the island so you can read them in place, scrolling past the limit. Maximum width, maximum height and duration are adjustable. Off by default.
- **Copyable notifications**: drag to select the sender and body text in mail, QQ and WeChat notifications and press Ctrl+C; clicking the text no longer jumps to the app (use the open button at the top right). A notification stays while the cursor is on it or text in it is selected. The mail page subject and details can be selected too.
- **Todo end-of-timer reminder**: turn on in Settings → Todos, then choose how many minutes before the end to be reminded when starting a timer. The todo blinks and its time turns red; with the sound on it chimes three times. Off by default.
- **Agent background tasks shown correctly**: while Claude Code background commands or subagents are still running, the island keeps showing that session and stays out, then collapses normally when everything finishes. If you installed the hooks, click Install / Repair once in Settings → Agents.
- **Ctrl + wheel to switch pages**: turn on in Settings → General → Expand and collapse, then hold Ctrl and scroll on the expanded island to switch pages. Off by default.
- **More appearance options**: separate Expanded (8–96) and Collapsed (0–40) corner radius settings plus Corner shape, previewed live while dragging; the visible strip height is adjustable for the Edge tuck style; the status light on the left now follows its colour setting live.
- **Reorganized settings**: each feature's switch and its options now sit together, with clearer groups and labels. All settings and saved choices are unchanged.
- **Translation**: the translation shortcut can be turned off on its own, and key-free Google Translate and MyMemory services are available for quick lookups.
- **Clipboard**: filter by text, images or files, with copied files now captured; the separate window can close when you click outside it, notes use the full window width, and history can be stored in a folder you choose, with existing data moved over.
- **Pick the todo save folder**: a folder button next to the path opens the Windows folder picker and saves the choice straight away.
- **Cleaner uninstall**: choosing "Delete the application data" when uninstalling also removes the hooks written to Codex and Claude Code settings, keeping your own configuration.
- **Plugin development guide published**: plugins are not enabled yet, but Settings → Plugins now links to the plugin development guide. You can start building and open a PR (with an in-island demo recording, author, contact and GitHub link).
- **A friendlier first launch**: new users find a "write something down here" todo and a short introduction on the file shelf, so the island is not empty.
- **Choose how many todos show at once**: Settings → Todos → Visible rows, like the clipboard; longer lists scroll.
- **Easier to spot clipboard button**: the clipboard page button in the header shows its name next to the icon.
- **Tidier General settings**: Position moves up under Expand and collapse, and the "stay out while" switches now sit under Tuck when idle, shown only while it is on.
- **Translation opens without the downward rush**: the in-island translation page no longer shifts up and slides back down as it opens.
- **Full message previews fit their length**: a short message no longer stretches across the whole island.
- **Sharper page switches**: text no longer blurs and then sharpens when switching pages.
- **English settings sidebar fix**: the settings sidebar no longer shows a horizontal scrollbar in English.
