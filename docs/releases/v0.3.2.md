## 关于这个版本

0.3.2 正式版，包含 0.3.2 三个测试版的全部内容和之后的改动。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

**升级后建议做一次**：在 设置 → AI Agent 里点「安装/修复」，状态灯、压缩提示、在岛上审批和回答提问等新功能才会生效。以前打开过「回复状态标记」的，请把它关掉再打开一次：标记从 `~/.claude/CLAUDE.md` 移到了单独的 `~/.claude/rules/focusd-island-reply-marker.md`，`CLAUDE.md` 里的其他内容不会动。

## 更新内容

- **会话状态灯**：Agent 页、提醒和收起条上的会话环用同一套颜色：红色是等你确认或出错，黄色是 AI 回复里在问你（问题、计划、「要的话我来做」），绿色是正在运行（包括在等它自己开的后台任务或子 Agent），灰色是已完成。看过的会话不再提醒，重启岛屿后也记得；还在问你的会话过一会儿会再提醒一次。
- **在岛上审批和回答（实验功能，默认关闭）**：
  - Claude Code 或 Codex 要你确认一个命令时，可以直接在岛上点「允许 / 拒绝 / 本会话始终允许 / 到终端处理」；Claude Code 用选项问你问题时，也可以直接在岛上选。卡片显示时可用 Ctrl+Alt+Y / N / T 允许、拒绝、交回终端。
  - 在 设置 → AI Agent 里点「安装/修复」并打开「在岛上审批」后生效；Codex 还要在它的 /hooks 里信任新钩子。不打开时和以前完全一样。
  - 在终端里回答了，岛上的卡片立刻消失；等 2 分钟没人选，会自动交还终端。可选「终端在前台时也在岛上弹出」（默认关闭）。
- **SSH 远程（新）**：设置 → AI Agent → SSH 远程 列出 `~/.ssh/config` 里的主机，也可以按地址添加。打开的主机通过 SSH（仅密钥登录）读取上面的 Claude Code 和 Codex 会话，每台主机保持一条连接，Agent 页可以按电脑分组。在这一页勾选的主机，「安装/修复」和「回复状态标记」也会作用到上面；之后远程会话的审批和提问也会出现在岛上的卡片里（经 SSH 反向转发，令牌只存在只有你能读的文件里）。`~/.ssh/config` 只读不改。
- **Agent 弹出提醒**：会话开始、完成、出错或等你时，收起的岛屿展开显示这一个会话，几秒后收起，完成和出错时带上 AI 最后的回复。每种事件可单独开关；点岛屿外面会收起。新增额度提醒：Claude 或 Codex 的 5 小时 / 7 天用量达到设定比例（默认 80%）时提示一次。
- **手机推送（新）**：设置 → AI Agent → 提醒 → 手机推送，会话等你、完成或出错时推送到 Bark（官方服务器或自建 bark-server），默认只在离开电脑 5 分钟后推。设备密钥存在 Windows 凭据管理器里。默认关闭。
- **Agent 音效**：新增「声音」设置页，会话开始、完成、出错、等你确认、上下文快满、额度偏低和刷新时可以播放音效；可以导入音效文件或音效包，插件市场里也有音效包。
- **Agent 页面**：
  - 列表、卡片、紧凑三种布局；可选卡片光效和「消散」归档动画；排序可选状态优先（默认）、最近活动、首次出现，分组可选按电脑、按项目或不分组。
  - 顶部显示 Claude 和 Codex 的用量；会话行显示 AI 的任务清单进度、后台任务数、你最近的指令和正在用的工具；显示「正在压缩上下文」。
  - 能分辨已退出的会话并默认隐藏；可以按文件夹或提示词隐藏会话，也可以手动移除。
  - 能切到会话所在的 Windows Terminal 标签页、WezTerm 标签页，VS Code 装配套扩展后能切到会话的终端；用 Git Bash 等方式启动、父进程已经退出的会话也能找到终端。
  - 可选「回复状态标记」：让 Claude 在回复末尾标出在等你还是已做完，状态灯更准（推荐打开）。
- **收起条**：会话环取代原来的蓝色会话数；可选显示 Claude 用量双环、中心图案和 Codex 宠物。
- **日历（新）**：日历页显示今天的日程和下一个会议，支持 CalDAV 和 ICS 订阅链接，标出节假日，带时间的待办也会出现在日历上。
- **设置窗口**：
  - 重新整理：每页改成分组列表；侧栏重新分组、可以折叠，AI Agent 有自己的一组；QQ、微信、邮箱合成「消息」页；「更新」并进「关于」，关于页新增「重置所有设置」和「退出岛屿」；插件市场有了单独的页面。
  - 搜索能搜到具体的设置项：标题、说明和选项，中英文都算，点一下直接打开那一页并高亮那一行。
  - 外观页最上面有按当前设置画出的岛屿预览。
  - 样式预设可以导出成主题文件，或从文件导入（外观 → 样式预设）。设置备份也包含了岛上审批、手机推送和歌词偏移这几项新设置。
- **岛屿与系统**：多显示器下可选岛屿显示在哪块屏幕；调节音量或亮度、耳机和蓝牙设备连接断开、蓝牙电量低、插拔电源、摄像头和麦克风在用时岛上有提示；展开和收起时文字不再模糊；托盘菜单跟随界面语言；Windows 设置了减少动画时，岛屿动画会收敛。
- **音乐**：同步歌词，支持网易云、酷狗等来源，带翻译、逐字高亮，可以按歌曲调整偏移；没在播放时停止波形检测，更省电。
- **插件**：插件可以在收起条上显示小格和进度环，出现在剪贴板、文件中转和消息的右键菜单里，修改 Agent 页显示的推理强度名称；启动后才启用的插件会立即启动。插件市场新增系统监控插件和音效包。
- **默认值调整**（只影响没改过这些设置的用户）：岛屿默认纯黑（#000000）；圆角默认「方圆」；没做完的待办默认顺延到第二天；会话来源默认只显示图标；Agent 页默认状态优先排序。
- **其他**：QQ / 微信不管装在哪个目录都能找到；邮箱底层换成了新版 IMAP 库，并修了依赖的安全提醒；悬停卡片不再挡在鼠标下面。

## About this release

The final release of 0.3.2, with everything from its three betas and the changes since. Install over your current version. Todos, notes, settings and connected mailboxes are kept. The installers are not code-signed; if Windows SmartScreen shows "Unknown publisher", choose "More info → Run anyway".

**After updating**: click "Install / repair" under Settings → AI Agent once, so the status lights, compaction notice, approving and answering on the island and the other new features work. If you had the reply status marker on, switch it off and on again: it moved from `~/.claude/CLAUDE.md` to its own `~/.claude/rules/focusd-island-reply-marker.md`, and nothing else in `CLAUDE.md` changes.

## What's New

- **Session lights**: the Agent page, alerts and the collapsed bar's session ring share one set of colours: red when a session waits for your approval or failed, yellow when the AI's reply asks you something (a question, a plan, "shall I do it?"), green while it works (including waiting for a background task or subagent it started), grey when done. Sessions you have looked at stop alerting, also after a restart; one still asking you is reminded once more after a while.
- **Approve and answer on the island (experimental, off by default)**:
  - When Claude Code or Codex asks you to approve a command, answer on the island (Allow, Deny, Always allow for this session, or Handle in terminal); when Claude Code asks a question with options, pick the answer there too. While a card shows, Ctrl+Alt+Y / N / T allow, deny or hand it back.
  - Click "Install / repair" under Settings → AI Agent and turn on "Approve on the island"; Codex also needs the new hook trusted in its /hooks. With the switch off, nothing changes.
  - Answered in the terminal, the card goes away at once; after two minutes without an answer, the request goes back to the terminal. Optionally also while the terminal is in front (off by default).
- **SSH remote (new)**: Settings → AI Agent → SSH remote lists the hosts in `~/.ssh/config`, and you can add one by address. For each host switched on, the island reads its Claude Code and Codex sessions over SSH (key login only) over one standing connection, and the Agent page can group sessions by computer. "Install / repair" and the reply status marker also act on those hosts, after which their sessions' approvals and questions reach the island's cards too (through an SSH reverse forward; the token lives only in a file only you can read). `~/.ssh/config` is only read.
- **Agent pop-up alerts**: when a session starts, finishes, fails or waits for you, a collapsed island opens showing just that session, then closes after a few seconds, with the AI's last reply for finished and failed ones. A switch for each event; a click outside closes it. A new usage alert says once when Claude's or Codex's 5-hour or 7-day usage reaches the set level (80% by default).
- **Phone push (new)**: Settings → AI Agent → Alerts → Phone push sends a Bark notification (Bark's server or your own bark-server) when a session waits for you, finishes or fails, by default only after 5 minutes away from the computer. The device key is kept in Windows Credential Manager. Off by default.
- **Agent sounds**: a new Sounds page plays a sound when a session starts, finishes, fails, waits for your approval, nearly fills its context, or when usage runs low or resets. Import sound files or sound packs; the plugin market has sound packs too.
- **Agent page**:
  - List, card and compact layouts; optional card light effects and a "dissolve" archive animation; sort by status (the default), recent activity or first seen, and group by computer, by project or not at all.
  - Claude and Codex usage at the top; session rows show the AI's task list progress, running background tasks, your latest prompt and the tool in use; "compacting context" shows.
  - Sessions that have quit are recognised and hidden by default; hide sessions by folder or prompt text, or remove one by hand.
  - Switches to the session's tab in Windows Terminal and WezTerm, and to its terminal in VS Code with the companion extension; a session whose parent process has exited (started from Git Bash and the like) is found too.
  - An optional reply status marker: Claude ends each reply saying whether it waits for you or is done, which makes the lights more exact (recommended).
- **Collapsed bar**: a session ring in place of the blue session count; an optional Claude usage double ring, centre pattern and Codex pets.
- **Calendar (new)**: today's events and the next meeting from CalDAV and ICS subscription links, holidays marked, and todos with a time on the calendar.
- **Settings window**:
  - Reorganised: every page is a grouped list; the sidebar is regrouped and folds, with AI Agent in a group of its own; QQ, WeChat and Mail are one Messages page; Updates moved into About, which also gains Reset all settings and Quit; the plugin market has its own page.
  - Search finds single settings by their title, description or choices, in Chinese or English, and opens the page at that row.
  - The Appearance page opens with a preview of the island drawn from the current settings.
  - Style presets can be exported as theme files and imported from them (Appearance → Style presets). Settings backups now also carry the approval, phone push and lyrics offset settings.
- **Island and system**: pick which display the island shows on; the island shows volume and brightness changes, headphones and Bluetooth devices connecting and disconnecting, low Bluetooth battery, the charger plugged in or out, and the camera or microphone in use; text no longer blurs while the island opens and closes; the tray menu follows the interface language; island motion calms down when Windows asks for less animation.
- **Music**: synced lyrics from NetEase, Kugou and other sources, with translations, word-by-word highlighting and a per-song offset; the waveform stops while nothing plays, saving power.
- **Plugins**: plugins can show cells and a progress ring on the collapsed bar, add entries to the clipboard, shelf and message right-click menus, and rename the effort the Agent page shows; plugins enabled after startup start right away. The market gains a system monitor plugin and sound packs.
- **New defaults** (only for settings you never changed): a pure black island (#000000); squircle corners; unfinished todos carry over to the next day; the session source shows only its icon; the Agent page sorts by status.
- **Other**: QQ and WeChat are found wherever they are installed; mail runs on a newer IMAP library, which also clears a dependency security advisory; hover cards step out from under the pointer.
