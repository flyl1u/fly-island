## 关于这个版本

0.3.1 正式版，包含 0.3.1 三个测试版的全部内容和之后的改动。直接覆盖安装即可，待办、笔记、设置和已连接的邮箱都会保留。安装包没有代码签名，Windows SmartScreen 提示"未知发布者"时，点「更多信息 → 仍要运行」。

## 更新内容

- **Agent 页面**：
  - 会话列表重新设计：会话直接排在岛上，不再套卡片；进行中的会话显示最新回复，已结束的折叠成一行。每行开头是状态圆点，末尾是来源图标，只有等待授权、失败和失联的会话才写出状态。
  - 点一个会话，会把它所在的窗口切到前台，任何终端或编辑器都可以；在 Orca 里还会切到这个会话的终端标签页，已经开着的会话也能切。/clear 或 /resume 之后仍能找到原来的窗口。第一次使用前请在 设置 → AI Agent 里点一次「安装/修复」。
  - 每个会话显示它运行在哪里（Orca、Windows Terminal、VS Code、Codex 等），带该程序的图标；在 worktree 里的会话按项目名显示。
  - 设置 → AI Agent 新增：列表显示多久以内的会话（1/2/6/24 小时）、分别显示 Claude Code 和 Codex、只显示进行中的会话、显示会话运行时长（默认关闭）和模型、会话来源的显示方式。
- **更新**：设置里新增「更新」页。
  - 可以选「稳定版」或「测试版（beta）」通道。测试版用户也照常收到正式版；切回稳定版不会降级。
  - 启动 20 秒后自动检查，之后每 6 小时检查一次，可以关闭。有新版本时岛上（包括折叠时）会出现提醒，可以跳过某个版本。
- **设置**：
  - 设置 → 通用 → 备份与恢复：把设置导出成文件，换电脑或重装后从文件恢复。待办、窗口位置和密码不会写进备份。
  - 设置 → 通用 → 展开与收起：可以选择鼠标移到收起的岛屿上时直接展开面板。
  - QQ、微信和邮箱在侧栏「消息」分组里各有一个设置页。
  - 新安装时使用一套整理过的默认外观，「重置外观」也恢复到这套设置。已保存的设置不受影响。
  - 去掉了鼠标悬停时弹出的系统提示框。
- **邮箱**：
  - 不再只支持 QQ 邮箱，163、126 以及大多数学校和公司邮箱都可以连接，最多同时连接 5 个，每个一个标签页。IMAP 服务器可以带端口。
  - 可以在岛上写邮件、回复邮件，查看附件并保存到「下载」文件夹，阅读时可以标为已读。
  - 断开邮箱前会先确认；后台连接崩溃后会自动重启。
- **翻译**：翻译窗口显示正在使用的服务和模型；对较慢的自建网关和中转服务，请求最多等 30 秒。
- **插件**：
  - 插件市场改从新的索引仓库 [focusd-plugins](https://github.com/TixXin/focusd-plugins) 读取，外部作者可以提交插件。市场页重新排版：可安装的在前、已安装的在后，每个插件只有一个操作按钮，标出「官方」「已验证」发布者；详情里能看到 README 和版本历史。
  - 插件包可以带作者签名，更新必须来自同一位作者；可以单独为某个插件接收预发布版本。
  - 设置 → 快捷键 新增「插件快捷键」，可以改、关闭插件命令的快捷键，或给没有快捷键的命令设一个。
  - 插件可以在用到时再申请权限，岛上会询问你，答复可以在插件设置页撤销。插件设置页新增「调用记录」，只记调用了哪些接口和结果，不记数据内容。
  - 插件卡片只显示插件自己占用的内存，每个插件可以设置内存上限。
  - 网页或其他程序可以通过 `focusd://plugin/<插件 id>/...` 链接唤起插件，第一次前会询问你。
  - 插件可以读取以前某一天的待办和笔记；在你刚操作过它之后，可以打开它自己的页面。
  - 修复插件宿主的多个问题：不读输入的插件不再卡住其他插件，撤销敏感权限后立即停止推送数据，市场不会把插件换成更旧的版本。
  - 插件开发：SDK 和脚手架 0.2.0。
- **待办**：修复在两个不同版本的岛屿之间切换时，待办被旧数据覆盖回去的问题。

## About this release

The final release of 0.3.1, with everything from its three betas and the changes since. Install over your current version. Todos, notes, settings and connected mailboxes are kept. The installers are not code-signed; if Windows SmartScreen shows "Unknown publisher", choose "More info → Run anyway".

## What's New

- **Agent page**:
  - A redesigned session list: sessions sit straight on the island instead of in cards. Working sessions show their latest reply and finished ones fold to one line. Each row starts with a status dot and ends with its host icon; only waiting, failed and stale sessions spell out their state.
  - Clicking a session brings its window forward, in any terminal or editor; in Orca it also switches to the session's terminal tab, including sessions that were already open. The window is still found after /clear or /resume. Click "Install / repair" once under Settings → AI Agent first.
  - Each session shows where it runs (Orca, Windows Terminal, VS Code, Codex, ...) with that program's icon; sessions in a worktree are named after their project.
  - Settings → AI Agent adds: how far back the list goes (1/2/6/24 hours), showing Claude Code and Codex separately, only sessions in progress, the running time (off by default) and the model, and how the session host is shown.
- **Updates**: a new Updates page in Settings.
  - Choose the Stable or Beta channel. Beta users still get every final release, and switching back to Stable never downgrades.
  - Checks 20 seconds after start and every 6 hours after that (can be turned off). A new version shows a reminder on the island, collapsed too, and a version can be skipped.
- **Settings**:
  - Settings → General → Backup and restore: export your settings to a file and restore them after reinstalling or on another computer. Todos, window positions and passwords are never in a backup.
  - Settings → General → Expand and tuck: hovering a tucked island can open its panel directly.
  - QQ, WeChat and Mail each have a page in the sidebar's Messages group.
  - New installs start with a tidied set of appearance defaults, which "Reset appearance" also restores. Saved settings are unchanged.
  - The system tooltips that popped up on hover are gone.
- **Mail**:
  - Not just QQ Mail any more: 163, 126 and most school and company mailboxes can connect, up to 5 at once, each in its own tab. The IMAP server field accepts a port.
  - Write and reply to mail from the island, see attachments and save them to Downloads, and mark a message read while reading it.
  - Disconnecting a mailbox asks first, and a crashed background connection restarts on its own.
- **Translation**: the translation window shows the service and model in use, and requests wait up to 30 seconds for slower self-hosted gateways and relays.
- **Plugins**:
  - The plugin market now reads the new index repository [focusd-plugins](https://github.com/TixXin/focusd-plugins), where outside authors can submit plugins. The market page is laid out anew: installable plugins first, installed ones below, one action button per plugin, and Official / Verified publisher marks; details show the README and version history.
  - Packages can carry an author signature, and updates must come from the same author. Each plugin can opt in to its pre-release versions.
  - Settings → Shortcuts has a "Plugin shortcuts" section to change or turn off a plugin command's shortcut, or give one to a command that has none.
  - Plugins can ask for permissions when they need them; the island asks you, and the answer can be revoked on the plugin's settings page. A plugin's settings page has a "Calls" list of the APIs it called and how each ended, without any of the data.
  - Plugin cards show only the plugin's own memory, and each plugin can have a memory limit.
  - Web pages and other apps can open a plugin with a `focusd://plugin/<plugin id>/...` link; the island asks you the first time.
  - Plugins can read the todos and notes of earlier days, and can open their own page right after you used them.
  - Fixes in the plugin host: a plugin that does not read its input no longer stalls the others, revoking a sensitive permission stops its data at once, and the market never swaps a plugin for an older version.
  - For plugin authors: SDK and scaffold 0.2.0.
- **Todos**: switching between two different builds of the island no longer rolls the todos back to old data.
