# 设置窗口改版：参考分析与方案

> 2026-11-06。用户觉得设置窗口「UI 乱、布局乱、分类乱、没轻重」，第一步视觉调整（`f871eae`，卡片和字号层级）之后仍然「差点意思」，于是提供了 macOS 上一款同类刘海岛工具的全部设置页截图作为参考。截图放在本机 `E:\Projects\design-refs\vibe-island-settings`，**不进仓库**。
>
> 我们借鉴的是它的组织方法和控件规矩，不照搬它的界面、配色和文案。这些规矩大多是 macOS「系统设置」和 Windows 11「设置」共用的分组列表惯例，放在 Windows 上同样自然。

## 一、它为什么看起来清楚

### 1. 侧栏：彩色图标块和三层分组

- 每个分类前面是一个**彩色圆角方块图标**（灰色通用、青色集成、红色通知、紫色显示、绿色声音、粉色用量……）。扫一眼靠颜色定位，不用读字。
- 侧栏只有 11 项，分三组：常用的 6 项不加标题；「高级」组放快捷键、SSH 远程、实验室；以产品名为标题的一组只放「通行证、关于」。**常用的放前面，少用的单独成组，关于产品自身的放最后。**
- 菜单文字是常规字重，字号比较大，选中项只用浅灰底色标出来，没有强调色描边。
- 页面标题左边重复这一页的彩色图标，和侧栏呼应。

### 2. 分组列表：组标题在卡片外，行和行之间用细线分隔

这是整套界面最核心的规矩，每一页都一样：

```
系统                       ← 组标题：卡片外面，粗体，中等字号
┌──────────────────────────────────────┐
│ 登录时打开                     [开关] │  ← 行：标题常规字重
├──────────────────────────────────────┤  ← 行间细线，左右留边
│ App 语言                 跟随系统  ⌃⌄ │
└──────────────────────────────────────┘
这些设置不改变审批行为。      ← 组脚注：卡片下方，灰色小字（可选）
```

- **组标题在卡片外**，用粗体。卡片里没有标题，只有行。
- **一组通常只有 2～4 行**。组多一点、每组短一点，整页就不显得乱。
- 行与行之间用细线分开，每一行都是一个能看清边界的单元。
- 说明整组的话放在**卡片下面**的脚注里（例如「管理 Vibe Island 与每个 Agent 的连接方式。」「提示：右键点击会话卡片可把它的目录添加为过滤规则。」），不和某一行挤在一起。

### 3. 每一行的结构都一样

```
┌──────────────────────────────────────────┐
│ 标题（常规字重，白色）           [控件]  │
│ 说明（小一号，灰色，可以折行）           │
└──────────────────────────────────────────┘
```

- 标题和说明是一个整体，在左侧；控件在右侧，和标题对齐。
- 说明只有一句，讲**打开或关闭后会怎样**，比如「关闭后，仅在你手动点击『检查更新』时才查找新版本」。
- 行高宽松（约 56～64px），左右内边距一致。

### 4. 控件种类少，而且每种都有固定的样子

| 控件 | 样子 | 什么时候用 |
|---|---|---|
| 开关 | 打开时用唯一的强调色（蓝），关闭时是灰色 | 是 / 否 |
| 弹出选择 | 右侧只有「当前值 + ⌃⌄」，**没有输入框外框** | 3 个以上选项，例如语言、时长、显示器 |
| 滑块 | 第一行是标题，右边是**数值胶囊**（等宽字体，如 `0.00s`、`460pt`），改过的旁边有 ↺ 恢复默认；第二行是整行宽的滑块，带刻度点 | 连续数值 |
| 快捷键 | 键帽样式的小方块，`⌃` + `Y`，可以点 ✕ 清除 | 快捷键 |
| 多选 | 一行里放几个小勾选框，例如「窗口 ☑5 小时 ☑7 天及更长」 | 少量并列选项 |
| 行内操作 | 强调色文字链接，例如「添加 CLI 分支…」「预览」「添加预警线…」 | 次要操作 |
| 按钮 | 很少用。真正需要动作时才放一个实心小按钮，例如橙色「安装」 | 主要动作 |

几条细节：

- 默认值直接写在选项里：「2 小时（默认）」。
- 状态用图标加文字：绿色 ✓「已安装」，旁边是红色文字「卸载」。
- 危险操作单独成行，用红色文字放在页面最底部（关于页的「移除所有自动配置」「退出」）。

### 5. 字重只有两档

页面标题和组标题用粗体，其余全部是常规字重，层级靠**字号和灰度**区分：

| 层级 | 大约字号（换算成网页 px） | 字重 | 颜色 |
|---|---|---|---|
| 页面标题 | 22 | 粗 | 白 |
| 组标题 | 15 | 粗 | 白 |
| 行标题 | 15 | 常规 | 白 |
| 行说明、组脚注 | 13 | 常规 | 灰 |
| 取值（弹出选择、数值胶囊） | 15 | 常规 | 浅灰 |

### 6. 让用户直接看到效果

- 「显示」页最上面是一张**预览图**：桌面壁纸上画着当前样式的刘海岛。下面「简洁 / 详细」是两张**带缩略图的可选卡片**，不是分段按钮。
- 会话卡片的一排开关下面，跟着一张**实时预览**的会话卡片，开关一拨就能看到哪里变了。
- 声音页每一行右边有 ▶ 试听；用量页的提醒有「预览」。

### 7. 按「用户想做什么」分组，不按代码模块分组

- 「通用」页分成：系统、展开、显隐、收起、交互。每组名字就是一个用户意图，没有「行为」「其他」这类杂项组。
- 能用一句说明讲清楚的，就不再多放一个设置项。比如「空闲时自动隐藏」只有一个开关，说明里写「没有 Agent 工作满 30 秒后隐藏」，时长不单独做成设置。
- 少用的高级内容折叠起来（SSH 页的「› Docker 容器」「› 手动安装」），或者放进「实验室」页（测试版更新、兜底重启、各家 CLI 的特殊开关）。
- 页面开头可以有一张说明卡，用两句话讲清这一页是干什么的、怎么开始（SSH 页）。

### 8. 关于页

居中的应用图标、名称、版本号，下面是三组列表：

1. 检查更新、更新日志（右侧显示版本号 ›）、自动检查更新、自动安装更新；
2. 外部链接，每行左边一个线条图标，右边是值加 ↗（官网、隐私、开发者、社区、报告 Bug、反馈邮箱）；
3. 诊断报告、致谢，最底下是红色的危险操作。

## 二、对照我们现在的设置窗口

| 规矩 | 参考软件 | 我们（`f871eae` 之后） | 差距 |
|---|---|---|---|
| 侧栏 | 彩色图标块，11 项，按常用 / 高级 / 产品分组 | 线条图标，16 项，基础 / 功能 / 消息 / 扩展 | 不好扫；项太多；插件两项、消息三项可以合并 |
| 组标题 | 卡片外，粗体 | 卡片里，小号灰字 | 第一步把标题做得太弱，组和组的界线反而不明显 |
| 行间分隔 | 有细线 | 没有 | 一组里多行时分不清边界 |
| 行说明 | 在标题下面，和标题是一个整体 | 在整行下面另起一段，跨满整行宽度 | 看不出说明属于哪一行 |
| 组说明 | 卡片下方的脚注 | 混在卡片里 | 同上 |
| 每组行数 | 2～4 行 | 「展开与收起」10 行 | 要拆 |
| 下拉框 | 当前值 + ⌃⌄，没有外框 | 带外框的输入框式下拉 | 太重 |
| 滑块 | 标题和数值胶囊一行、滑块整行，带 ↺ | 左标题、中滑块、右数值（第一步改的） | 我们的滑块太短，数值没有胶囊，也不能一键恢复默认 |
| 开关颜色 | 唯一强调色 | 绿色，和主强调色（青蓝）不一致 | 统一成一个强调色 |
| 按钮 | 很少，次要操作用文字链接 | 胶囊按钮很多（复位、保存当前、立即检查、前往快捷键……） | 很多可以改成文字链接 |
| 预览 | 外观改动当场能看到 | 外观页只有一排排滑块和色块 | 外观页最缺这个 |
| 高级 / 实验性内容 | 折叠或放进实验室 | 插件开发者模式、更新通道、游戏模式都和常用设置放在一起 | 要分层 |
| 关于页 | 图标、版本、三组列表、危险操作 | 结构接近，但「更新」是单独一页 | 可以把更新并进关于，或者保留但改成同样的列表 |

## 三、改版方案

### 1. 先做一套设置专用组件（`src/windows/settings/` 下）

把规矩写进组件里，以后每一页都只能这样写，不会再各写各的：

- `SettingsGroup`：`title`（卡片外粗体）、`footer`（卡片下灰色脚注）、子元素是若干行，行间自动加细线。
- `SettingsRow`：`title`、`description`（可选，标题下灰字）、右侧 `control`。需要时 `indent` 表示挂在上一行开关下面的子项，父开关关闭时不渲染。
- 现有控件在设置窗口里的样子改成上表那样：
  - 开关：用 `--color-accent` 一个颜色。
  - 下拉：改成「值 + ⌃⌄」的无框弹出按钮，复用 `SelectControl` 的菜单部分。
  - 滑块：标题和数值胶囊一行，滑块整行宽，加刻度点；数值和默认值不同时显示 ↺。
  - 快捷键：键帽样式。
  - 次要操作：新增一种强调色文字链接按钮。

组件放在设置窗口目录里，岛屿上的插件表单不受影响。

### 2. 再按新组件逐页迁移，顺便调整结构

每迁一页就是一次「结构 + 视觉」一起改，按用户使用频率排序：

1. **通用**：系统（开机自启、语言）→ 展开（展开方式、悬停延迟、移开后收回）→ 贴边隐藏（自动贴边、闲置时长、靠近时只露出岛屿还是直接展开面板、移开后再次隐藏、有新消息时露出）→ 全屏与游戏 → 位置 → 备份与恢复。时间统一用秒；「收起」只表示从展开态回到折叠态，贴到屏幕边缘统一叫「贴边隐藏」。
2. **外观**：最上面放一张**岛屿预览**（按当前设置画出折叠态和展开态的岛，改什么都能马上看到）；「经典 / 液态玻璃」「默认 / 像素字体」改成带缩略图的可选卡片；颜色、尺寸各成一组；样式预设移到页面最下面。
3. **AI Agent、待办、翻译、剪贴板、文件中转、音乐**：套用新组件，每组控制在 2～4 行。「功能开关」不再单独占一组，放在每页第一组的第一行。
4. **消息**：QQ、微信、邮箱合成一个「消息」页，三组分别是 QQ、微信、邮箱（邮箱账号是组里的行，「添加邮箱」是组底部的文字链接）。
5. **插件**：「插件扩展」和「插件市场」合成「插件」一页，顶部用「已安装 / 市场」两个标签切换；「开发者」放到最下面，默认折叠。
6. **快捷键**：标签下面那行重复的组合键去掉，右侧只留键帽。
7. **关于**：把「更新」页并进来，做成「检查更新 / 更新内容 / 自动检查 / 更新通道」一组；链接一组；最底部是红色的「重置所有设置」「退出岛屿」（这两个是新功能，要单独确认）。

### 3. 侧栏

```
  通用
  外观
  快捷键
功能
  待办 · 音乐 · 翻译 · 剪贴板 · 文件中转 · AI Agent · 消息
扩展
  插件
fly-island
  关于
```

从 16 项减到 12 项，每项换成彩色圆角图标块（图标还是 lucide，放在有颜色的方块上）。

### 4. 不改的东西

- 所有设置的存储 key、数据格式和默认值都不变，页面的 `?page=` 分类值保留旧的写法并兼容跳转（例如 `qq`、`wechat`、`mail` 都打开「消息」页，`market` 打开插件页的市场标签）。
- 岛屿本体的样式不受影响。

## 五、实施顺序与验证

1. 组件和控件样式（不改页面结构），先用「通用」页试用，截图给用户看。
2. 用户认可后逐页迁移，每一页或每两三页一个提交，同步更新 `tests/regression/settings.tsx` 里的检查，`DESIGN.md` 的「设置窗口」一节随之改写。
3. 侧栏合并和分类改名放在最后，单独一个提交，带旧分类值的兼容跳转。

每一步都运行 `pnpm check`、`pnpm build`、`pnpm test:regression`，并用 `tests/regression/settings.html?page=<分类>` 截图逐页检查 820px 和 580px 两种宽度。
