# 本地重构 review

来源、改造范围和贡献署名见[架构说明](../architecture/local-refactor.md)。本次只创建本地 Git 提交，不推送、创建或合并远程 PR，也不发布新版本。

## 主要变化

- `src/windows/` 负责岛屿、设置和翻译窗口；`src/features/` 负责业务组件、状态、存储与 IPC；CSS 随组件归属。
- Rust 的窗口、系统、代理状态、媒体、消息与剪贴板分开；Win32 注册表读取、进程句柄访问集中封装。
- 设置从岛内长页面改成独立窗口，包含通用、外观、通知、集成、关于五类，外观可调贴顶圆角。
- 保留 v0.2.16 主线的默认经典外观和启动更新功能；更新待办不持久化、不导出、不跨日结转、不参与任务轮播。
- 主窗口持有唯一更新句柄，设置窗口重建时请求快照；重复检查与安装由主窗口串行接受。
- 托盘打开设置通过工作线程执行，窗口创建加锁防止同时创建两个窗口。只为设置窗口补充原生标题翻译权限。
- 增加安全存储边界、Ctrl+Space 修复、统一检查、文件大小检查和 Windows CI 定义。
