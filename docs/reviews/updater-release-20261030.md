# v0.2.12 签名与发布验证

日期：2026-10-30。基于合并 PR #22、#23 后的主线。

## 发布配置

- 维护者更新密钥在发布机本地生成，私钥带随机密码，目录仅授予当前用户访问。
- 解锁密码通过 Windows DPAPI 保存；受保护的独立本机备份包含原密钥及恢复密码，不纳入仓库或 Release。
- `pnpm release` 在没有显式 CI 密钥变量时自动读取本机凭据；显式指定密钥时不混用另一套本机密钥。
- 基础配置保持空公钥，发布覆盖配置内置公钥并开启签名产物；发布端点仍为正式 HTTPS 地址，没有测试应用标识或本地 HTTP 地址。
- Release 包括签名 EXE、签名 MSI、各自 `.sig`、`latest.json` 与 `SHA256SUMS.txt`。
- 清单提供 NSIS、MSI 分别对应的目标及通用 NSIS 回退入口。
- Release 先作为草稿上传，核对 GitHub 资产 SHA-256 与本地产物后再公开。标签明确指向发布提交，不覆盖同版本资产。

## 验证边界

隔离测试用的 0.2.11、0.2.12 签名包已构建。界面自动化被用户 Esc 中止，随后用户明确要求不再使用电脑操控，因此真实点击下载、安装和自动重启未完成，不据此宣称完整升级链路已经通过。本次继续采用非界面的构建、签名校验、篡改拒绝、上传文件一致性和线上清单检查。

测试配置与测试产物留在忽略的构建目录或临时目录，正式 Release 不包含它们。v0.2.11 及更早正式版需要手动安装 v0.2.12，才能启用后续应用内更新。
