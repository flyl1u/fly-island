# 日历

岛上的日历列出今天和明天的日程，会议快开始时在收起的小岛上倒计时，有会议链接时可以一键加入。代码在 `src-tauri/src/calendar/`（读取日历）和 `src/features/calendar/`（界面）。

## 日历从哪里来

在「设置 → 日历」里添加，两种方式：

| 方式 | 适用 | 需要填 |
|---|---|---|
| 账号密码（CalDAV） | 飞书、钉钉、企业微信、iCloud | 服务器地址、账号、密码 |
| 订阅链接（ICS） | Google 日历的私密地址、Outlook 发布的日历、其他公开的 .ics 链接 | 链接 |

各家在哪里生成账号和链接，设置页里有说明。几点：

- **Windows 自带的日历读不到。** 读取系统日历（`AppointmentStore`）要求应用有包标识；原来的「邮件和日历」应用已被新版 Outlook 取代，新版 Outlook 不往系统日历里写数据。
- **CalDAV 地址**可以是服务器（例如 `https://caldav.feishu.cn`），岛屿会自己找到账号下的所有日历（`current-user-principal` → `calendar-home-set` → 其中的日历，最多 20 个）；也可以直接填某个日历的地址。飞书的自动发现不完整，找不到时填日历本身的地址。
- **只认 https。** `webcal://` 会当作 `https://`；`http://` 的链接不接受，因为订阅链接本身就是读权限。
- 添加时会先读一次，读不到就不保存，并说明原因（地址不对、账号或密码不对、链接失效）。
- 苹果的服务器即使没被要求也会返回 gzip 压缩的内容，岛屿会先解压。

## 隐私

- 订阅链接和 CalDAV 密码存在 Windows 凭据管理器（服务名 `com.focusd.island.calendar`，账户名是日历的 id），和 QQ 邮箱授权码一样。设置页只显示网站和账号，不显示链接。
- `calendar-sources.json`（应用数据目录）只存类型、名称、CalDAV 地址、网站和账号。
- 没添加日历时不联网。添加后每 15 分钟读一次（`get_calendar_events`），打开日历页时立即重读；读到的日程只在内存里。
- 「显示会议标题」关掉后，收起的小岛只写「会议 · 10 分钟后」，共享屏幕时不会露出会议内容。

## 读取

- 只取今天零点到后天零点（本机时间）之间的日程。CalDAV 用 `REPORT calendar-query` 按这个时间段查；ICS 链接整份下载后在本地筛。
- iCalendar 解析在 `ics.rs`，只读标题、时间、地点、说明和 URL。时区按 `TZID` 识别：IANA 名称（包括写在路径末尾的）、Outlook 常用的 Windows 名称（如 `China Standard Time`），都不是时按本机时区；没有时区的时间按本机时间；只有日期的是全天日程。
- 重复日程用 `rrule` 展开，最多看 500 次。`UNTIL` 由岛屿自己处理（各家写的时区不统一，`rrule` 会拒绝），`EXDATE` 排除的不显示，`RECURRENCE-ID` 改期的那次用改过的时间，`STATUS:CANCELLED` 的不显示。
- 同一个日程出现在两个日历里（共享日历、加了两次）只显示一次。

## 会议链接

`meeting_link.rs` 依次在日程的 URL、地点、说明里找已知会议服务的加入链接（参考 MeetingBar 的做法），同一处有多个时取最长的：腾讯会议（`meeting.tencent.com/dm/`、`/p/`）、VooV、飞书和 Lark（`/j/`）、钉钉会议、Zoom（含 `zoom.com.cn`）、Teams、Google Meet、Webex。只认这些服务，所以岛屿不会打开邀请里的任意链接。

## 小岛上的显示

- **会前倒计时**：会议开始前 N 分钟（设置里选 5、10、15、30 分钟或不显示，默认 10）到开始后 5 分钟，收起的小岛用「标题 · 8 分钟后」代替待办和 Agent 标题；开始后写「已开始」。有会议链接时，右边有「加入」按钮。消息预览、设备提示、音量提示和翻译结果优先。全天日程和没有时长的日程不算会议。显示倒计时时点小岛打开日历页。
- **日历页**：添加了日历后，岛顶部多一个橙色圆点。页面分「今天」「明天」，每行写时间（全天日程写「全天」）、标题、地点和日历名。正在进行的高亮，已结束的变淡；有会议链接、还没结束的有「加入」按钮。有日历读不到时，页面顶部提示。
