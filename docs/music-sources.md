# 音乐来源发现与采纳

设置 → 音乐 → 播放器采纳与顺序，会列出已经发现过的播放器和音频应用。

- 同时读取 Windows SMTC 媒体会话与所有活动输出设备的 Core Audio 会话，包括分配到非默认声卡、耳机的应用。
- 软件至少建立过一次音频会话后才能被发现；这不是扫描所有已安装软件。已退出的软件保留在设置中，方便调整顺序和采纳状态。
- 每个来源可以独立关闭“采纳”。不采纳的来源仍保留在设置列表中，但不参与岛上的展示、播放控制或音频电平；选择保存在本机，并同步到其他窗口。
- 发现同一应用的 SMTC 与音频会话时合并，优先使用 SMTC 的歌名、封面、进度与播放控制。普通音频会话按可执行文件路径合并，覆盖多进程和多输出设备；不会把瞬时进程 ID 当作设置标识。
- 音频来源后来启用 SMTC、或 SMTC 暂时消失时，使用来源别名保留顺序和“不采纳”选择。
- 已采纳的来源优先选择正在播放的，再按设置顺序选择；没有播放时选择排在前面的可用来源。

## 控制能力

SMTC 来源使用应用报告的播放、暂停、上一首、下一首和跳转能力。普通音频来源仅能静音 / 恢复该应用的音频会话，**不会暂停播放进度**，不会显示虚构的歌曲、封面、歌词或时间线；不能切歌的按钮保持禁用。

所有来源被排除时，不发送全局媒体键。指定来源退出时也不会自动把控制命令发给另一个应用。播放器没有任何会话、且用户没有排除任何来源时，空状态保留原来的系统媒体键“继续播放”。

SMTC 服务不可用不影响 Core Audio 发现；一个设备、进程或会话不可读时跳过该项。独占音频、驱动直接输出、拒绝进程查询的受保护应用等仍可能无法识别。没有 SMTC 的应用无法通用取得真实歌名、封面、播放进度或暂停能力。
