# 收起态消息动画

本次为收起态内容切换的局部优化，沿用岛屿的配色、宽度与消息入口。

- 设计目标：让短暂到来的消息轻柔地接替待办或专注任务，结束后自然恢复。
- 按用户指定的 Apple 风格调整为小幅形变与阻尼弹簧：原内容以 200ms 微缩退出（前 100ms 内淡净），新内容以 560ms 弹簧收敛到位，垂直位移仅 3px。图标先进入，文字延后 100ms 跟随，避免新旧文字重叠；取消模糊，恢复时方向相反。岛屿外框不因消息改变大小。
- 消息独立使用 Windows 系统 UI 字体，13px、650 字重，QQ 好友名为 700；像素主题下消息仍使用系统字体。字号与字重区别于上一版继承像素字体的 12px、500 字重，保证提示清晰可读。
- 微信：现有微信图标 +「你收到了一条消息」。QQ：QQ 图标 + 好友名 + 消息。QQ 邮箱：邮箱图标 + 邮件主题摘要。好友名和消息分别省略，完整内容保留在无障碍标签中。
- 保留接收器原有预览时间（通常 5 秒），不新增消息队列。新到消息可以打断过渡；同一快照的重复渲染不会重播。更新较新的消息后，不再回放仍未过期的旧来源。
- 通知结束后恢复当前待办或专注标题，并保留隐藏收起态文字的设置。常驻标题继续使用用户选定的字体；展开、边缘收起时立即清除动画残留，托盘隐藏期间不展示新预览。
- 尊重「减少动态效果」，并在动画结束事件缺失时清理旧内容。

## 验证

```powershell
node --test tests/unit/message-preview.test.mjs tests/unit/qq-notification-timing.test.mjs
pnpm build
pnpm dev
```

打开 `http://localhost:1420/tests/regression/collapsed-message-animation.html?test=1`，运行真实 `IslandShell`、通知 Hook 和 Tauri 官方 IPC mock 的回归检查。覆盖三种来源、自动恢复、交错消息、动画打断、窄宽度、长内容、标题/像素字体、点击入口、展开/边缘收起/托盘隐藏与减少动态效果。检查应连续通过 3 次。

不带 `test` 参数可手动操作；`state=wechat`、`state=qq`、`state=qqMail` 可直达对应预览。测试页恢复自身修改过的存储偏好，不读取本机消息或调用原生应用。

本次只对该组件进行画面对比和交互自检，不做整页视觉重设计或独立评分。
