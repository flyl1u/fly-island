# 多语言界面 / Interface localization

在 **设置 → 语言** 中选择简体中文或 English。首次使用会优先匹配系统语言，不支持的语言回退到简体中文；手动选择保存在 `focusd-island-locale`，重启后保留，并同步到独立翻译窗口。

待办、每日笔记、自定义预设名和消息原文保持原样，已有数据使用的存储键不变。翻译字典覆盖 React 界面、辅助功能标签以及消息、邮件和快捷翻译面板。原生服务返回的错误信息继续原样显示。

新增语言：

1. 复制 `src/i18n/locales/en.ts`，按 `Translations` 类型翻译全部字段，包含带参数的函数。
2. 在 `src/i18n/types.ts` 的 `LocaleCode` 中添加语言代码，并在 `src/i18n/index.ts` 的 `TRANSLATIONS` 中注册字典。`localeLabel` 使用该语言自己的名称，`localeTag` 使用有效的 BCP-47 标签。
3. 运行 `pnpm build` 和 `pnpm test`。启动 `pnpm dev` 后，打开 `/tests/regression/i18n.html?test=1` 检查切换与数据兼容性；`/tests/regression/i18n.html` 可预览真实界面和跨窗口语言同步。

Select Simplified Chinese or English under **Settings → Language**. The first launch matches the system's preferred languages and falls back to Simplified Chinese. An explicit choice is stored in `focusd-island-locale`, survives restarts, and syncs to the separate translation window.

Tasks, daily notes, custom preset names, and message content stay as written. Existing data storage keys are unchanged. The typed dictionaries cover the React interface, accessibility labels, messages, mail, and quick translation. Errors returned by native services are displayed verbatim.

To add a language, copy `src/i18n/locales/en.ts`, translate every field and parameterized function in `Translations`, add its code to `LocaleCode`, and register it in `TRANSLATIONS`. Use a native language name for `localeLabel` and a valid BCP-47 tag for `localeTag`. Run the build and tests above, then use the browser fixture to check switching and data compatibility.
