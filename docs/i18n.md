# 多语言界面 / Interface localization

在 **设置 → 语言** 中选择简体中文或 English。首次使用会优先匹配系统语言，不支持的语言回退到简体中文；手动选择保存在 `focusd-island-locale`，重启后保留，并同步到独立翻译窗口。

待办、每日笔记、自定义预设名和消息原文保持原样，已有数据使用的存储键不变。翻译字典覆盖 React 界面、辅助功能标签以及消息、邮件和快捷翻译面板。原生服务返回的错误信息继续原样显示。

文案按分区存放在 `src/i18n/sections/` 下，设置页的文案在 `sections/settings/` 下再按页面拆分。每个分区文件里有该分区的类型和 `zhCN`、`en` 两份文案；`src/i18n/types.ts` 与 `src/i18n/locales/*.ts` 只把各分区汇总起来。

新增文案：只改对应的分区文件，类型、`zhCN`、`en` 三处一起加，类型检查会报出遗漏。

新增语言：

1. 在 `src/i18n/sections/` 下的每个分区文件（包括 `settings/` 子目录和 `settings/index.ts`）里，仿照 `en` 加一份该语言的导出（例如 `export const ja: CommonText = { ... }`），翻译全部字段，包含带参数的函数。
2. 复制 `src/i18n/locales/en.ts` 为新语言文件，把其中的 `.en` 引用改成新导出的名字，并修改 `localeLabel`（该语言自己的名称）和 `localeTag`（有效的 BCP-47 标签）。
3. 在 `src/i18n/types.ts` 的 `LocaleCode` 中添加语言代码，并在 `src/i18n/index.ts` 的 `TRANSLATIONS` 中注册字典。
4. 运行 `pnpm build` 和 `pnpm test`。启动 `pnpm dev` 后，打开 `/tests/regression/i18n.html?test=1` 检查切换与数据兼容性；`/tests/regression/i18n.html` 可预览真实界面和跨窗口语言同步。

Select Simplified Chinese or English under **Settings → Language**. The first launch matches the system's preferred languages and falls back to Simplified Chinese. An explicit choice is stored in `focusd-island-locale`, survives restarts, and syncs to the separate translation window.

Tasks, daily notes, custom preset names, and message content stay as written. Existing data storage keys are unchanged. The typed dictionaries cover the React interface, accessibility labels, messages, mail, and quick translation. Errors returned by native services are displayed verbatim.

Copy lives in per-section files under `src/i18n/sections/` (settings pages are split further under `sections/settings/`). Each section file holds the section's type plus its `zhCN` and `en` copy; `src/i18n/types.ts` and `src/i18n/locales/*.ts` only compose the sections. To add a string, edit that one section file — type, `zhCN` and `en` together — and the type check reports anything missing.

To add a language, add an export for it next to `en` in every section file (including `settings/` and `settings/index.ts`), translating every field and parameterized function. Then copy `src/i18n/locales/en.ts`, point its `.en` references at the new exports, set `localeLabel` to the language's native name and `localeTag` to a valid BCP-47 tag, add the code to `LocaleCode`, and register it in `TRANSLATIONS`. Run the build and tests above, then use the browser fixture to check switching and data compatibility.
