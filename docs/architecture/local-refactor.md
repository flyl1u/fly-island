# 本地模块化改造

基于主线 `f9a22b6`（v0.2.16），分批拆分原生服务、前端功能和窗口。主线的启动下载更新、待办安装提示以及新用户默认经典外观必须保留；不改变现有数据 key、命令参数和更新端点。

## 来源与署名

架构方案及部分模块搬迁实现来自 [@TixXin](https://github.com/TixXin) 的 [PR #36](https://github.com/flyl1u/fly-island/pull/36)，参考快照为 `c5729d38013df9a4f55dd5e78dc6198c77067629`。本地按当前主线适配、补充回归和修复，不合并该 PR 的历史。

复用实现的提交保留 `Co-authored-by: tixxin <tixxin@qq.com>`，作者信息取自原提交。项目 MIT 许可保持不变。

## 分批范围

1. 原生服务：岛屿窗口、媒体、消息、剪贴板、代理状态、系统功能分开；Win32 注册表读取与进程句柄查询集中封装。托盘入口保持原有功能。
2. 前端领域：组件、状态、存储、IPC 和样式按功能归属；保留主线自动更新与待办的数据边界。
3. 设置窗口与检查：五类设置、跨窗口同步、统一更新任务所有权、自动检查和 Windows CI；验证窗口关闭重开与托盘入口。

## 验证记录

- 改造前：48 项 Node 测试通过，`pnpm build` 通过。
- 原生拆分：`cargo test --manifest-path src-tauri/Cargo.toml`（69 通过、5 忽略）、`pnpm tauri build --no-bundle` 通过。微信探测示例已适配共享 Win32 模块。
- 前端整合：领域组件、状态、IPC、存储与样式分离；新增五类独立设置窗口。主窗口持有唯一的更新任务，设置窗口通过事件获取快照和发送操作；托盘通过后台任务打开窗口，创建操作串行化。
- 主线兼容：新用户默认经典外观；更新待办不写入 localStorage、Markdown 或归档，也不参与任务轮播。关闭重建设置窗口及重复检查/安装由独立上下文测试覆盖。
- 自动化桌面交互在用户按 Esc 后停止，未将窗口、托盘、热键、QQ/微信实机行为记作验收通过；留给本地 review。
- 最终主仓库 `pnpm check`（104 项测试）、`cargo test`（69 通过、5 忽略）和 `pnpm tauri build --no-bundle` 均通过；桌面快捷方式已指向并核对主仓库产物。详细结果与人工检查表见[本地 review](../reviews/local-refactor-20261104.md)。

## 按用户要求恢复原外观

初版重构带入的贴顶反向圆角、自动吸附和圆角滑块已撤回，恢复 `f9a22b6` 的岛屿形状、拖拽落点与鼠标命中边界。保存的颜色、透明度、字体、缩放与预设继续沿用；仅忽略新增的 `topFilletRadius` 字段。模块化结构、设置分类与更新修复保留。

恢复后：104 项前端测试、66 项 Rust 测试通过（5 忽略；已移除新增吸附功能对应的 3 项测试），消息动画 24 项与多语言 17 项通过，release 构建通过。16 种状态下的 1,056 项计算样式与重构前实际构建的 CSS 一致。
- 后续各批的验证结果在提交说明和最终验收记录中列出。
