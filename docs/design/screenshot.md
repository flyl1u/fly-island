# 截图与截图翻译

截图覆盖层保留现有框选与标注交互。截图结束必须恢复小岛之前的显示状态；用户原本从托盘隐藏的小岛不得被截图取消动作重新显示。

翻译展示采用原图和双语文字并排、窄窗口上下排列，支持仅双语文字或仅原图。每段先显示原文，再显示译文，统一正常字号，长句自动换行，后续段落自然下移。原图独立显示，译文不覆盖图像。支持复制译文与原文/译文对照。（2026-11-26 用户反馈：原图覆盖译文会遮挡，不再需要保留格式）

识别文字也按阅读顺序逐行显示，不还原列、缩进和图像字号；同一行的片段合并成普通文字。默认 16px，可调整阅读字号，原图缩放不缩小文字。编辑或改变窗口宽度后，文字行自动增高，并预留滚动条位置，避免测量时宽度变化导致末行被裁切。保留原图定位和纯文本复制。（2026-11-26 用户要求）

翻译请求和设置复用 Fly Island；窗口提供本次翻译方向的调整，不覆盖全局默认设置。失败在对应行显示，可修正 OCR 原文后重试；不把网络错误当成空译文吞掉。关闭窗口后丢弃迟到结果并停止派发排队请求。

结果窗口使用 `tokens.css` 的表面、文字、系统字体与深浅色主题。图标使用 lucide，文案集中在截图 i18n 分区。

## 图形的绘后编辑

- 方框、椭圆支持「填充」复选框：勾选用当前颜色填满，取消后恢复线框。选中旧图形时控件读取、修改它的实际属性；未选中时改变下一次绘制的默认值。
- 在任意标注工具下点击已有图形的线条或已填充的内部即可选中；空心图形的内部留给继续绘图，重叠对象优先选择最上层。方框、椭圆和马赛克提供八个缩放控制点，箭头保留端点，拖动图形本身可移动。
- 选中线条类图形后，普通滚轮直接改变线宽，不改变图形尺寸；工具栏的形状、填充、颜色、线型和线宽也作用于当前对象。文字、序号和马赛克继续支持选中后修改对应属性。
- Del 删除当前选中图形；操作填充复选框或线宽滑块后仍可直接按 Del。文件名、文字编辑和 OCR 输入框中的删除键保持文本编辑行为。

## 截图触发、箭头与色板

- 按截图快捷键进入后立即整屏变灰；未框选时也必须显示遮罩。选区确定后内部恢复清晰，外部继续变灰；遮罩只用于界面，不进入导出图片。
- 覆盖层采用光标所在显示器的无边框全屏模式，覆盖任务栏区域。Ctrl+A 明确选择整屏，桌面空白处点击也可选择整屏；拖选接近屏幕边缘时吸附到精确边界，包含最后一行和最后一列像素。
- 箭头正文悬停显示移动光标，拖动时显示抓取光标；圆形端点显示与当前方向对应的标准缩放光标，并提示“调整长度和方向”。矩形/椭圆控制点使用对应方向的缩放光标。
- 箭头属性以带文字的下拉框提供单箭头、双箭头和无箭头（直线）；既支持绘制前选择，也支持选中旧箭头后修改，保留位置、颜色、线宽和线型。旧箭头默认为单箭头。
- 填充复选框必须带清晰可读的文字，不依赖文档主题的浅色字色。所有工具的色板使用方形色块和足够间距，选中框不得遮住相邻色块；属性行可换行，工具栏高度随内容重新测量。

## 跨显示器与自定义缩放

坐标来自每次抓屏的实际原生矩形与当前 WebView 视口，横纵比例分别计算，不假定等比例取整，也不写死主屏分辨率。尺寸标签显示物理像素。截图前等待原生 DPI、WebView DPR 和视口布局一致，避免切换显示器时沿用旧比例；等待失败时明确提示重试，不能静默导出错位图片。放大镜、窗口吸附、标注画布、马赛克和导出都使用对应轴的比例。

工具栏的属性和操作行均可换行，较小逻辑视口也应保持控件可达。缩放回归矩阵覆盖常见 100%–300%、110%/137%/163% 自定义值、笔记本/FHD/QHD/4K、竖屏及负坐标显示器。浏览器测试模拟原生整数像素与 CSS 取整，并在同一 WebView 中连续切换 DPI；真实多显示器的 Windows 窗口行为仍需实机验收。
