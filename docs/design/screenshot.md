# 截图与截图翻译

截图覆盖层保留现有框选与标注交互。截图结束必须恢复小岛之前的显示状态；用户原本从托盘隐藏的小岛不得被截图取消动作重新显示。

翻译展示参考 PixPin 的图文结果窗口：文本和图片并排，窄窗口上下排列；支持只显示文本、只显示图片，以及原图/译图切换。译图中的 OCR 行框以图片原始尺寸为基准，不使用桌面绝对坐标。长结果分别滚动并换行，文字可选中复制。

翻译请求和设置复用 Fly Island；窗口提供本次翻译方向的调整，不覆盖全局默认设置。失败在对应行显示，可修正 OCR 原文后重试；不把网络错误当成空译文吞掉。关闭窗口后丢弃迟到结果并停止派发排队请求。

结果窗口使用 `tokens.css` 的表面、文字、系统字体与深浅色主题。图标使用 lucide，文案集中在截图 i18n 分区。
