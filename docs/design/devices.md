# 设备页

2026-11-20，用户要求在设置和岛上分别提供独立设备页，电量查询和音频切换集中展示；改选设备后自动刷新。

岛上界面参考用户提供的 MyFinder Device Battery 项目的双列设备卡片：设备图标 / 名称、大号百分比、细进度条；底部固定音源分段按钮、当前输出和刷新 / 设备设置入口。卡片滚动，操作区保留在视野内。仅使用已有系统字体、lucide 图标和小岛语义颜色；明暗色与玻璃背景继承宿主。

未知百分比显示「未知」且不绘制进度条；估算显示约号，历史 / 待确认 / 充电状态分别标注。仅展示已有查询结果，不因参考图中存在 DPI、麦克风或音量控件而增加未实现的控制。

设备页随插件启用出现在岛上页面按钮中，支持拖动顺序、记住最后页面和 Ctrl + 滚轮导航；插件关闭时隐藏入口并回退至可用页面。岛收起或离开设备页即卸载该页查询。旧设备目录、开关和绑定保留；重复保存相同目录不清空绑定。

设置侧栏的「设备」页提供目录与启用、端点绑定、音源切换和电量列表。选择后自动保存 / 查询，保留原设备列表；音频五秒或获焦更新，电量六十秒更新，互不因绑定改变而重新启动。详见 [设备插件](../device-battery.md)。
