# 音乐页

全局方向见 [DESIGN.md](../../DESIGN.md)。

## 正在播放（2026-11-10 重做）

用户觉得上一版（左封面、右侧一栏、歌词垫在波形上的深色卡片）不好看。这一版从头设计，参照 Apple 灵动岛 / 正在播放、Spotify 迷你播放器和 Windows 11 媒体浮窗。（Agent 推断）

- **不再是一张卡片**：音乐页像 Agent 页一样直接画在岛上，没有卡片底色和描边，岛本身就是播放器。层级只靠字号、字重和留白。
- **结构（从上到下）**：歌曲（封面 + 歌名 + 歌手）→ 歌词（有歌词时）→ 进度条 → 播放控制。页面高度不变（岛 320px）。
- **没有歌词时**：封面 112px，歌名 20px / 600、最多两行（长名省略），歌手 14px，下面一行灰色的"专辑 · 播放器"；中文歌只查了 LRCLIB 没找到时，这一行换成强调色文字链接"没找到歌词 · 试试酷狗和网易云"（点开设置 → 音乐）。
- **有歌词时**：封面缩到 52px，歌名和歌手各一行（15 / 13px），把位置让给歌词；封面大小和圆角在 360ms 内过渡。歌词三行、居中（2026-11-10 用户反馈：靠左时整页明显不对称），和进度条、播放控制在同一条中线上，左右各留 60px 给快慢控件：当前句 18px / 600 最亮，上一句和下一句 13px 灰色，上下边缘再淡出一些；换句时新句从下一句的位置上移 8px 淡入。逐字歌词照旧逐字点亮；有翻译时翻译代替下一句。这首歌的快慢（− 0s +）只在鼠标移到歌词上或用键盘进入时出现在歌词右上角。
- **封面**：圆角 16px（小封面 12px），柔和方圆；下面垫一层模糊放大的封面当阴影，带出这首歌的颜色（播放时 .55，暂停时 .3），不再整张铺底。暂停时封面缩到 94%，播放时回到 100%（同 Apple Music）。没有封面时是深色渐变方块和音符。
- **强调色**：从封面取平均色（饱和的像素权重更高），调到在黑底上读得清的亮度（`features/media/artworkTint.ts`），用于进度条填充、右上角的跳动小条和歌词提示链接；没有封面时是柔白。
- **右上角**：四根跳动的小条（纯 CSS，播放时跳、暂停时落下，减少动画时静止），旁边是麦克风图标按钮"歌词设置"，打开设置 → 音乐。不用齿轮，因为岛的顶栏已经有设置齿轮。
- **进度条**：整行宽、4px，只读（Windows 媒体会话这里没有接跳转，所以不画拖动圆点）；下面左边是已播放时间，右边是剩余时间（"−3:26"），等宽数字。播放器不报告时长（如网易云）时，用歌词来源（LRCLIB、酷狗、网易云的搜索结果）给的歌曲时长；位置照旧由岛自己从看到这首歌起计时。两边都不知道时长时才不显示。（用户要求 2026-11-10：网易云下也要有进度条）缓存里没有时长的旧歌词会重新查一次。
- **播放控制**：三个不带底色的白色图标，播放 / 暂停更大（26px，48px 点击区），上一首、下一首 22px，间距 28px；悬停时出现浅色圆底，按下缩到 90%。不能切歌时按钮变淡。
- **没有在播放**（2026-11-10 重做，用户在真实应用里看过：原来的样子丑）：不再是"一个空播放器"——没有空封面、进度条和变灰的上一首 / 播放 / 下一首。页面中间一组：左边一张静止的黑胶唱片（92px，细纹、深色圆标、淡淡一道反光，纯 CSS，不转），右边"没有在播放"、一句"在任意播放器里放一首歌，就会出现在这里"，和一个安静的胶囊按钮"▶ 继续播放"（发送系统播放键，让上次用的播放器接着放；指向时提示这一点）。只用灰色：颜色留给歌曲封面。实现在 `MusicIdle.tsx`；检查页 `tests/regression/music-lyrics.html?view=idle`。
- 去掉了波形（`MediaWaveform`）：它和歌词抢位置，也是上一版显得杂乱的主要原因。收起岛上的音乐小条（`MusicWaveButton`）不变。
- 回归页 `tests/regression/music-lyrics.html` 检查以上各状态；`island-tour.html?media=playing|paused|nocover|long|nolyrics|none`（`&lyrics=0` 关闭在线歌词）可以在整个岛里看。
- **在线歌词默认打开**：设置 → 音乐里的"在线查找歌词"和其下的"酷狗和网易云"新装默认都开（用户要求 2026-11-10）；已经保存过关闭的照旧关闭。
