## 正在播放（2026-11-10 重做）

用户觉得上一版（左封面、右侧一栏、歌词垫在波形上的深色卡片）不好看。这一版从头设计，参照 Apple 灵动岛 / 正在播放、Spotify 迷你播放器和 Windows 11 媒体浮窗。（Agent 推断）

- **不再是一张卡片**：音乐页像 Agent 页一样直接画在岛上，没有卡片底色和描边，岛本身就是播放器。层级只靠字号、字重和留白。
- **结构（从上到下）**：歌曲（封面 + 歌名 + 歌手）→ 歌词（有歌词时）→ 进度条 → 播放控制。页面高度不变（岛 320px）。
- **没有歌词时**：封面 112px，歌名 20px / 600、最多两行（长名省略），歌手 14px，下面一行灰色的"专辑 · 播放器"；中文歌只查了 LRCLIB 没找到时，这一行换成强调色文字链接"没找到歌词 · 试试酷狗和网易云"（点开设置 → 音乐）。
- **有歌词时**：封面缩到 52px，歌名和歌手各一行（15 / 13px），把位置让给歌词；封面大小和圆角在 360ms 内过渡。歌词三行、居中（2026-11-10 用户反馈：靠左时整页明显不对称），和进度条、播放控制在同一条中线上，左右各留 60px 给快慢控件：当前句 18px / 600 最亮，上一句和下一句 13px 灰色，上下边缘再淡出一些；换句时新句从下一句的位置上移 8px 淡入。逐字歌词照旧逐字点亮；有翻译时翻译代替下一句。这首歌的快慢（− 0s +）只在鼠标移到歌词上或用键盘进入时出现在歌词右上角。
- **封面**：圆角 16px（小封面 12px），柔和方圆；下面垫一层模糊放大的封面当阴影，带出这首歌的颜色（播放时 .55，暂停时 .3），不再整张铺底。暂停时封面缩到 94%，播放时回到 100%（同 Apple Music）。没有封面时是深色渐变方块和音符。
- **强调色**：从封面取平均色（饱和的像素权重更高），调到在黑底上读得清的亮度（`features/media/artworkTint.ts`），用于右上角的跳动小条和歌词提示链接；没有封面时是柔白。进度条不再跟封面变色（2026-11-11 用户反馈：绿色进度条很怪），用岛上普通的前景灰白 `--text-2`，和播放控制一致。
- **右上角**：四根跳动的小条（纯 CSS，播放时跳、暂停时落下，减少动画时静止），旁边是麦克风图标按钮"歌词设置"，打开设置 → 音乐。不用齿轮，因为岛的顶栏已经有设置齿轮。
- **进度条**：整行宽、4px；下面左边是已播放时间，右边是剩余时间（"−3:26"），等宽数字。播放器不报告时长（如网易云）时，用歌词来源（LRCLIB、酷狗、网易云的搜索结果）给的歌曲时长；位置照旧由岛自己从看到这首歌起计时。两边都不知道时长时才不显示。（用户要求 2026-11-10：网易云下也要有进度条）缓存里没有时长的旧歌词会重新查一次。
  - **拖动跳转**（用户要求 2026-11-11）：播放器允许外部跳转（媒体会话的 `IsPlaybackPositionEnabled`）并且自己报告时长时，进度条可以点、可以拖。指向时条变粗到 6px、填充变亮、末端出现 10px 的白色圆点，光标变手形；拖动时时间和填充直接跟着指针走（不带过渡），松手才发一次跳转（`media_seek` → `TryChangePlaybackPositionAsync`），岛上马上显示新位置，不等播放器回报。键盘：方向键前后 5 秒，Home / End 到头尾。点击区上下各多 6px，不占布局。
  - 播放器不让跳转、或时长是借歌词来源的（网易云不装插件）时，进度条保持只读：没有手形光标、不变粗、没有圆点。
- **播放位置怎么算**（用户反馈 2026-11-11：在播放器里拖了进度，岛上的歌词还照旧往下走）：
  - 媒体会话的时间线是一份"快照"：`Position` 是 `LastUpdatedTime` 那一刻的位置，播放器想推才推（Spotify、浏览器每次跳转 / 暂停 / 继续都推，有的只在换歌时推一次）。所以位置 = 快照位置 + 从 `LastUpdatedTime` 起过去的时间 × 播放速度，而不是从岛读到它时算起（`media_control/timeline.rs`）。
  - 没有新快照时，暂停就停在暂停那一刻推算出的位置，继续播放从那里接着走，不会把暂停的时长也算进去；时间戳缺失、是 0、在未来、或比整首歌还旧时，当作"现在"取的；位置变了但时间戳没变的播放器，也当作现在取的。从岛上跳转后，播放器不推新快照也按跳转的位置走。
  - 后台线程订阅每个会话的 `TimelinePropertiesChanged`、`PlaybackInfoChanged`、`MediaPropertiesChanged`（以及会话增减），一有变化就发 `media-session-changed`，岛立即重读，播放器里一拖，歌词马上跳过去；1.5 秒的轮询照旧兜底（有的播放器不发事件）。音乐关掉、岛不再读状态 10 秒后线程自己退出。
  - 前端只在新读数和岛自己推算的位置差 300ms 以上（跳转、暂停、校正）或换歌、换播放状态时才重新定锚（`features/media/positionAnchor.ts`），否则保留原来的锚点：不再每次轮询都让整页重渲染、让逐字歌词重启。差 1.5 秒以上算跳变，进度条填充直接跳过去，不滑过去。
  - 已知做不到的：**网易云音乐**自带的 SMTC 不给时间线（位置和时长都是 0），岛只能自己从看到这首歌起计时，在网易云里拖进度岛上不会跟；装 InfLink-rs 插件后有完整时间线。**酷狗**、AIMP、foobar2000（不装插件）同样没有时间线；旧版 **QQ 音乐**（21.10.2962 之前）也没有。这些情况下不假装知道位置。
- **播放控制**：三个不带底色的白色图标，播放 / 暂停更大（26px，48px 点击区），上一首、下一首 22px，间距 28px；悬停时出现浅色圆底，按下缩到 90%。不能切歌时按钮变淡。
- **没有在播放**（2026-11-10 重做，用户在真实应用里看过：原来的样子丑）：不再是"一个空播放器"——没有空封面、进度条和变灰的上一首 / 播放 / 下一首。页面中间一组：左边一张静止的黑胶唱片（92px，细纹、深色圆标、淡淡一道反光，纯 CSS，不转），右边"没有在播放"、一句"在任意播放器里放一首歌，就会出现在这里"，和一个安静的胶囊按钮"▶ 继续播放"（发送系统播放键，让上次用的播放器接着放；指向时提示这一点）。只用灰色：颜色留给歌曲封面。实现在 `MusicIdle.tsx`；检查页 `tests/regression/music-lyrics.html?view=idle`。
- 去掉了波形（`MediaWaveform`）：它和歌词抢位置，也是上一版显得杂乱的主要原因。收起岛上的音乐小条（`MusicWaveButton`）保留，颜色从薄荷绿改为普通前景灰白（`--text-2`，指向时 `--text-1`），播放时不再发绿光（2026-11-11 用户要求）。
- 回归页 `tests/regression/music-lyrics.html` 检查以上各状态；`island-tour.html?media=playing|paused|nocover|long|nolyrics|none`（`&lyrics=0` 关闭在线歌词）可以在整个岛里看。
- **设置 → 音乐 → 播放器顺序**下方一直有一行提示"不显示封面？请在播放器的设置里打开 SMTC（系统媒体控制）"：封面来自 Windows 媒体会话，播放器不开 SMTC 就不交出封面。（用户要求 2026-11-11）这行提示做成一条轻量的信息框（2026-11-11 用户反馈：不够显眼）：左边 info 图标，文字比普通说明亮一档（`--color-text-muted`），极淡的底色和细边框，不用强调色。
- **在线歌词默认打开**：设置 → 音乐里的"在线查找歌词"和其下的"酷狗和网易云"新装默认都开（用户要求 2026-11-10）；已经保存过关闭的照旧关闭。
- 网易云缺少时间线时，诊断卡片提供显式点击的一键启用、下载许可说明和进度 / 重试；设置中的播放器兼容性提供二次点击确认卸载，300px 下按钮换行。
