# AI Agent：会话标题与 Agent 页

全局方向见 [DESIGN.md](../../DESIGN.md)。

`release-features.json` 的插件开关关闭时，Agent 页不订阅插件宿主、不显示插件会话或额度，消息页与折叠岛同样没有插件入口或预览；内置来源照常显示，已保存的插件设置保持原样。（用户要求 2026-11-16）

Codex 会话兼容修复（2026-11-15）：纯思考与工具任务使用同一套运行灯、标题和完成提醒，不要求信任 hooks。桌面版的 `response_item.message(role=user)` 同样视为用户输入；显式完成时间变化可以触发两次轮询之间完成的任务，首次发现时只补最近 15 秒内的完成。仍需保持完成 6 秒，仍按用户提示去重并抑制后台任务；历史会话不在启动时集中提醒。未结束的 Codex turn 静默 30 分钟才变为 stale（客户端没有固定 heartbeat），正在等待用户时不按静默判为 stale；关闭记录和会话时间窗口仍生效。界面外观、额度环与设置均不变。

## AI Agent 会话标题

- 只有未退出且阶段为 `running` 或 `waiting` 的会话才占收起态文字位；没有这样的会话时退回待办、歌词或空闲文字。标题单行省略、不撑宽小岛。优先级：消息预览 > Agent 标题 > 待办。多个符合条件的会话只显示最近更新的一个；等待用户批准或回答时用红色等待灯，不计入蓝色运行数字。展开的 Agent 页和等待/完成/错误提醒照常显示。
- 标题优先用 Agent 自己生成的标题（Claude Code 的 `ai-title`、Codex 的 `session_index.jsonl`），没有时依次退回第一句提问、文件夹名。"AI Agent"设置页"小岛显示"中可关闭，默认开启。Claude Code / Codex 的标题与 Agent 页同源，直接读会话记录，不依赖钩子（用户确认：统一数据来源）；插件和本地接口上报的来源用各自上报的标题。设计与实测见 `docs/architecture/agent-session-title.md`。（Agent 推断，依据同类项目调研）
- 图标使用官网的 Claude、OpenAI 应用图标，16px 圆角 4px，与 QQ / 微信图标同尺寸。（Agent 推断）
- 小岛显示 Agent 标题时，点击（或悬停展开）打开岛上的 Agent 页，不直接跳终端。（用户确认）
- AI Agent 开启时，小岛最右侧的灰色收起圆点换成正在运行的会话数（蓝色数字），点击打开 Agent 页；没有运行中的会话时不显示。进程仍开着、转入等待或完成后仍有后台任务，本身都不算正在运行；展开列表中的后台任务标记保留。收起到边缘改由闲置自动收起或展开后的最小化按钮（最小化方式选"收起到边缘"）完成。AI Agent 关闭时保留原灰点。

## Agent 页

- DeepSeek Harness（DSH）桌面端作为第三个会话来源，沿用现有列表/卡片/紧凑布局、标题、状态灯、归档和提醒。提供方使用 DeepSeek 官方白鲸标识（浅色圆角底，与 Claude、Codex 的方块图标同规格），宿主优先使用本机可执行文件图标；点击只聚焦主窗口（未找到支持的外部具体会话路由）。支持官方源码宿主及 DataElement / anywhere-labs 社区桌面端，宿主文字明确显示所属程序；共享目录无法确认创建者时使用当前兼容宿主或通用 DSH，不把社区包标成官方。本地投影能判定运行、等待回答和结束，临时工具审批和准确失败原因不作推测。来源开关在“AI 会话 → 会话来源”，Claude Code、Codex、DSH 三个来源各有开关，默认开，关掉后该来源的会话、标题、声音、弹出、用量环和用量查询均不参与。（issue #51；限制详见 [DSH 接入说明](../deepseek-harness.md)）
- DSH 余额环排在 Claude/Codex 后，玫红色（2026-11-13 起，原青绿色让给 WorkBuddy），仍为 22px。DSH 是按量付费钱包，没有固定订阅额度分母：内外两圈都表示余额可用（2026-11-13 起；此前内圈表示存在赠送余额，多数账号没有赠送余额，内圈总是空的，用户要求内环也带颜色），赠送余额写在悬停卡片里；实心/空圈表达可用性，环旁显示带币种的余额，悬停/读屏解释语义、各币种充值与赠送余额及更新时间，不写百分比或重置时间。只提醒余额耗尽和恢复；首次读取、离线或失败不算余额耗尽。（issue #51）
- 插件市场 Agent（2026-11-18，用户要求「装了插件就相当于把源码改写了一遍」）：Cursor、Kimi Code、Hermes 装上后作为普通会话来源进入同一个列表，沿用卡片、状态灯、归档和提醒；Z Code 目前只有额度环。安装后「AI 会话 → 会话来源」末尾才出现各自的开关（默认开），关掉后会话和额度一起隐藏。Kimi Code、Z Code 装上并打开后，「额度环」里出现各自的复选框，和内置 Agent 一样可勾选；额度提醒也和 Claude、Codex 一样按 5 小时 / 7 天窗口弹出（2026-11-19，用户要求插件 Agent 对标原有 Agent）。安装时一并勾上它的额度环，所以老用户已保存的勾选不会把新来源挡掉。读取方式都是只读、不装钩子：Cursor 读 `%APPDATA%\Cursor\User\globalStorage\state.vscdb`（`composerHeaders` + `composerData` + 气泡），生成中为运行、有待批准操作为等待确认，Cursor 关闭时为已退出，点击切到该工作区的 Cursor 窗口；Kimi Code 读 `~/.kimi/sessions/*/*/wire.jsonl`（`TurnBegin`…`TurnEnd`，未答复的审批 / 提问为等待）；Hermes 读 `state.db` 的 `sessions` / `messages`。额度：Kimi Code 紫色环（5 小时 / 7 天，用 Kimi Code CLI 的登录查官网），Z Code 琥珀色环（编程套餐的窗口，没有套餐时用体验额度当内圈），两者都在 Rust 侧缓存 5 分钟。做不到的：Cursor 不说哪个对话在前台，所以 Cursor 在前台时只把最近改动的那个当作已看；Hermes / Kimi Code 的会话没有进程信息，不能判断是否已退出。
- Z Code 的「会话来源」开关下方提供 Coding Plan 平台和 API Key 设置。Key 使用密码输入，可显示 / 隐藏；保存后只返回掩码，支持清除。Key 优先于桌面版登录；设置页显示本次查询的认证、网络、HTTP 和额度格式状态。只在插件安装后显示设置。
- Antigravity 是插件市场里的可选来源（作者 lilipeng0615-cyber，默认未安装）。装上并打开后，桌面 App、CLI 和使用同一会话库格式的 IDE 版本共用 Agent 页的会话卡片、状态灯、归档、声音和弹窗。会话读取 `conversation_summaries.db` 和本地 `transcript.jsonl`，后者提供模型、推理强度、最近回复、当前工具、上下文用量和当前轮次的完成时间。点击桌面会话会切到已打开的 Antigravity 窗口（没开时不会启动），点击 CLI 会话通过 `agy --conversation` 恢复该对话。桌面版在前台时，最近更新的桌面会话计为已看。
  - 额度优先来自 Antigravity 本机语言服务器的 `RetrieveUserQuotaSummary`，上弧固定 5 小时，下弧固定每周；每个窗口取启用额度池中剩余比例最少的值。禁用桶不视为 100%，缺失值显示「暂无数据」。旧 `GetUserStatus` 模型余额和旧缓存不冒充时间窗口；接口暂时不可用时保留原有双窗口快照，时间不延长。安装、启用并勾选后仍常驻。
- 「AI 会话 → 额度环」提供 Claude、Codex、DSH、WorkBuddy 四个复选框，默认全选；Kimi Code、Z Code、Antigravity 装上插件后才出现各自的复选框，安装时一并勾上。Agent 页依次显示勾选且有数据的来源。额度行为空时收回其高度。会话、标题及原有提醒由「会话来源」控制。
- WorkBuddy 显示国内个人账号的积分。青绿色（2026-11-13 起，原 DSH 的颜色）上下两弧按同一个剩余比例填充，中央显示 WorkBuddy Logo；悬停及键盘聚焦只显示剩余积分，完整总额与更新时间保留在读屏名称中。零余额显示空环。登录入口在「会话来源」的 WorkBuddy 开关下方：一行状态加一个按钮（未登录/已过期时「去登录」，读不到时「重试」，已登录时「退出登录」），开关关闭时不显示。积分用完、恢复时各提醒一次（规则同 DSH 余额，跟随会话来源开关和额度提醒开关）。积分汇总沿用官网余额口径。 [WorkBuddy 用量说明](https://www.codebuddy.cn/docs/workbuddy/Usage)
