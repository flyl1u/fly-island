# AI Agent：会话标题与 Agent 页

全局方向见 [DESIGN.md](../../DESIGN.md)。

## AI Agent 会话标题

- Codex / Claude Code 运行时，小岛在待办位置显示"Agent 图标 + 会话标题"，标题单行省略、不撑宽小岛；完成后保留 3 秒再恢复待办，失败或可能中断时配黄灯继续显示。优先级：消息预览 > Agent 标题 > 待办。多个 Agent 同时运行时只显示最近有动静的一个。（用户确认：图标和标题）
- 标题优先用 Agent 自己生成的标题（Claude Code 的 `ai-title`、Codex 的 `session_index.jsonl`），没有时依次退回第一句提问、文件夹名。"AI Agent"设置页"小岛显示"中可关闭，默认开启。Claude Code / Codex 的标题与 Agent 页同源，直接读会话记录，不依赖钩子（用户确认：统一数据来源）；插件和本地接口上报的来源用各自上报的标题。设计与实测见 `docs/architecture/agent-session-title.md`。（Agent 推断，依据同类项目调研）
- 图标使用官网的 Claude、OpenAI 应用图标，16px 圆角 4px，与 QQ / 微信图标同尺寸。（Agent 推断）
- 小岛显示 Agent 标题时，点击（或悬停展开）打开岛上的 Agent 页，不直接跳终端。（用户确认）
- AI Agent 开启时，小岛最右侧的灰色收起圆点换成正在运行的会话数（蓝色数字，含可能中断的会话），点击打开 Agent 页；没有运行中的会话时不显示。收起到边缘改由闲置自动收起或展开后的最小化按钮（最小化方式选"收起到边缘"）完成。AI Agent 关闭时保留原灰点。（用户确认：灰点改成数字、去掉收起）

## Agent 页

- 岛屿展开后的 Agent 页列出最近 2 小时有动静的 Claude Code / Codex 会话，直接读两者的会话记录，不依赖钩子；正在运行的排前面，最多 12 个。agent 已经退出的会话默认不列出（「隐藏已退出的会话」，默认开）。（用户确认：最近 2 小时、默认隐藏已退出的会话）
- 每行：Agent 图标、"项目名 · 标题"、模型与推理强度（如"Opus 5.5 · Medium"）、状态灯与会话环同色（红"等待确认"或失败、黄"等你回复"、绿运行、半透明绿 10 分钟无动静、灰完成；没看过的完成会话灰点发亮；判断见 `sessionLight.ts`，roadmap B11）、最近一条回复（最多两行）、状态与多久前更新。项目名取会话开始时的文件夹。样式与文件中转页一致的深色面板。每行等高（没有回复摘要的行同样高，状态行贴底对齐），面板高度正好放下"设置 → AI Agent → 会话列表 → 展开后显示条数"设定的行数（2–5，默认 3，与剪贴板的显示条数同样做法，不随样式预设保存），更多会话滚动查看。（用户确认：参照剪贴板显示条数）
- 显示方式（设置 → AI Agent → 会话 → 会话卡片 → 显示方式，`agentSessionView`）：列表（默认，上面这种每行）、卡片、紧凑。卡片每个会话一张 62px、按状态灯颜色描边的卡片：第一行标题、权限模式、模型与推理强度、时间、运行位置和 Agent 图标；第二行状态（按灯色）、子 Agent、任务进度、后台任务、正在调用的工具或最新回复，右端是上下文 tokens。紧凑每个会话一行 34px：状态色条、标题、状态、时间和图标。归档、看过与没看过、找不到窗口的提示三种方式一样。参照 PR #5（Louis），在现有页面上重做。卡片光效（`agentCardEffects`，默认关，只对卡片和紧凑生效）：粒子流苏（边框按灯色发光，进行中和等你处理的呼吸，左侧飘一条粒子流苏）或渐变带（从右端铺一层灯色渐变，进行中和等你处理的更亮）；系统要求减少动画时静止。（用户确认 2026-11-07：列表仍默认，卡片作为可选）
- 归档动画（`agentArchiveMotion`）：滑出（默认，向右滑出再收起）或粒子消散（从左到右化成状态颜色的粒子，约 0.5 秒，再收起），三种显示方式都适用，撤销照旧展开回来；系统要求减少动画时直接移除。参照 PR #5 的消散，做成归档的可选效果，不另加 × 按钮。（用户确认 2026-11-07）
- "等待确认"：Claude Code 会话停在工具授权或 MCP 输入请求时显示，状态文字同为橙色；等待中的会话计入小岛上的会话数、小岛继续显示它的标题，不会因为等太久变成"可能已中断"。依赖 Claude Code 的 `Notification` 钩子（需要点"安装/修复"），Codex 没有对应钩子。（用户确认：采纳等待授权建议）
- 点击一行，把该会话所在的窗口切到前台：Windows Terminal 按窗口标题里的会话标题匹配，VS Code 类编辑器按标题中的项目文件夹匹配，Codex 会话最后退回 Codex 应用；最小化的窗口先恢复。能直接打开具体对话的宿主会打开那个对话：Claude 桌面版（`claude://code/continue?session=local_…`）、Codex 桌面版（`codex://threads/<id>`）、VS Code 类编辑器里的 Claude Code / Codex 扩展；终端里的会话切到它的标签页（Windows Terminal 按标题，标题对不上时按唯一含项目文件夹名的标签）。找不到时在该行提示"没找到对应的窗口"。（用户确认：简化版跳转；2026-11-10 用户要求点会话打开具体对话）
- 对齐与归档（B17，用户确认 2026-11-07）：会话圆点、额度环和每行最右的图标都对齐到岛屿 20px 的内边距，和顶部栏的状态灯、右上角按钮在同一条线上；只有悬停高亮往外多出 6px。每行在提供方图标右边有一个一直显示的归档图标，它就是这一行最右的元素，离岛屿边缘 20px，和右上角按钮对齐：平时很淡，鼠标在这一行上时变成普通的灰色，指上去变亮（不用红色，归档不是删除）。（用户确认：只在悬停时显示会在右侧空出一块，对不齐）点了以后这一行先向右滑出淡出、再收起高度，下面的行补上来，播完才离开列表（岛屿高度随行数变，所以之后才变矮）；左下角浮出「已归档 · 撤销」小胶囊（从左边滑入，5 秒后或撤销时滑出，不占列表位置），撤销时这一行反向展开回来。系统要求减少动画时直接出现和消失。
- 入口：展开后左上角的状态灯图标（点击进入 Agent 页，所在页时高亮）、小岛上的会话数、显示 Agent 标题时点击小岛。AI Agent 关闭时没有 Agent 页。（Agent 推断）
- 弹出提醒：会话开始、完成、出错或等待你确认 / 回答时，收起的岛屿（含贴边隐藏）自动展开到 Agent 页，只显示触发的那一个会话（不显示用量；完成或出错时显示 AI 最后的回复，去掉 Markdown 符号，最多 3 行，面板高度按这一行的实际高度），停留 5 秒（3–30 秒可选）后收起；鼠标停在岛上时不收起，在面板里点过就不再自动收起。会话窗口已在前台、游戏模式勿扰、或你正在用展开的岛屿时不弹。"设置 → AI Agent → 弹出提醒"里，会话开始可选每一轮开始 / 只在新会话开始 / 不弹（默认每一轮），其余三种事件各有开关，默认都开。没有单独的卡片，直接用只含这一个会话的 Agent 页，点这一行即跳到终端；点岛上别处（如 Agent 按钮）、切页或收起后，Agent 页回到完整列表。（用户确认：B6 第 1 期；弹出时只显示那一个会话为用户反馈）
- Agent 页顶部的用量是一行额度环（2026-11-10 用户要求，替换原来每个 Agent 一行的文字用量）：先 Claude（橙，Anthropic clay），再 Codex（蓝），各一对同心环，外圈 5 小时、内圈 7 天；和 Codex 自己的用量页一样显示**剩余**额度（2026-11-10 用户反馈「Codex 依旧是错的」后改：数值与 Codex 后端一致，只是 Codex 写的是剩余），环满表示还没用，环旁写两个剩余百分比（外圈的用该 Agent 的颜色）；没有数据的 Agent 不画环，都没有时这一行不出现。Codex 免费版只有 30 天窗口，画在内圈。悬停或键盘聚焦环时，卡片写各窗口剩余和已用多少、何时重置（含 Claude 各模型窗口）、图例、更新时间和来源；读屏读出同样的数字。已过重置时间的窗口不再显示旧数字。Claude 的数字来自 claude-hud 快照或 Claude 桌面版自己记录的用量历史（`plan-usage-history.json`，没有重置时间，所以 Claude 的卡片不写重置时间）。展开高度按这一行算，「显示几条会话」仍然准确。（B4）
- 没处理时再提醒（B6.4.1）：等你确认或回答的会话（打开回复状态标记时也包括回复末尾是 `↩` 的）过了设定时间还在等，就再弹一次卡片并再响一次（提问用「提问」音效，审批用「审批」音效）；每次等待只补一次，回答后再次等待会重新计时。设置 → AI Agent →「等待确认时」下面缩进的一行，可选 不再提醒 / 30 秒 / 1 分钟 / 2 分钟 / 5 分钟，默认 1 分钟。会话窗口在前台、游戏模式勿扰、关掉「等待确认时」时不补。（用户确认要做；默认值和选项为 Agent 推断）
- 隐藏会话（B6.4.3）：设置 → AI Agent →「隐藏会话」里按规则隐藏，规则是「所在目录」（含子目录）或「标题或提示词包含」，一条一行，右边 × 删除，最后一行选类型、输入、添加（回车也可以）。符合任一规则的会话在岛上完全不出现。和 Agent 页上逐个移除会话不同，规则一直生效，包括以后的新会话。（Agent 推断，待用户确认）
- 子 Agent 通知（B6.4.2）：主 Agent 一轮结束时，它在后台启动的子 Agent 或命令还在跑，就不弹「完成」、不响，会话保持绿色；后台任务结束、主 Agent 接着回复后再按平常提醒。不另设开关，和 B11 的后台命令处理相同。Agent Team 的分屏队友是独立会话，照常各自提醒。（Agent 推断）
- 只在任务完成和等你时响（2026-11-11 用户反馈「Agents 的音效老是在响」）：提示音只留完成、出错、等待审批 / 提问；压缩上下文、额度不足 / 额度重置默认不响（额度提醒仍会弹出）。一轮结束后要保持完成 6 秒才响「完成」，Agent 在这期间自己接着跑（后台任务的结果、排队的消息）就当作中间步骤不响；同一条提示词只响一次「完成」，Agent 自己接着跑完的后续几轮不再响，你发新的提示词后才重新计。
