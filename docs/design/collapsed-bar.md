## 内置插件与收起条槽位（2026-11-06）

- 用量环、会话环、中心图案都做成内置插件，在"插件扩展"里开关，不另设功能开关。（用户确认：插件形态）
- 用量环是同心双环：外环 5 小时、内环 7 天。（用户确认）会话环是一个分段环，每段一种会话状态，中心可写总数。（用户确认）
- 收起条有三个槽位，都空着时收起条与现在完全一样（Agent 推断，依据审阅报告）：
  - 中心槽位：只在没有消息预览、翻译、Agent 标题、待办和名称时显示，占摘要的位置，在状态灯与右侧元素之间的剩余空间居中；点它和点小岛一样。
  - 仪表槽位：放在最右侧元素（收起灰点或会话数）紧前面，和音乐、文件中转按钮同一行间距。
  - 会话槽位：AI Agent 开启时代替蓝色会话数；AI Agent 关闭时不显示，保留收起灰点。
  - 插件声明槽位要占的宽度（`centerWidth`、`sideWidth`），折叠岛按它变宽（最宽 340px），不挤压摘要。
- `MiniRing` 是纯 SVG 小环：同心环或单个分段环，12 点钟方向起顺时针，圆头，默认 20px、线宽 2.5、环距 1.5，底轨白 16%；中心标签用 `--text-1`、600、等宽数字；数值变化 320ms 缓出，减少动效时不动画。值为 0 的环只画底轨，不画弧。（Agent 推断，依据审阅报告）
- 用量双环（内置插件 `focusd.claude-usage`）：外环 5 小时、内环 7 天；常态 `#E5A385`，≥70% `#E5C890`，≥90% `#E78284`；数据超过 15 分钟或没有数据时整体变灰（`#8E8E93`），没有数据时只画底轨。数据与 Agent 页顶部的用量相同：Claude Code 经本机 magpie 网关时读 magpie 的用量，否则读 claude-hud 的用量快照（都不联网、不读凭据）；插件设置「直接向 Anthropic 查询」打开时（默认关），两者取较新的一份。直接查询失败但数据仍新鲜时环不变灰，卡片里加一行原因；卡片最后一行写更新时间和来源（claude-hud / Anthropic）。环是按钮，点击立即请求刷新并重读（原生端 60 秒内只放行一次）。（用户确认：配色与过期、直接查询可选且默认关、不直连；点击行为为 Agent 推断）
- 会话环（内置插件 `focusd.session-ring`，数据就是 Agent 页的会话列表，含 Codex）：AI Agent 开启时代替蓝色会话数，点击打开 Agent 页；AI Agent 关闭时不显示。段色：等你确认（等审批或等回答）`#FF453A`、等你回复（回合结束、最后的回复在问你：回复状态标记 ↩，没有标记时看最后一段是否问句）`#FFD60A`、运行 `#34C759`、可能已停（运行中但很久没动静）半透明绿、做完了（没看过的一直显示，看过的显示 10 分钟）`#8E8E93`；失败的会话在没看过或 10 分钟内算红色，按这个顺序从 12 点起排；中心写这些会话的总数，20px。没有要显示的会话时整个环不显示，退回蓝色数字。悬停卡片列出各状态计数和前三个等你处理的会话"状态：标题 · 项目"，标题超过 40 字截断。（配色与优先级为用户确认；数据来源改为岛屿自己的会话列表为维护者决定）
  - 打开设置 → AI Agent →「回复状态标记」（B9）后，已完成的会话按回复末尾的标记分：`↩` 等你回复为黄（看过也保持黄），`⋯` 等它自己的后台任务算运行（绿），`✓` 做完为灰（没看过的一直显示，看过的 10 分钟后不再计入）；没有标记的会话沿用“没看过算等你回复”。Agent 页里等你回复的会话在状态行写「等你回复」。提醒和音效同样细分：等你回复按「等你确认 / 回答」弹出（受那个开关控制）并用「提问」音效，等后台任务不弹不响，做完照旧是完成。标记符号自定，不沿用 claude-sessions 的符号与文字。（用户确认做成可选、默认关；符号与文案为 Agent 推断，待用户审阅）
- 悬停详情卡片 `IslandHoverCard`（`src/components/`，用量环、会话环、Agent 页顶部用量行共用；用量行的卡片出现在这一行正下方，只写直接查询失败的原因和「更新时间 · 来源」，和用量环卡片的最后几行一致）：不用原生 `title`。光标停在环上 200ms 后，在胶囊正下方居中出现；会被鼠标指针挡住时整张移到指针左边（左边放不下就移到右边），鼠标在触发区里移动时跟着避让，键盘聚焦（`:focus-visible`）时立即出现；移开、按下、失焦或原生端报告光标离开岛时消失。底色用岛的 `--island-background-color`，1px 白 8% 描边、圆角 12、阴影；文字 12px，数据行 `--text-1`，次要行 `--text-3`，行首可带 6px 色点（环的颜色）。卡片画在 `.stage` 里、岛外面，不接收鼠标，不在原生点击区域内，因此不挡穿透、不抢焦点；环是按钮，按现有规则停在上面不会悬停展开。进场 140ms 淡入下移 4px，减少动效时不动画。（用户确认：卡片形式与位置；样式细节为 Agent 推断）

## 折叠待办状态

- 没有已开始的任务时，默认显示“剩余 x 个待办”；设置中可单独关闭，开始任务后显示任务标题。（用户确认：本次请求）
- 数量只包含当前待办中的未完成项，包括 0；总文字开关仍控制全部折叠文字，消息预览继续优先显示。（Agent 推断）

## 折叠态中心图案

- 摘要为空时折叠岛中间显示一个图案：内置四款 SVG 动画（跟随光标的眼睛、小鸟、呼吸光点、小猫），或一只 Codex Pets 宠物（petdex 格式，读 `~/.codex/pets` 与应用数据目录 `pets/`，同名时应用数据目录优先）。不做任意单张图片导入。（用户确认）
- 图案 22px 高、最宽约 44px，白 / 浅灰为主，喙、脚、耳内少量暖色；只动 transform / opacity，循环 5–9 秒，岛展开、贴边收起和"减弱动态"时停住。眼睛跟随窗口外的光标靠原生端约 28Hz 的 `island-cursor-moved` 事件，只在眼睛显示时开启；4 秒没有光标变化就自己缓慢环视。（Agent 推断）
- 宠物按状态播放 petdex 的行：空闲 idle、运行 running、等待确认 waiting、失败 failed、完成 waving；帧数和循环时长照 petdex 渲染器的状态表。图集总是大幅缩小显示，用平滑采样（`image-rendering: auto`），像素风也不用 `pixelated`。v2 的 8×11 图集按前 9 行使用。（Agent 推断）
- 中心图案是内置插件"中心图案"（`focusd.center-pattern`，默认关闭），设置里选图案（眼睛 / 小鸟 / 光点 / 小猫 / 宠物）和宠物；宠物从本机找到的列表里选，不手填 id。（用户确认：插件形态）
- 选的是宠物时，折叠条显示 Agent 标题的那一刻，宠物（18px 高，约 16.6px 宽，与 16px 图标占位一致）跟随状态替换标题前的 Agent 图标；没有标题时照旧在中心显示。内置 SVG 图案只在没有摘要时出现。（Agent 推断，待用户确认）
- 折叠岛 38px 高：内置图案保持 22px，宠物放大到 28px。中心显示时折叠岛加宽（SVG 图案 44px、宠物 30px），避免被状态文字和右侧按钮挤掉。岛展开、贴边收起、全屏免打扰、窗口被托盘隐藏时暂停。宠物图集和读取失败都缓存，中心槽反复显隐不重新读取。宠物状态跟本应用读到的 Agent 会话：有等待确认演 waiting，有运行演 running，失败或可能中断演 failed，刚完成挥手约 3 秒后回 idle；宠物不存在或读不到时显示眼睛。（Agent 推断）
