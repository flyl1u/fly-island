## 外形（2026-11-10 重做，同日按用户反馈再改）

默认外形保持不变；贴顶时另提供可选的内凹贴边圆角，默认关闭。（用户要求 2026-11-13：11-10 去掉肩膀的决定改为可选，不恢复旧版常开的肩膀）

- **贴顶（默认）**：顶边与屏幕上沿齐平，底部两角圆角；两侧顶端是直角，不再有内凹的"肩"。（用户要求 2026-11-10：不要贴边圆角）
- **贴边圆角（可选）**位于外观 → 外形，默认关闭。大小为 4–20px，步长 0.5px，默认 10px，再乘当前岛屿缩放。开启后，仅贴顶且露出时显示。肩部与岛身由一条闭合路径裁剪，肩弧和底角共用圆弧或软方圆的曲线族。软方圆肩部按 1.4 倍换算尺寸，弧线同时与顶边和侧边相切。岛高不足时等比缩小肩弧和底角，保留曲线比例。
  - 经典材质的半透明填充和全高度渐变共用这条轮廓。玻璃沿用 3.2.8 的材质，肩部和岛身使用同一张窗口坐标系里的实时模糊画面、色调、磨砂和颗粒。没有帧时共用玻璃底色和颗粒。肩部用 `clip-path` 截去玻璃的岛身侧亮边，透镜光覆盖完整轮廓，玻璃层连续绘制。文字、交互、外部阴影独立于材质层。
  - 圆角随展开、收起和大小滑块过渡。肩部超出岛身的部分不可点击。旧 WebView 缺少单路径裁剪能力时使用平顶外形。常规 820px 舞台容纳两侧软方圆，展开最大约 739px，折叠最大约 750px。
- **离开顶边（拖到别处）**：岛浮起来，四角一样圆：收起时是胶囊，展开时四角都是展开态的半径。拖回顶边 16px 以内吸附并恢复贴顶外形。
- **胶囊外形（可选，暂未开放）**（用户要求 2026-11-18：很多用户想要苹果灵动岛那样的胶囊；同日要求先关闭，`CAPSULE_SHAPE_ENABLED = false`：设置里不显示，存档里的 `capsule` 按刘海读取，打开开关即上线）：外观 → 外形 →「岛屿外形」二选一，刘海（默认，即上面的贴顶外形）/ 胶囊。胶囊悬在工作区上沿下方 8px（`CAPSULE_TOP_GAP`，作为窗口的上边距交给 Rust），收起时是一颗完整的药丸：收起圆角固定为条高的一半、两端用圆弧，不受「收起圆角」「圆角形状」影响，所以选胶囊时隐藏「收起圆角」和「贴边圆角」；展开时四角都是展开圆角，和拖离顶边的岛一样。拖到顶边吸附后也保持药丸，不变成平顶。设置里的「重置位置」按钮只在真的拖动过时出现。四种收起方式沿用原逻辑：常驻（不自动贴边）一直是胶囊；细线时窗口上滑贴顶、药丸收成同一条短线，露出时窗口下滑 8px、短线长回药丸，三段为细线 → 胶囊 → 展开（点击模式悬停先回到胶囊、再点展开；悬停模式一步展开）；露边时窗口上滑，露出药丸的下沿；隐藏时直接滑走。设置项 `islandShape`（`notch` / `capsule`），代码在 `features/appearance/islandShape.ts`。
- **曲线：苹果的连续圆角**（用户要求 2026-11-10：上一版 superellipse(1.3) 不好看，改成 Apple 圆角）。苹果的圆角（Figma 里 60% 的 corner smoothing）在离角 1.6R 处就开始弯，和直边相接处没有"折"。CSS 用 `corner-shape: superellipse(1.6)` 配 1.4R 的 `border-radius` 来画，和苹果的曲线相差不到 R 的 1%（数值拟合得出，`features/appearance/cornerShape.ts`）。原生点击区域按 |x|ⁿ + |y|ⁿ ≤ rⁿ（n = 2^1.6）判断（`island/state.rs`）；上下圆角加起来超过高度时，和 CSS 一样按比例缩小（浮起的收起态因此是胶囊）。
- **半径**：相当于 30px 的苹果圆角，即展开态 `border-radius` 42px；收起态按 12 / 30 的比例为 16.8px（用户要求 2026-11-11：原来 22 / 30 时收起态就是一颗胶囊，太圆；Rust 的点击范围 `COLLAPSED_RADIUS` 同步改为 12）。收起 ↔ 展开时半径随宽高一起过渡（时长和曲线见下一条）。
- **展开、收起的动效**（2026-11-10，用户要求"优化岛屿展开丝滑度"）：宽、高、圆角用弹簧曲线（CSS `linear()` 采样阻尼弹簧，从静止起步，第一帧来晚也不会"跳"一下）。展开 560ms，带 0.8% 的回弹，像岛自己稳住；收起 380ms，临界阻尼，更快、不回弹（每个状态用"进入它"的那条曲线）。页面内容在展开开始 120ms 后淡入（240ms），6px 的下落用同一条弹簧。`@supports` 检测 `linear()`，支持时保留原采样曲线；旧 WebView2 回退为展开 `cubic-bezier(0.34, 1.3, 0.64, 1)`、收起 `cubic-bezier(0.16, 1, 0.3, 1)`，时长不变。测量：`node scripts/measure-island-motion.mjs [次数] [--scale=1.1] [--trace] [--profile] [--frames]`（生产构建、无头浏览器、CPU 降速 4 倍；开合之外也测翻页，`--trace` 连同栅格线程和 GPU 进程一起统计）。原生端本来就是"先放大窗口、动画结束后 600ms 再缩小"，一次只发一个原生调用（bb1e8de）。
- **所有用户完整播放**（老板确认于 2026-11-13）：系统关闭动画效果或要求减少动画时，外形展开 560ms / 收起 380ms、折叠条和展开面板进出、翻页淡入（220ms）、贴边收起与滑出，均与正常模式一致。很多用户关闭系统动画只是为了性能，并不是对动效敏感。此例外只覆盖岛的展开、收起相关动效，待办、消息卡片、设置页、页面入口的 Dock 跟随和玻璃光晕等仍遵守减少动画。
- **动效只动外形，不重画内容**（2026-11-11，用户反馈 3.0.0 展开、翻页"巨卡"，要求"一定要丝滑"）：每帧只改岛外形（`.island`）的宽、高和圆角，尺寸直接按缩放算成 px；里面的折叠条和页面面板各自保持固定的 `scale()`，缩放本身永远不做动画。页面面板在展开、收起期间（约 640ms，`useMotionLayer.ts`）临时拥有自己的合成层（2026-11-18 起翻页不再提升：独立层上的文字没有次像素抗锯齿，翻页会先糊后清），只被移动、淡入淡出和裁切，不再每帧重新绘制整页的文字、额度环、封面模糊；动完撤掉合成层，文字重新直接画在岛上。翻页时面板立刻换成新页面的高度（只排版一次），由外形的高度过渡把它露出来或收进去，不再每帧重排整页（以前文件中转的文件名测量每帧都会触发一次 React 渲染）。变形期间，会带动整岛重渲染的轮询（媒体状态、Agent 状态与会话、音频电平）跳过这一拍（`lib/islandMotion.ts`）；展开后不显示波形，音频电平也不再轮询。
- **描边**：展开态有一圈 1px 的淡白描边（`.island::after`），让黑色的岛在深色窗口前也有边界；贴顶时描边在顶部 30px 内淡出，屏幕边缘就是岛的上沿。收起态没有描边，也没有任何白线：贴边隐藏时不画提示横条；用鼠标点过收起岛上的按钮后不留底边亮线，只有键盘焦点才点亮。（用户要求 2026-11-10：收起时不要白线）
- **内层同心**：页面面板与岛边缘相距 20px，圆角取"岛屿圆角 − 20px"，形状同为连续圆角；收起态焦点框内缩 3px 跟随小岛圆角。`tests/regression/island-tour.html?test=1` 逐页检查内容没有超出岛的圆角形状、也没有挤到距岛边缘 8px 以内。
- **岛内的方框也用连续圆角**（2026-11-10，用户要求：岛里的框要苹果的圆角，待办的圆角不好看）：待办条目、输入框、笔记本页签、卡片、剪贴板行和缩略图、翻译框、消息与邮件、音乐封面、文件中转、岛内设置页的分组卡片和控件，都和岛同一条曲线。`tokens.css` 里一套刻度 `--corner-xs / sm / md / lg / xl / 2xl`（苹果半径 4 / 6 / 8 / 10 / 12 / 16），和 `corner-shape: var(--corner-shape)` 成对使用；支持 `corner-shape` 时按 1.4 倍半径画 superellipse(1.6)，不支持时退回同样大小的普通圆角（岛本身也一样退回 42 / 1.4 = 30px 的圆角），尺寸和嵌套不变。原来散落的 4–18px 圆角按就近刻度换成这些 token。胶囊（按钮、页面圆点、开关）和圆形保持正圆：superellipse 会把它们的两端压方。嵌套规则：里面的框圆角 = 外框圆角 − 两者间距（CSS 半径），不小于 `--corner-xs`；面板用 `--island-panel-radius`，面板里贴着 16px 内边距的框可用 `--island-card-radius`。Agent 页的样式（另一个会话负责）暂时还是旧的 `--radius-*` 普通圆角，之后换成同一套 token 即可。
- 待办：页签四角同一个圆角（原来上 7 下 4 的不对称圆角加一条底影）；条目列表不再比上面的输入框窄 4px（滚动条的位置改用负外边距让出）。
- 旧设置里的 `islandCornerRadius`、`islandCornerShape` 照旧不读取（按默认值），localStorage key 不变。
- 调研与对比页见 `docs/investigations/corner-shape-compare.html`（当时比较了圆角与 squircle）。

- **默认细线与一次性迁移**（用户要求 2026-11-13）：新用户默认细线，已有存档无论原为默认还是隐藏都迁移为细线一次。完成标记写入后，用户再选择默认/隐藏不会被覆盖；没有存档只标记完成。覆盖下文初版默认 edge 的约定。「隐藏」样式改回窗口上滑 / 下滑配合淡出淡入（用户要求 2026-11-13：原地渐变不如以前滑出来），窗口留在屏幕上的 6px 即热区；细线仍原地变形、窗口不动。原来的「默认」选项中文改叫「露边」（英文仍为 Edge），免得默认值已是细线时还有一个叫「默认」的选项。

## 游戏模式的恢复与召唤（2026-11-25）

- 全屏程序退出或最小化后 Windows 常把前台交给岛屿或设置窗口，此前"自家窗口在前台就保留上次结果"会让游戏模式一直停在开启，岛屿贴边且不参与命中测试。现在记住被判定为全屏的窗口：自家窗口在前台时，只有该窗口仍可见、未最小化且仍铺满显示器才继续保留；否则立即清除。没有可记住的窗口（演示模式）时最多保留 6 秒（`system/fullscreen_hold.rs`）。
- 托盘「显示岛屿」、设置窗口等明确的召唤动作调用 `show_island`，会立即结束游戏模式的压制；之后再检测到全屏程序在前台时照常恢复。诊断事件 `fullscreen / foreground` 的 `reason` 增加 `summoned`、`held_window_gone` 等。

## 浏览器在前台时自动贴边（社区 PR #118，作者 SeanWang114514，2026-11-25 移植）

- 设置 → 通用 → 贴边分组末尾「浏览器打开时自动贴边」（`browserAutoTuck`，**默认关闭**）。开启后，浏览器在岛屿所在显示器的前台时岛屿自动贴边；悬停需停留「鼠标停留后展开」（0–10 秒，步进 0.01，默认 0.65 秒，保留已有保存值）才露出，或勾选「点击贴边岛屿展开」改为点击（此时停留时长置灰）；展开后鼠标离开立即再贴边。
- 「永远不自动贴边」仍优先；游戏模式、消息预览、设置预览结束后再判断。浏览器自动贴边优先于「这些时候不贴边」（音乐、Agent、待办计时），会接管已由闲置计时贴边的岛屿。离开浏览器时只恢复浏览器负责的贴边，不撤销减号、右键等手动贴边。
- 浏览器识别：匹配已知进程名（含 `ego.exe`），或按完整路径匹配 Windows `StartMenuInternet` 注册项；不以 `Chrome_WidgetWin_1` 作为浏览器证据。注册路径最多每 60 秒刷新一次，前台判断仍复用 800ms 的轮询与 `foreground-fullscreen-changed` 的 `browserOnIslandMonitor`。

## 细线悬停走廊（2026-11-25，用户选定方案）

- 贴边后把岛拖到离屏幕顶端较远处时，悬停细线（或露边、隐藏热区）露出的岛会回到下方的自定义位置，光标原本既不在线上也不在岛上，岛随即收回、线又在光标下展开，形成死循环。修法：由光标停在贴边热区引起的露出期间，细线与岛之间的竖直走廊（宽度取两者并集）也算"在岛上"，只影响悬停判定，点击仍穿透。光标第一次真正进入岛、离开走廊、或岛再次贴边时走廊结束，之后回到普通判定（`island/corridor.rs`，由 `passthrough.rs` 的光标循环驱动）。滑动动画期间不判定离开。岛在顶部（没有空隙）时没有走廊。消息露出等不是由悬停热区引起的露出没有走廊。诊断事件 `island / hover_corridor`，`reason` 为开始或结束原因。

## 贴边露出的位置（2026-11-19，用户要求；实现为 Agent 判断）

- 悬停或新消息使贴边岛屿露出时，返回贴边之前的正常位置。正常的自定义悬浮位置保留；本来贴顶的岛不额外下移。
- 已有自定义位置时，进入贴边前用窗口实际物理坐标校准缓存；若露出动画尚未结束就再次贴边，记录动画终点，不记录中间帧。校准沿用原位置事件和存储键，不新增配置。
- 顶部 Windows 任务栏的高度只作为一次物理偏移；DPI 只换算逻辑边距与露边尺寸，舞台 / 面板高度不改变上沿。排查和测试范围见 [贴边位置排查](../investigations/tuck-peek-position-2026-11-19.md)。

## 灵动岛视觉规范（2026-11-06）

- 展开顶栏的页面入口在「外观 → 岛上的排列 → 页面按钮」切换胶囊、图标或图标加文字，默认图标。图标沿用 16px 线条和各页面的颜色，选中时有轻底和细描边，Agent 图标沿用状态色。
- **图标加文字**：Agent、普通页面和消息入口都在图标右侧显示完整页名，文字使用 600 字重。选中和悬停沿用图标样式的高亮底色、细描边和圆角。默认展开宽度 560px、默认字号下，中英文七个页名都在同一行完整显示。
- 顶栏使用左侧页面按钮区到右侧窗口操作前的全部可用空间，包括可点击收起的空白。空间不足时，先收紧按钮内边距和按钮间距，再收紧图标和文字的间距，最后将字号基准由 12px 调为 11px。两档均跟随岛屿字号等比缩放。
- 极窄且最紧排版仍放不下时才仅显示当前页名，再窄则只显示图标。恢复较宽松的排版需要 2px 余量（各档宽度来自隐藏探针，测量容器不随档位变宽变窄，不会来回跳；8px 曾让英文在默认宽度下卡在仅当前页）。每一档里按钮之间的空隙都大于图标和自身页名的间距，否则图标会看起来属于前一个页名。外观预览按同一套宽度规则展示。

下列条目除注明"用户确认"外，均为 Agent 推断，依据一轮岛屿界面的设计审阅。圆角形状见上文"顶边贴合"。设置窗口不在这一轮范围内。

- **清晰度**：新用户默认折叠 / 展开缩放都是 1.0（老用户保留已存值）。不常驻 `will-change`：页面面板只在变形期间临时提升为合成层（见"动效只动外形"）。缩放用 `transform`（不用 `zoom`），因为原生点击区域（`island/passthrough.rs`）按"基准尺寸 × 缩放、顶部居中"计算，`zoom` 会改变布局盒、还会让展开高度测量换算；2026-11-11 起缩放放在折叠条和页面面板上，外形本身按缩放后的 px 尺寸画。进场动画用 `backwards` 填充，结束后不残留合成层。
- **字体**：默认使用 `Segoe UI Variable Text`、`Segoe UI`、`Microsoft YaHei UI` 等系统字体。设置 → 外观 → 文字的字体下拉列表同时提供默认字体、像素字体和 Windows 已安装字体。展开、折叠和外观预览共享所选字体。遇到缺少的字形或已卸载的字体时，沿用系统字体栈。等宽代码仍使用原有等宽字体。字重使用 400、600，≥15px 的标题可用 700。
- **文字 4 级**：`--text-1/2/3` 与 `--text-placeholder`，同一色相（`--color-text` 的 248,246,240）取 .96 / .68 / .54 / .42。在岛 `#030303` 与内层面板 `#1e1e22` 上分别为 17.5 / 14.2、8.7 / 7.8、5.7 / 5.4、3.8 / 3.8：前三级用于可读文字（≥4.5:1），placeholder 只给输入框占位。岛上中性灰文字一律用这 4 级，带色相的强调色（薄荷、粉、紫等）不在此列；待办纸张上的墨色不在此列。
- **图标**：岛上 lucide 图标只用 16px（顶栏、折叠条、列表）和 14px（行内、插件页按钮），统一 `strokeWidth={1.5} absoluteStrokeWidth`；品牌图标 16px。
- **颜色语义**：颜色只给数据和状态用，其余黑白灰。黄色只表示"需要注意"（Agent 状态）；剪贴板页圆点和玻璃强调色改为粉 `#f4a7c4`，"有新版本"徽标和设置按钮上的提示点改用强调青 `--color-accent`。会话列表里仍有运行中会话时，状态灯显示蓝色运行，不再出现"绿灯 + 蓝色数字"。
- **透明度**：经典模式的"透明度"只作用于岛的底色（`--island-fill`）和折叠态的明暗渐变（`--island-fill-alpha`），文字和图标保持不透明。有意的变化：以前整岛一起变淡，现在文字、待办纸张和内层面板在透明度 < 100 时保持不透明。（原来贴顶时用底色条盖住顶边描边、半透明时透出深线的问题，2026-11-10 改为描边在顶部淡出后不再存在。）

## 配色（2026-11-14，用户要求）

用户反馈：岛屿只有一套深色，文字颜色写死，把背景改成白色后就看不清了。

- 「外观 → 风格 → 配色」：深色（默认，就是原来的样子）、浅色、跟随系统。存在 `fly-island-settings.colorScheme`。四个窗口都在 `<html>` 上写 `data-theme`，跟随系统时用 `matchMedia('(prefers-color-scheme: dark)')` 监听。（用户确认）
- **颜色从通道派生**：`tokens.css` 里文字是 `--ink-rgb`，半透明叠加和描边是 `--overlay-rgb`，`--text-*`、`--color-white-aXX` 都由它们算出来。组件不写死白色或深色底；只在一种配色下需要不同值的单个颜色，用 `color-mix(in srgb, 浅色值 calc(var(--is-light) * 100%), 深色值)`，阴影用 `calc(a - var(--is-light) * b)` 变淡。
- **岛屿的明暗看背景色，不看配色**：岛屿舞台带 `data-tone`，按实际背景色的亮度（`theme.ts` 的 `toneOn`，即 `inkOn` 的分界 0.18）决定用深色还是浅色那套 token。所以深色配色下把背景改成白色，文字、图标、内层面板都变成浅色版本。设置里的岛屿预览同样处理。
- **三种自定义颜色**：每种配色各有一套默认值（深色 `#2F2F37` / `#FFFFFF` / `#3AE489`，浅色 `#F4F4F7` / `#1C1C22` / `#12A155`）。存的值等于任意一套默认值，就视为「没改过」，跟着配色走；改过的值在所有配色下都保留。文字色和状态灯没改过时跟着背景的明暗走，不跟配色走。颜色设置里显示的是实际画出来的颜色。
- **浅色文字四级**：同一色相 `26,26,32`，取 .94 / .72 / .64 / .50。在岛 `#F4F4F7` 与内层面板 `#E7E7EA` 上分别为 13.5 / 12.1、6.5 / 6.2、5.0 / 4.8、3.3 / 3.2，前三级 ≥4.5:1。深色这几级不变。
- **浅色的强调和状态色**加深到能在白底上看清：强调 `#0071B8`、警告 `#9A6700`、危险 `#C7354B`；会话灯的黄色加深为 `#E5B400`，仍然只表示「需要注意」。音乐页从封面取的强调色在浅色岛上取同一色相、亮度 0.38（`artworkTint.ts` 的 `tintOnLight`）。
- 浅色岛屿在白色窗口前没有边界，展开和收起时各加一层很淡的阴影；深色不加。黑胶唱片（音乐空闲页）、二维码白底、批准按钮的白字在两种配色下保持原样。
- 设置窗口的原生标题栏和窗口底色由前端调用 `set_settings_window_theme` 设置，只改 DWM 标题栏属性和窗口底色，不改窗口主题：改窗口主题会同时改所有窗口共用的 WebView2 配置的首选配色，「跟随系统」就会读到自己设的值。启动时在首帧之前同步写 `data-theme`，窗口隐藏到页面画完再显示，不会先闪一下深色。

## 质感（2026-11-14，用户要求）

「外观 → 风格 → 质感」：经典（默认，平涂底色）、液态玻璃、磨砂玻璃。存在 `fly-island-settings.material`，`<html>` 上同时写 `data-material`。

- ~~**只用 CSS 画，不模糊桌面**~~（已由 v3.2.6 的实时模糊取代，见文末）（用户确认）：岛屿窗口是 820×460 的透明舞台，DWM 亚克力会把整块舞台都模糊掉；透明窗口上的 `backdrop-filter` 也没有东西可模糊。也不用 `filter: blur`，因为岛的外形每帧都在变，模糊层会拖慢展开动画。原生侧收到玻璃开关只回 `css-fallback`。
- **液态玻璃**（参考用户给的视频前半段和 Wallpaper Engine 作品「Still」的音乐胶囊）：底色很淡，不透明度为「不透明度 × (0.58 − 0.3 × 玻璃强度)」，默认约 0.36；边缘是 1px 亮边，上沿更亮、下沿透出一点光，亮边内侧一条暗细线，里面有一圈柔光，像玻璃的厚度；顶部一道短高光跟着鼠标走，鼠标附近有一团很淡的光（渐变，不是模糊的圆）；整块叠一层细颗粒（一张 128px 的噪点图平铺）。玻璃强度越高，底色越透、亮边越亮。
- **磨砂玻璃**（参考用户给的 Windows 风格控制中心截图）：浅色岛是乳白、深色岛是烟灰，不透明度为「不透明度 × (0.9 − 0.16 × 玻璃强度)」，默认约 0.78；底色上叠一层白（深色 5%、浅色 19%）代替模糊带来的雾感；边缘内侧 1px 亮边，上沿略亮；颗粒更轻。不跟随鼠标、没有高光条。
- 液态玻璃几乎透明，岛上的文字加一圈反色光晕：深色岛黑色阴影，浅色岛白色光晕。贴顶时上沿的高光挪到下沿，贴边圆角沿用同一份玻璃材质。
- 展开时亮边从暗到亮淡入（只动透明度）；系统要求减少动画时不播，鼠标跟随也停。
- 设置里的岛屿预览按同样的底色和亮边画。
- **玻璃里的内层面板不用深色底**（用户反馈 2026-11-14：玻璃里面的面板像黑盒子，不搭）：翻译页、文件中转页的面板和岛内设置页的左栏，在经典质感下是不透明的深色（浅色时白色）底；选了玻璃时换成一层同色调的淡底（液态玻璃深色 22% / 浅色 34%，磨砂玻璃 10% / 20%）加一层很淡的高光渐变、1px 内描边和上沿亮线，不再有投影，让玻璃透出来，弱化文字仍读得清。由 `IslandGlass.css` 在岛上设 `--inner-panel-fill / -edge / -sidebar / -cutout` 变量，面板用 `var(变量, 经典底色)` 读取，经典质感完全不变。消息、剪贴板、待办、Agent、音乐页本来就是半透明卡片，不用改；浮层菜单和提示（`--float-rgb`）保持实心，避免盖在内容上看不清。（Agent 推断：透明度数值）
- 质感只改岛屿本身（收起和展开）。翻译、剪贴板、设置窗口跟随配色，但保持实心底：`<html>` 上已经写了 `data-material`，以后要给这些窗口加玻璃效果时可以直接用。（Agent 推断）

## v3.2.6：玻璃、圆角与露边（2026-11-18）

- **玻璃的实时模糊**（issue #74；2026-11-18 手测后用户否决了壁纸方案：「每一个界面里背景都是桌面，丑飞了」）：两种玻璃下面是岛屿身后**实时**画面的模糊，来自 Desktop Duplication。岛屿窗口只从 Desktop Duplication 中排除，截图和录屏照常可见。身后有变化才更新，最多 30 帧/秒；贴边收起、托盘隐藏、全屏应用占满本屏时暂停。画面在页面里是相对窗口静止的 canvas，岛变形时只裁切、不重绘；没有画面时保持纯色调。外观 → 主题新增「背景模糊」0–100%（默认 60%），仅玻璃材质显示，拖动时实时生效。液态玻璃：很淡的色调、亮边、指针高光、透镜边缘聚光；磨砂玻璃：更重的乳白 / 烟色色调加白雾与细噪点。实现与实测见 `docs/investigations/glass-live-backdrop.md`。
- **玻璃上的文字不加光晕**（2026-11-18，用户反馈玻璃下文字发糊）：去掉液态玻璃的 `text-shadow`，玻璃相关的层都不常驻 `will-change`。切页只淡入、不位移，切页时面板不进独立合成层，所以文字不会先糊后清。
- **玻璃不随动画重绘**：投影是一个展开尺寸的固定层，收起时用与外形同曲线、同时长的 `transform: scale()` 缩小；去掉 16px 模糊的 inset 光晕；收起态与展开态共用同一套玻璃底，收起时不再瞬切背景。
- **玻璃展开时不先出边框**（2026-11-18，用户反馈「展开的时候会提前加载出边框，很难看；展开之后外面也有一层隐约的边框；部分用户反馈卡顿」）：
  - 液态玻璃的亮边、透镜聚光、指针光和高光条，以及磨砂玻璃的 1px 亮边，不再在空玻璃板上先画出一圈轮廓（2026-11-19 起改为外形停稳后再淡入，见下一条）。
  - 投影改为负扩散（`0 12px 20px -10px`），只落在岛的下方，两侧不再有一圈像第二道边框的光晕；投影的加深也跟内容一起淡入。
  - 贴顶时岛身上原有一层 40px 模糊的投影，和 `.island__glass-shadow` 叠成两层，而且弹簧动画每帧都要按平滑圆角的路径重画一次，现已去掉，只保留固定层投影。
  - 同时去掉了玻璃层自己多余的一层圆角裁剪（外层 `.island__surface` 已经裁剪）和内阴影的 0.5px 模糊。无头 Chrome 软件绘制下，液态玻璃岛每次重画的耗时从约 6ms 降到约 3.5ms（`node scripts/measure-island-motion.mjs 1 --trace --material=liquidGlass` 的 Paint by element 表）。
  - 实时模糊每来一帧，原本都会把位置和亮度变量写到 `:root` 上，导致整个窗口重算样式（最多 30 次/秒，身后在放视频时一直如此）。现在只写到背景层本身，而且只在值变了时才写。
  - 合成层会让上面的文字失去子像素抗锯齿，所以不为此加 `will-change`。
- **玻璃展开收起不卡、下面不留空白**（2026-11-19，用户反馈「下面会有一块莫名其妙的空白」「贴边状态展开时会先出轮廓」「展开、收起时有一点点卡」）：
  - 实时模糊的截取范围原来只在开启时按窗口高度算一次，窗口为更高的页面或从贴边展开而变高后，多出来的部分没有背景，只剩一圈亮边。现在窗口尺寸一变就重新发送范围；贴边时先隐去旧画面（窗口已挪位，旧画面对不上），恢复后 Rust 立即补发一帧。有背景时岛身仍保留自己的色调垫在画面下面，画面还没铺到的地方也是玻璃色，不是空白。
  - 展开和收起的过程中（`data-moving`，约 640ms），液态玻璃的亮边、透镜聚光、指针光、高光条和磨砂玻璃的亮边先隐藏，外形停稳后 200ms 淡入：这些平滑圆角上的内描边原本每帧都要重画，是玻璃动画里最大的开销。实时模糊背景层只在这段时间进独立合成层，停稳后撤掉，文字保持清晰。
  - 实测（`measure-island-motion.mjs`，模拟有实时背景）：软件绘制下，原来展开时帧间隔中位数 33ms（掉到 30 帧），背景层进合成层后回到 16.7ms；`--gpu` 下再隐去动画中的亮边，展开每次掉帧从约 5.8 帧降到 1.5–2.3 帧，收起约 1 帧（液态、磨砂相同）。
- **展开圆角与收起圆角分开调**（issue #76；2026-11-18 用户要求两者不再按比例联动）：外观 → 刘海与外形依次是「展开圆角」8–96px（默认 42）、「收起圆角」0–40px（默认 16.8，即旧的 12 / 30 比例在默认展开圆角下的值，外观不变），以及两者共用的「圆角形状」平滑 / 圆弧。展开圆角只管展开态和内层面板，收起圆角管折叠条、贴边和浮起的收起态。旧数据没有收起圆角时，按已保存的展开圆角乘 12 / 30 推出。Rust 命中区跟随（`set_island_interaction` 新增可选参数 `collapsedCornerRadius`）。两个滑块拖动时实时生效。
- **露边高度可调**（issue #76）：通用 → 岛屿 → 贴边样式选「露边」时缩进显示「露出高度」3–20px（默认 10，和以前一样）。

## 2026-11-19：时间与天气状态位（用户要求）

安装插件后收起态增加可独立排列的时间与天气位：本地24小时 `HH:mm`、lucide天气图标与摄氏温度（如 `23°`），颜色和字号跟随岛屿。关闭、卸载、未选城市或观测过期时不占位置。通知阅读器继续使用原来的整岛阅读布局，读完再恢复状态位（Agent 推断，保留现有阅读行为）。

### 收起态自动长度与过渡

- 自动长度根据当前显示的待办（轮换取最宽标题）、Agent、待办计数、自定义空闲文字、额度/设备电量提示或消息预览，结合状态位和附加控件计算，限制在设置的最短和最长之间。
- 自动长度 = 两侧留白 + 各状态位按自身实际宽度 + 间距 + 文字按收起岛字体实际量出的宽度（至少留两个汉字的点击位置）+ 附加控件，不另加固定底数或预留位；内容放得下时就正好是设置的最短长度（缩放前的像素，各缩放比例一致），放不下才加长。读数只取不随岛宽变化的部分，不会被当前宽度锁住。为对齐整设备像素可能相差几个像素（125% 缩放下最短 160 实为 164）。（2026-11-25 用户反馈：最短设 160、待办两个字时岛仍很长）歌词与倒计时胶囊保留固定宽度，不随歌词或秒数跳动。手动长度不按单行消息调整。开启独立的自适应阅读时仍可换行滚动，自动长度同时受自动范围和阅读上限约束，两者不相交时保留自动最短长度。
- 保持收起时，宽度统一用 `cubic-bezier(0.32, 0.72, 0, 1)`、400ms；新目标从正在显示的宽度继续，不叠加第二段动画。状态位入场在伸长约 100ms 后淡入并滑入，离场先淡出约 120ms 再缩短；消息切换沿用原有摘要动画。开合和贴边继续走原有弹簧。原生命中宽度先扩后缩。系统减少动态效果时保留外形过渡，不播放内容的淡入滑动。

### 滚轮临时切换收起内容

（2026-11-25 用户要求：不要点状态灯切换，改为鼠标在岛内滚动滚轮）

- 只在收起态、没有贴边、没有消息预览和额度 / 电量提醒占用文字位时生效：向下滚到下一项，向上滚回上一项，按设置中的循环顺序，在有进行中会话的 Agent、可显示的待办、正在播放且有同步歌词之间切换，跳过不可用的。只有一项或没有可切换项时不变；普通优先级仍可在无歌词时显示歌曲标题。展开态的滚轮照旧（页面滚动、Ctrl + 滚轮翻页）；收起态按住 Ctrl 的滚轮不处理。
- 一次滚动手势只切一项：|deltaY| 累计到 50 才切；切换后 350ms 内忽略；之后还要停顿 150ms 或反向滚动才算新手势（触控板的惯性滚动会超过 350ms）。参数在 `windows/island/collapsedWheel.ts`。
- 滚轮不展开岛、不抢焦点、不传给页面；悬停展开模式下，滚动和按下鼠标一样取消这次待展开（移开再回来才会悬停展开）。切换复用摘要淡入淡出和外形宽度过渡，不修改设置。
- 选择仅保存在主窗口内存，重启恢复优先级。该项不可用时丢弃选择，恢复普通优先级（有倒计时则显示待办）；该项再出现不会自动切回。可以切走倒计时，但不暂停计时或既有活动保活规则。
- 状态灯恢复原用途：有消息预览时打开预览，否则打开 Agent 页。它仍不加悬停、按下效果或工具提示，不改变鼠标指针；只保留键盘焦点环。透明点击区域比亮点宽，拖动不触发点击。
- **插件页按钮**（2026-11-16）：声明 `panel` 的已启用插件各占一个按钮，排在可拖动的页面圆点之后、消息之前，不参与拖动（顺序就是插件列表）。所有插件共用一个淡蓝色胶囊 / 图标色，名字取插件清单。插件要"该看一眼"时按钮右上出现一个暖色小点（例如休息到点、任务进度落后），不发通知。页面本身由宿主绘制：一句话状态、说明、若干行（可带百分比条或宿主自己倒数的期限）、底部动作按钮；行数决定展开高度，超出在页内滚动。插件停用或卸载后该页回到第一个可用页。
