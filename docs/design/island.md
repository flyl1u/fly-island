# 灵动岛：顶边贴合与视觉规范

全局方向见 [DESIGN.md](../../DESIGN.md)。

## 外形（2026-11-10 重做）

用户反馈去掉圆角选项和贴顶圆弧后，岛"像个方盒子"。这一版只有一种外形，不提供设置。（用户要求：选一个好的默认值，不加回设置）

- **贴顶（默认）**：顶边与屏幕上沿齐平，底部两角是大圆角；两侧顶端各有一段 8px 的内凹"肩"，把屏幕边缘顺着弯进岛的侧边，像刘海一样长在屏幕上，而不是一块贴上去的长方形。肩不在点击区域内，鼠标在那里穿透到桌面。（Agent 推断，参照灵动岛 / 刘海）
- **离开顶边（拖到别处）**：岛浮起来，四角一样圆：收起时是胶囊，展开时四角都是展开态的半径。拖回顶边 16px 以内吸附并恢复贴顶外形。
- **半径**：展开态底角 32px，收起态底角按原 22 / 30 的比例为 23.5px（38px 高的小岛接近半圆，读起来是一颗"岛"）。收起 ↔ 展开时半径随宽高一起在 560ms 内过渡。
- **曲线**：柔和的方圆，CSS `corner-shape: superellipse(1.3)`（`features/appearance/cornerShape.ts`）。旧版用的 `squircle`（superellipse(2)）太贴近直角，半径再大也像方块；普通圆弧在与直边相接处有明显的"折"。1.3 介于两者之间：仍是看得出的圆角，又平顺地并入直边。原生点击区域按 |x|ⁿ + |y|ⁿ ≤ rⁿ（n = 2^1.3）判断（`island/state.rs`）。
- **描边**：展开态有一圈 1px 的淡白描边（`.island::after`），让黑色的岛在深色窗口前也有边界；贴顶时描边在顶部 30px 内淡出，屏幕边缘就是岛的上沿，描边不会沿屏幕顶边跑、也不会在肩上打结。收起态没有描边。
- **贴边隐藏**：只露出底部一条边时，边上居中显示一条 36×3px 的浅色小横条（不透明度 .34），提示可以把岛拉下来；露出后淡出。
- **内层同心**：页面面板与岛边缘相距 20px，圆角取"岛屿圆角 − 20px"（默认 12px），形状同为柔和方圆；收起态焦点框内缩 3px 跟随小岛圆角。`tests/regression/island-tour.html?test=1` 逐页检查内容没有超出岛的圆角形状、也没有挤到距岛边缘 8px 以内。
- 旧设置里的 `islandCornerRadius`、`islandCornerShape` 照旧不读取（按默认值），localStorage key 不变。液态玻璃暂停中，玻璃模式不画肩（模糊的背景与平涂的肩对不上）。
- 调研与对比页见 `docs/investigations/corner-shape-compare.html`（当时比较了圆角与 squircle）。

## 顶边贴合

- 拖放时距离顶边 16 逻辑像素以内会吸附到顶边；顶部任务栏存在时以任务栏下沿为顶边。（Agent 推断）
- 多显示器（C1）：设置"位置 → 显示在"可选主显示器（默认，和以前一样）、鼠标所在的显示器、前台窗口所在的显示器。跟随时，收起的岛（含贴边收起）在目标换到另一块屏幕并停留约 0.6 秒后，移到那块屏幕的顶部中间；展开或正在拖动时不移，等收起后再移；前台是岛屿自己时不算换屏。移屏会清掉拖动保存的位置。只有一个岛，不做每屏一个。（用户确认：跟着走）
- 展开方式可选"点击"（默认）或"鼠标悬停"。悬停时光标在岛上停留满"悬停延迟"（0–1000ms，默认 300ms）才展开；延迟内按下鼠标会取消，拖动和点击不受影响；停在小岛上的消息预览、邮件、音乐按钮上不展开。小岛正在显示 QQ / 微信 / 邮件预览时暂停悬停展开，点击预览照常打开对应应用；预览结束时光标仍停在岛上的，需移开再回来才会悬停展开。（用户确认：悬停与点击预览冲突）悬停模式下，面板无论是悬停还是点击打开、在里面点过什么，只要光标进入过面板再移开，就在"移开后收起延迟"（0–2000ms，默认 400ms）后收起；正在文本框里输入、或鼠标仍按住（如拖出面板的拖动）时暂不收起，结束后照常收起。光标从未进入过的面板（快捷键、设置预览打开）不按此规则收起。失焦收起照旧。（用户确认：点过后不收起不符合预期）悬停不抢占输入焦点。收起时光标仍在岛上的，需移开再回来才会再次悬停展开。光标进出岛形状由原生端判断（事件 `island-hover-changed`），不依赖网页的 mouseleave。（用户确认）
- "收起到边缘时，收到新消息自动露出"（默认开启，在"通用 → 展开与收起"）：岛贴边收起时仍接收 QQ / 微信 / 邮件预览，有新预览时滑出并显示；预览显示期间暂停闲置计时，预览结束后重新完整计时再收回。关闭后保持旧行为：贴边时丢弃预览。（上游 issue #28，用户确认）
- "外观 → 尺寸与位置"中的"最大面板高度"（306–546px，默认 490px，随样式预设保存）限制会滚动的页面：待办随条目增高到此为止后列表开始滚动，剪贴板和消息页也不超过它；音乐、归档等固定布局的页面不受影响。字号不单独设置，由"展开面板大小"整体缩放；面板宽度暂不开放（需要原生窗口宽度随之变化）。（用户确认）
- 在设置中拖动"展开面板大小""最大面板高度"时，收起的岛自动展开实时预览，滑块停止 1.5 秒后自动收起；拖动"折叠岛屿大小"时，预览打开的面板立即收起（贴边收起的岛会滑出）以显示小岛。用户自己打开的面板、或预览中在面板里按过的，不会被自动收起。预览不抢占焦点。（用户确认：本次请求）

## 灵动岛视觉规范（2026-11-06）

下列条目除注明"用户确认"外，均为 Agent 推断，依据一轮岛屿界面的设计审阅。圆角形状见上文"顶边贴合"。设置窗口不在这一轮范围内。

- **清晰度**：新用户默认折叠 / 展开缩放都是 1.0（老用户保留已存值）。`.island` 不再常驻 `will-change: transform`，内容层只保留 `will-change: opacity`；缩放仍用 `transform`（不用 `zoom`），因为原生点击区域（`island/passthrough.rs`）按"基准尺寸 × 缩放、顶部居中"计算，`zoom` 会改变布局盒、打断缩放过渡，还会让展开高度测量换算。进场动画用 `backwards` 填充，结束后不残留合成层。
- **字体**：全岛一个字体栈 `--font-ui`（`Segoe UI Variable Text`、`Segoe UI`、`Microsoft YaHei UI`…），写在 `tokens.css`，`base.css` 引用；不再有私有字体栈和 `font-synthesis: weight`（像素字体主题除外）。字重只用 400 / 600，≥15px 的标题可用 700；不用 800 / 900。
- **文字 4 级**：`--text-1/2/3` 与 `--text-placeholder`，同一色相（`--color-text` 的 248,246,240）取 .96 / .68 / .54 / .42。在岛 `#030303` 与内层面板 `#1e1e22` 上分别为 17.5 / 14.2、8.7 / 7.8、5.7 / 5.4、3.8 / 3.8：前三级用于可读文字（≥4.5:1），placeholder 只给输入框占位。岛上中性灰文字一律用这 4 级，带色相的强调色（薄荷、粉、紫等）不在此列；待办纸张上的墨色不在此列。
- **图标**：岛上 lucide 图标只用 16px（顶栏、折叠条、列表）和 14px（行内、插件页按钮），统一 `strokeWidth={1.5} absoluteStrokeWidth`；品牌图标 16px。
- **颜色语义**：颜色只给数据和状态用，其余黑白灰。黄色只表示"需要注意"（Agent 状态）；剪贴板页圆点和玻璃强调色改为粉 `#f4a7c4`，"有新版本"徽标和设置按钮上的提示点改用强调青 `--color-accent`。会话列表里仍有运行中会话时，状态灯显示蓝色运行，不再出现"绿灯 + 蓝色数字"。
- **透明度**：经典模式的"透明度"只作用于岛的底色（`--island-fill`）和折叠态的明暗渐变（`--island-fill-alpha`），文字和图标保持不透明。有意的变化：以前整岛一起变淡，现在文字、待办纸张和内层面板在透明度 < 100 时保持不透明。（原来贴顶时用底色条盖住顶边描边、半透明时透出深线的问题，2026-11-10 改为描边在顶部淡出后不再存在。）

## 收起时的临时提示（2026-11-07）

- 收起的小岛上，消息预览之外的临时提示按这个顺序占用文字位置：设备提示（耳机或蓝牙音频连接 / 断开、蓝牙电量低、插拔电源，3 秒）先于音量 / 亮度提示（1.5 秒），二者都让位于消息预览。展开、贴边收起、游戏免打扰时不显示，期间发生的变化直接丢弃，不补显示。（Agent 推断）
- 设备提示：图标 16px + 一行文字（太长时省略）+ 右侧电量百分比（等宽数字，没有电量不显示）。连接、充电用绿色图标 `#34C759`，断开、拔电源用灰色图标，电量低时图标和百分比用橙色 `#FF9F0A`。只提示耳机、耳麦和蓝牙音频，扬声器和显示器的 HDMI 音频不提示。蓝牙电量降到 20%、10% 各提醒一次，充到 30% 以上后重新计。（Agent 推断）
- 托盘菜单（F13）：跟随岛屿的界面语言（中文 / English），设置里切换语言后立刻跟着变；岛屿启动前先显示中文，和界面的默认语言一致。菜单三项：「显示岛屿 / 隐藏岛屿」（一项，按岛屿当前是否可见显示对应文字）、「设置」、「退出」。（用户确认）
- 展开、收起动画中文字保持清晰（F14）：整岛的缩放过渡作用在 `@property` 注册的 `--island-scale` 上，不直接过渡 `transform`，避免合成器拉伸位图；内容层的 6px 滑入用 `top`，不用 transform，也不预先 `will-change`。以后给岛上的文字加动画时同样避免 transform 过渡和常驻 will-change。（用户反馈）
