# 设置

全局方向见 [DESIGN.md](../../DESIGN.md)。

## 设置窗口

- 设置默认作为岛屿的一页打开（齿轮按钮、托盘「设置」都打开这一页）；「通用 → 独立设置窗口」打开后改为单独的窗口，关掉时窗口合回岛上。这个选择单独保存（`focusd-island-detached-settings`），不进外观预设。（用户要求 2026-11-09：选项尽量少，默认内嵌）

- 设置窗口分左右两栏：左侧分类菜单，右侧只显示当前分类的内容，独立滚动。（用户确认）
- 设置窗口打开时宽 1080、高 860（逻辑像素），正好让右侧内容到达最宽的 860px（侧栏 172 + 内容 860 + 两侧边距 48）；屏幕放不下时按屏幕缩小，不小于 580 × 420。（用户要求 2026-11-07，原为 820 宽）
- 切换分类时，新页面的标题和各张卡片依次上移 6px 淡入（220ms，每张错开 30ms，第四张起不再错开），侧栏选中项左边的高亮条从中间长出来（180ms）；没有退场动画，旧页面直接换掉。系统要求减少动画时直接切换。（用户反馈切换没有过渡；时长与做法为 Agent 推断）
- 侧栏分组：「基础」通用、外观；「功能」待办、音乐、翻译、剪贴板、文件中转、消息；「AI Agent」会话、提醒、声音、审批、连接；「关于」单独放在最底部。没有搜索、没有导出 / 恢复设置、没有单独的快捷键页（快捷键放在翻译、剪贴板各自的页面里）。（用户要求 2026-11-09）
- 各页内容：
  - 外观：最上面是**岛屿预览**，按当前设置画出折叠态和展开态的岛（背景色、不透明度、液态玻璃、字体、圆角、离顶部的距离、缩放、亮点和任务文字颜色），下面依次是风格、颜色、尺寸、圆角、显示内容，样式预设在最下面。预览是画出来的示意，不是真的岛；要在屏幕上看真岛，用尺寸组里的「预览」。两个岛都按岛上的实际样子画 Agent 会话：折叠态是亮点、提供方图标、会话标题和会话环里的数字；展开态按真实岛屿（660px 宽）的比例画，占预览框宽度的 92%，所有尺寸随预览框宽度等比缩放（窗口越宽画得越大，不是拉宽后字仍很小），预览框高度跟着变；依次是顶部栏（Agent 状态灯、页面圆点、右侧圆形按钮）、用量行、会话列表（默认的列表样式），会话行是等待确认（红点，带模型标签和工具行）、等你回复（黄点）、已完成（灰点），每行右侧是状态与时间、提供方图标、归档图标。状态、时间和用量的文字直接用 Agent 页自己的文案；文字跟随岛屿背景的深浅。不再画待办，所以待办纸张颜色不在预览里显示。（用户要求 2026-11-07，并指出第一版和实际不一样；示例内容为 Agent 推断）
  - 消息：QQ、微信、邮箱合成一页，三组各自带开关；邮箱账号是组里的行，「添加邮箱」是组底部的文字链接。旧的 qq / wechat / mail 页名都打开这一页。
  - 关于：名称与版本，「版本」组（检查和安装更新、更新通道），链接（版本发布、反馈问题、Star），最后是「退出岛屿」。没有「重置所有设置」（v0.2.19 起去掉，避免误触）。
  （用户确认：消息合并、更新并进关于）
- 功能开关：待办、音乐、AI Agent 等各在自己设置页第一组的第一行，QQ、微信、邮箱在「消息」页各自的组里；QQ、微信、剪贴板复用原有的接收 / 记录开关。关闭后岛上隐藏入口并停止后台工作，数据保留：待办隐藏页面圆点和小岛上的任务与剩余数；音乐隐藏圆点和波形按钮并停止轮询；AI Agent停止轮询、状态灯保持空闲、隐藏 Agent 页；QQ / 微信 / 邮箱隐藏消息面板对应标签，三个都关时隐藏铃铛；邮箱关闭时暂停已登录账号的同步，重新开启时恢复；剪贴板关闭时同时释放全局快捷键。当前页被关闭时切到第一个仍开启的页面；全部关闭时点击或悬停都不展开。（用户确认：隐藏加停后台、放各自设置页、复用已有开关）
- 侧栏（D9，用户确认 2026-11-07：原来分组不明显、选中态太弱）：
  - 宽 172px（岛上内嵌时 112px），背景比页面深一档，右边一条分隔线。每组上面是不可折叠的组名小标题。
  - 项与项靠紧（约 29px 一行），组与组之间留出空隙。
  - 选中项：浅强调色底、左边一条强调色竖条、强调色图标、文字加粗。
  - 「关于」固定在侧栏最底部，分隔线上方。
- 左栏每项为 lucide 图标加文字。窗口默认 720×640，最小宽度 580。岛屿请求定位保存路径时自动切到"待办"。（Agent 推断）
- "恢复默认外观"按钮放在外观页标题行右侧，点击后原位变为"确认恢复 / 取消"，4 秒无操作自动取消；它与套用样式预设都只改外观字段（外观模式、字体、玻璃强度、透明度、尺寸、边距、圆角、颜色、折叠岛显示开关），不改待办设置和自动收起。预设仍保存完整设置，数据格式不变。（用户确认：采纳重置按钮建议）
- 样式预设可以导出、导入主题文件：每个预设行在「启用」后面有导出图标，标题行右侧是「导入… / 保存当前」；导入的预设放在列表最上面，不自动启用，结果（导出路径和「在文件夹中显示」、导入了哪个、出错原因）写在组下方的说明里，和通用页「备份与恢复」一致。主题只含外观字段，完整设置仍走备份与恢复。（用户要求 2026-11-08；位置和交互为 Agent 推断）
- 设置页用分组列表（`components/settings/`）：组标题是卡片外的粗体小标题，卡片里是若干行、行间有内缩的细线，整组的说明写在卡片下方的灰色脚注里；一组尽量 2～4 行。每行左边是标题（常规字重）和一句灰色说明（打开或关闭后会怎样），右边是控件。只在某个开关打开时才有用的行缩进挂在它下面，开关关闭时不显示。控件：开关用强调色；三个以上选项用不带外框的「当前值 ⌄」下拉；两三个选项用分段选择；数值用整行宽的滑块，数值写在右上角的胶囊里，改过后旁边出现恢复默认的按钮；次要操作用强调色文字链接，不用实心按钮。时间统一用秒显示。只有页面标题和组标题加粗。侧栏保持线条图标，不用彩色图标块。（用户确认 2026-11-06：参考同类软件的设置页；侧栏不要彩色；开关改强调色；滑块和组标题按参考做）
- 叫法：「收起」只指从展开态回到折叠态；岛屿贴到屏幕顶部只露出一条边叫「贴边隐藏」，从那里出来叫「露出」。（用户确认）
