## 分类与分组约定（2026-11-18 整理，用户反馈「设置有点乱了，按需重排」；取代下方 11-14 表格中的对应行）

只调整布局、分组、顺序和文案，不删设置项，不改 localStorage key、字段名、默认值和行为。约定：

- **一个功能一组**：功能的开关在组内第一行，子项缩进挂在它下面，开关关掉时隐藏；子项本来只在开关开启时生效，隐藏不改变行为。
- **常用在前、低频在后**：各页依次是功能开关（无标题组）→ 常用选项 → 显示细节 → 存储位置等低频项。
- **组粒度一致**：每组 1～5 行，同一页不出现 8 行以上的杂烩组；组标题用短名词，不和组内第一行同名。
- 同类功能不跨页：快捷键留在翻译、剪贴板各自页面；游戏模式下的通知挂在游戏模式下（它只在游戏模式开启时生效）。

## 插件设置归类规范（长期）

2026-11-26 用户要求，长期规范：插件的设置按类别放进对应的设置页，**不能堆在插件页下面**。插件会越来越多，堆在一起整页会乱掉。本节取代上文里「外部插件安装后在插件页显示各自设置」的做法。

### 放在哪里

| 类别 | 目录声明 `settings.placement` | 位置 |
| --- | --- | --- |
| 岛屿 / 功能类（时间与天气、护眼提醒、设备电量与音频等） | `standalone` | 装好并启用后，在侧栏「功能」组末尾出现独立栏目。栏目名用插件名，图标用该插件的线条图标。页面里是插件的设置；已有同一用途的页面（如原「设备」页）并入这个栏目，只留一个入口。 |
| AI Agent 类（MiniMax Code、Cursor、Kimi Code、CodeBuddy、Antigravity、Z Code、Hermes 等） | `agentSessions` 或 `agentConnect` | 不新增侧栏项。额度、会话、提醒相关放「AI 会话」页，连接或接入配置放「接入 AI 工具」页；设置和动作性质不同时，用 `actions` 单独指定动作按钮放哪一页。每个插件一个分组，组标题是插件图标加插件名，排在内置分组之后。 |
| 消息类（钉钉、飞书、企业微信等） | `messages` | 「消息」页，每个插件一个分组，组标题是插件图标加插件名，排在内置分组之后。 |
| 没有任何设置项 | `settings: null` | 卡片上没有「打开设置」。 |

- **插件页只放卡片**：市场和已安装插件（安装、卸载、启用开关、作者、简介、安装进度与失败原因、有新版本时的「更新」），加跳到所在页面和分组的「打开设置」按钮。插件页不渲染任何插件的设置项或动作。
- 版本、运行状态和权限标签放在插件设置所在页面 / 分组的最后一行。
- 插件停用或卸载时，它的栏目或分组消失；正停在它的独立栏目时回到插件页。
- **新增插件必须在目录（`features/plugins/native/catalog.ts`）里声明 `settings`**（内置插件和打包市场插件都要，类型上是必填项）。设置面板和侧栏只按声明渲染，不写按插件 id 分支的代码。
- 开发者模式下加载、目录里没有的插件按清单的 `contributes` 归类：含 `quota` 或 `sessions` → AI 会话；否则含 `notifications` → 消息；否则独立栏目。
- 外部进程插件的设置项来自清单 `settings`，仍用 `PluginSettingRow` / `PluginNumberSettingRow` 渲染，归类只改位置，不改协议。

### 图标

- 有品牌且能合规取得官方标识的，用品牌图标（放在 `src/assets/brands/`，在它的 README 里记录来源和授权）；否则用 lucide 线条图标配一个低饱和强调色。**不允许占位图标、字母头像或插件包自带的位图。**
- 线条图标的卡片磁贴和「时间与天气」「日历标记」一致：同样的尺寸、圆角、描边、底色浓度和光晕强度，线宽 1.5，图形占磁贴的 72%。
- 同一个插件在插件卡片、侧栏栏目、分组标题三处用同一套图标。侧栏统一用线条图标，不用彩色图标块。
- 图标只在 `features/plugins/PluginIcon.tsx`（磁贴）和 `features/plugins/pluginLineIcons.ts`（线条图标）里定义。
