# 设置窗口与插件市场页

全局方向见 [DESIGN.md](../../DESIGN.md)。

## 设置窗口

- 设置窗口分左右两栏：左侧分类菜单，右侧只显示当前分类的内容，独立滚动。（用户确认）
- 切换分类时，新页面的标题和各张卡片依次上移 6px 淡入（220ms，每张错开 30ms，第四张起不再错开），侧栏选中项左边的高亮条从中间长出来（180ms）；没有退场动画，旧页面直接换掉。系统要求减少动画时直接切换。（用户反馈切换没有过渡；时长与做法为 Agent 推断）
- 侧栏分组：「基础」通用、外观、快捷键；「功能」待办、日历、音乐、翻译、剪贴板、文件中转、消息；「AI Agent」会话、提醒、声音、审批、连接、SSH 远程；「扩展」插件、插件市场；分隔线下是关于。（用户确认 2026-11-06，D8；AI Agent 单独一组 2026-11-07，B16：Agent 的设置项越来越多，以后移植 Vibe Island 的功能也放这一组。分类名 `agents`（会话）、`sounds` 不变，岛上和旧链接照样能打开；SSH 读取的远程电脑单独一页 `agentRemote`，侧栏名「SSH 远程」，放在这一组最后，2026-11-07 用户要求）
- 各页内容：
  - 外观：最上面是**岛屿预览**，按当前设置画出折叠态和展开态的岛（背景色、不透明度、液态玻璃、字体、圆角、离顶部的距离、缩放、亮点和任务文字颜色），下面依次是风格、颜色、尺寸、圆角、显示内容，样式预设在最下面。预览是画出来的示意，不是真的岛；要在屏幕上看真岛，用尺寸组里的「预览」。两个岛都按岛上的实际样子画 Agent 会话：折叠态是亮点、提供方图标、会话标题和会话环里的数字；展开态约为实际大小的 0.7，依次是顶部栏（Agent 状态灯、页面圆点、右侧圆形按钮）、用量行、会话列表（默认的列表样式），会话行是等待确认（红点，带模型标签和工具行）、等你回复（黄点）、已完成（灰点），每行右侧是状态与时间、提供方图标、归档图标。状态、时间和用量的文字直接用 Agent 页自己的文案；文字跟随岛屿背景的深浅。不再画待办，所以待办纸张颜色不在预览里显示。（用户要求 2026-11-07，并指出第一版和实际不一样；示例内容为 Agent 推断）
  - 消息：QQ、微信、邮箱合成一页，三组各自带开关；邮箱账号是组里的行，「添加邮箱」是组底部的文字链接。旧的 qq / wechat / mail 页名都打开这一页。
  - 插件：已安装的插件、插件的岛屿页面和开发者工具。插件市场是「扩展」组里单独的一页（用户确认 2026-11-07，D10：分段藏在页面顶部不好找）；市场里「管理」打开插件页上那个插件的设置。
  - 关于：名称与版本，「版本」组（检查和安装更新、更新通道、后台检查，原「更新」页并进来），链接（版本发布、反馈问题、Star），最后一张卡片是「重置所有设置」和「退出岛屿」。没有更新公钥时「查看最新版本」打开 Release 页。旧的 updates 页名和岛上「去更新」都打开关于。
  （用户确认：消息合并、更新并进关于、关于里加重置和退出）
- 「重置所有设置」点一下后原位变成「取消 / 确认重置」，4 秒无操作自动取消；只恢复设置，待办、笔记、邮箱、插件、密钥、样式预设和界面语言都保留。「退出岛屿」和托盘菜单的「退出」一样，直接退出、不再确认。（Agent 推断）
- 功能开关：待办、音乐、AI Agent 等各在自己设置页第一组的第一行，QQ、微信、邮箱在「消息」页各自的组里；QQ、微信、剪贴板复用原有的接收 / 记录开关。关闭后岛上隐藏入口并停止后台工作，数据保留：待办隐藏页面圆点和小岛上的任务与剩余数；音乐隐藏圆点和波形按钮并停止轮询；AI Agent停止轮询、状态灯保持空闲、隐藏 Agent 页；QQ / 微信 / 邮箱隐藏消息面板对应标签，三个都关时隐藏铃铛；邮箱关闭时暂停已登录账号的同步，重新开启时恢复；剪贴板关闭时同时释放全局快捷键。当前页被关闭时切到第一个仍开启的页面；全部关闭时点击或悬停都不展开。（用户确认：隐藏加停后台、放各自设置页、复用已有开关）
- 侧栏（D9，用户确认 2026-11-07：原来分组不明显、选中态太弱）：
  - 宽 172px，背景比页面深一档，右边一条分隔线。最上面是「搜索设置」框，代替原来的「设置」标题：按页面名、组名和每页的关键词（`categories.keywords`，例如「蓝牙」找到通用、「音效」找到声音）筛选，折叠的页面也能搜到；回车打开第一个结果，Esc 清空。
  - 项与项靠紧（约 29px 一行），组与组之间留出空隙。
  - 选中项：浅强调色底、左边一条强调色竖条、强调色图标、文字加粗。
  - 每个组（基础、功能、AI Agent、扩展）都是一行带图标和箭头的可折叠项，组里的页面缩进挂在下面，左边有一条引导线。打开窗口时全部展开（用户确认 2026-11-07）；折叠只在窗口开着时保留，折叠的组仍显示当前打开的那一页。全部展开时列表比 640px 的窗口长，切换页面时侧栏会把当前页滚进视野。
  - 「关于」固定在侧栏最底部，分隔线上方。
- 左栏每项为 lucide 图标加文字。窗口默认 720×640，最小宽度 580。岛屿请求定位保存路径时自动切到"待办"。（Agent 推断）
- "恢复默认外观"按钮放在外观页标题行右侧，点击后原位变为"确认恢复 / 取消"，4 秒无操作自动取消；它与套用样式预设都只改外观字段（外观模式、字体、玻璃强度、透明度、尺寸、边距、圆角、颜色、折叠岛显示开关），不改待办设置和自动收起。预设仍保存完整设置，数据格式不变。（用户确认：采纳重置按钮建议）
- 设置页用分组列表（`components/settings/`，分析与方案见 [settings-window-redesign.md](../reviews/settings-window-redesign.md)）：组标题是卡片外的粗体小标题，卡片里是若干行、行间有内缩的细线，整组的说明写在卡片下方的灰色脚注里；一组尽量 2～4 行。每行左边是标题（常规字重）和一句灰色说明（打开或关闭后会怎样），右边是控件。只在某个开关打开时才有用的行缩进挂在它下面，开关关闭时不显示。控件：开关用强调色；三个以上选项用不带外框的「当前值 ⌄」下拉；两三个选项用分段选择；数值用整行宽的滑块，数值写在右上角的胶囊里，改过后旁边出现恢复默认的按钮；次要操作用强调色文字链接，不用实心按钮。时间统一用秒显示。只有页面标题和组标题加粗。侧栏保持线条图标，不用彩色图标块。（用户确认 2026-11-06：参考同类软件的设置页；侧栏不要彩色；开关改强调色；滑块和组标题按参考做）
- 叫法：「收起」只指从展开态回到折叠态；岛屿贴到屏幕顶部只露出一条边叫「贴边隐藏」，从那里出来叫「露出」。（用户确认）

## 插件市场

- 插件页和市场页的插件都是卡片，放得下时一行两张（每张至少 220px），窗口窄时一行一张（用户确认 2026-11-07，D10）。
- 插件页：最上面一张卡片是「允许运行第三方插件」开关和插件目录（打开、重新加载两个图标按钮），风险说明是卡片下的脚注；下面按「第三方」「内置」分组。点卡片空白处打开插件自己的设置页，开关、按钮、权限展开不触发；主页和卸载是图标按钮，卸载点一下后变成「确认卸载」。
- 市场页：状态行右边是刷新图标按钮；搜索框和分类在同一行；分组依次是「可更新」「可安装」，已是最新版的已安装插件默认隐藏，列表下方的「显示已安装的插件（N）」展开。卡片里说明和提示占满整宽，安装 / 更新按钮在卡片底部右侧；展开详情的卡片独占一行。校验说明放在页面最下面。

- 页面标题已经是「插件市场」，列表上方不再重复标题，改为一行状态「共 N 个插件 · 索引更新于 HH:MM」，右侧是「刷新」。只显示岛屿缓存的列表时不写时间。（用户确认）
- 列表分两组：「可安装」在上，「已安装」在下；已安装里有新版本的排在前面。（用户确认）
- 卡片右侧只有三种状态：「安装」（第一次安装其他发布者时是「信任并安装」）；灰色「已安装 ✓」加「管理」，「管理」跳到「已安装」里这个插件的设置页；强调色的「更新到 vX」。点卡片本身展开详情，不再有单独的「详情」按钮。下架、不兼容、换了作者密钥的更新保留原来的提示和两步确认。（用户确认）
- 官方插件在名字旁显示一个小的「官方」标记，不再每张卡片都写「发布者 TixXin · 官方」；已验证的发布者同样只显示「已验证」，域名放在悬停提示里。（用户确认）
- 卡片的事实行：发布者（官方的省略）、权限数（含可选权限，有敏感权限时用警示色，悬停列出权限）、运行时（Node.js / PowerShell / 程序）、签名、自定义界面和分类标签。说明最多两行，展开后完整显示。（用户确认）
- 索引里没有插件图标，用名字的第一个字加分类颜色生成；没有分类时按插件 id 固定取一种颜色。（Agent 推断）
