# 剪贴板历史

全局方向见 [DESIGN.md](../../DESIGN.md)。

## 平面列表

- 移除盒子套盒子的视觉层级，与岛屿深色背景融合。（2026-11-10，用户确认）
- 不绘制独立面板底色、边框或投影；记录用细分隔线组织，不使用行卡片。文字类型图标、备注、收藏和操作按钮默认不带底框，图片保留紧凑缩略图。（Agent 推断）
- 沿用全部 / 收藏、搜索、复制、备注和删除操作；收藏常显，其余操作在悬停或键盘进入行内时显示。复制与删除确认保留状态反馈。（Agent 推断）
- 搜索框保留低对比底色和可见焦点，备注编辑时为输入及确认 / 取消按钮留出足够宽度；长内容在行内截断，不挤压操作区。（Agent 推断）
- 搜索框放在“全部 / 收藏”右侧，与栏目共用一行；面板高度同步减少，不保留原搜索行的空白。（2026-11-10，用户确认）
- 经典和玻璃外观都直接使用岛屿自身背景，避免再叠一块玻璃面板。维持现有每行 44px、行距 6px 和按记录数量计算高度的规则。（Agent 推断）

## 容量与岛内高度（用户要求 2026-11-13）

- 历史条数为 5–500，默认仍为 30；设置里「最多保存几条」下紧跟「一次显示几条」，范围 3–8、默认 4，步进 1。后者只决定岛内剪贴板高度，不影响保存数量，不随外观预设重置。
- 列表先挂载 20 条，滚动到距离底部不足 200px 时再追加 20 条；搜索和筛选对完整数据生效，并从第一批重新显示。仍为平铺的 44px 行，不引入虚拟列表依赖。

## 多选与预览（用户要求 2026-11-13）

- 头部垃圾桶进入选择状态，行左侧的圆形勾选框淡入、内容在 180ms 内右移；点行切换选择，不复制。头部全选只操作当前搜索和筛选结果（包括尚未挂载的条目），隐藏的已选项保留，删除按钮显示全部已选数量。再次点击垃圾桶删除明确选中的记录，包括收藏；成功后退出，失败时保留选择并原地提示。
- X 或 Esc 退出选择，不设三秒超时；单条删除仍保留原两次点击确认。
- 缩略图是独立的放大入口，悬停使用 zoom-in 光标；选择状态下也可预览，不改变选择。图片以原比例放在面板内的半透明遮罩上，显示尺寸；读取时先放大缩略图，失败时保留占位并提示。
- 点遮罩、关闭按钮或 Esc 关闭预览；预览优先消耗 Esc，接下来再退出选择，不触发岛屿收起。180ms 淡入与轻微缩放，减少动画时只淡入；焦点留在预览中，关闭后恢复。
