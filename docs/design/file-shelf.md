全局方向见 [DESIGN.md](../../DESIGN.md)。

## 文件中转

- 单独一页「文件中转」，顶部圆点和强调色用薄荷绿（`#6ee7c8` / `110, 231, 200`），与待办蓝、音乐紫、剪贴板粉区分。（用户确认：单独一页；颜色为 Agent 推断）
- 只存路径不复制文件；拖出默认复制、Shift 移动，与资源管理器一致。（用户确认：只存引用）
- 拖入时列表保持原位并变暗，整个面板叠一层带虚线框的薄荷绿覆盖层；空列表时投放区撑满面板。放下后列表回到顶部，新加入的条目高亮约 1 秒；全部是已有文件时标题旁短暂提示「已在列表中」。（用户确认：覆盖层方案）
- 选中条目用薄荷绿底和描边；选中两个以上时标题下方出现一行选择栏。置顶条目在图标外加一圈薄荷绿描边；「已失效」划掉文件名，「无法访问」用琥珀色文字、不划掉，表示文件可能还在。（Agent 推断）
- 折叠态的数量标签是薄荷绿的胶囊，默认关闭。（用户确认：要这个设置项；默认关为 Agent 推断）
- 条目是平铺在面板上的行，不再一行一张卡片：指向、选中、刚放下时才出现底色。左侧 40px 图标位：图片为缩略图，其他为资源管理器的系统图标（不加底板，带一点投影）；拿不到系统图标时是按类型着色的图标底板（文件夹黄、文档蓝、表格绿、演示橙、压缩包琥珀、音频紫、视频粉、代码青、程序蓝紫）。名称下方是"PDF · 1.4 MB"，文件夹和失效状态照旧。（Agent 推断，2026-11-09 参考 xiaotang-daozai 的置物架思路，未使用其代码或素材）
- 复制、在文件夹中显示、置顶、移除四个按钮只在指向、键盘聚焦或选中该行时出现；置顶的条目一直显示置顶按钮。指向时图标上浮 1px。（Agent 推断）
- 新放下的条目从上方滑入并短暂发出薄荷绿光。拖入时覆盖层带中心薄荷绿光晕和虚线框，箭头上下轻轻浮动；空列表显示收件盒图标、提示和一行说明"只记住位置，不复制文件；移除也不会删掉原文件"。（Agent 推断）
- 详见 `docs/file-shelf.md`。
