# 文件中转

全局方向见 [DESIGN.md](../../DESIGN.md)。

## 文件中转

- 单独一页「文件中转」，顶部圆点和强调色用薄荷绿（`#6ee7c8` / `110, 231, 200`），与待办蓝、音乐紫、剪贴板粉区分。（用户确认：单独一页；颜色为 Agent 推断）
- 只存路径不复制文件；拖出默认复制、Shift 移动，与资源管理器一致。（用户确认：只存引用）
- 拖入时列表保持原位并变暗，整个面板叠一层带虚线框的薄荷绿覆盖层；空列表时投放区撑满面板。放下后列表回到顶部，新加入的条目高亮约 1 秒；全部是已有文件时标题旁短暂提示「已在列表中」。（用户确认：覆盖层方案）
- 选中条目用薄荷绿底和描边；选中两个以上时标题下方出现一行选择栏。置顶条目在图标外加一圈薄荷绿描边；「已失效」划掉文件名，「无法访问」用琥珀色文字、不划掉，表示文件可能还在。（Agent 推断）
- 折叠态的数量标签是薄荷绿的胶囊，默认关闭。（用户确认：要这个设置项；默认关为 Agent 推断）
- （2026-11-10 起由下方"图块布局"取代）条目是平铺在面板上的行，不再一行一张卡片：指向、选中、刚放下时才出现底色。左侧 40px 图标位：图片为缩略图，其他为资源管理器的系统图标（不加底板，带一点投影）；拿不到系统图标时是按类型着色的图标底板（文件夹黄、文档蓝、表格绿、演示橙、压缩包琥珀、音频紫、视频粉、代码青、程序蓝紫）。名称下方是"PDF · 1.4 MB"，文件夹和失效状态照旧。（Agent 推断，2026-11-09 参考 xiaotang-daozai 的置物架思路，未使用其代码或素材）
- 复制、在文件夹中显示、置顶、移除四个按钮只在指向、键盘聚焦或选中该行时出现；置顶的条目一直显示置顶按钮。指向时图标上浮 1px。（Agent 推断）
- 新放下的条目从上方滑入并短暂发出薄荷绿光。拖入时覆盖层带中心薄荷绿光晕和虚线框，箭头上下轻轻浮动；空列表显示收件盒图标、提示和一行说明"只记住位置，不复制文件；移除也不会删掉原文件"。（Agent 推断）
- 详见 `docs/file-shelf.md`。

## 图块布局（2026-11-10 第一版，已由下方"重新设计"取代）

第一版每排 4 个图块、名称两行、操作按钮浮在图块顶边，页面一排 315px、两排 463px。

## 重新设计（2026-11-10，用户要求"不要参考之前的，从空白页开始，相信你的审美"）

整体：安静、让文件本身的颜色做主角。面板和剪贴板页同一种深色卡片，薄荷绿只留给"和文件中转有关的动作"：置顶、选中、拖入。（Agent 推断，下同）

**去掉标题行和面板里的框**（2026-11-10，用户在真实应用里看过后要求：删掉左上角"文件中转"标题行；面板里的虚线框是"框里套框"，很别扭）：面板顶上不再有图标 + "文件中转" + 数量那一行——顶栏的页面圆点已经说明这是哪一页。面板里不再画任何框：文件平时只有图标和名字，像桌面上的图标，指向或选中时才出现一块淡淡的底色；"还能再放"空位没有虚线框，只剩一个淡加号和字；空状态直接放在面板上，没有托盘；拖入时不再盖一块虚线投放区，而是面板自己的边缘亮成薄荷绿。搜索框、提示和清空按钮合成面板底部一行（28px）：文件多时左边是搜索框，中间是灰色提示（放不下时省略，指向显示全文；"已在列表中"短暂替换它），右边清空；多选时整行换成"已选 N 个"栏。

- **按数量换排法**：1–4 个文件是一排大图块（48px 缩略图或系统图标在上，文件名一行、下面是大小）；不满 4 个时，排尾留一个"还能再放"空位（无框），告诉人还可以往里拖。5 个以上换成两列紧凑的行（28px 图标、名称、大小），一行 44px，最多显示 5 行，再多在面板里滚动；这时底部一行出现搜索框（文件少时不显示）。排法跟着文件总数走，不跟着搜索结果走，打字时不重新排。
- **图标**：图片显示缩略图（连续圆角），其他文件显示资源管理器的系统图标（`get_file_shelf_icon`，不加底板）；拿不到时是按类型着色的方形图标底板（文件夹黄、文档蓝、表格绿、演示橙、压缩包琥珀、音频紫、视频粉、图片杏、代码青、程序蓝紫）。失效、无法访问的条目图标变灰半透明，只按类型取图标、不去读文件。
- **文件名**：只占一行；放不下时从中间省略、保留开头和结尾，扩展名始终完整显示并稍暗一档（"IMG_2026…3522.jpg"、"2026 第…终版）.pdf"），按名称的实际字体和宽度测量（`fitFileStem` + `useFittedStem`），中文按字截断。大小一行只写大小（扩展名已在名字里），文件夹写"文件夹"。指向时显示完整路径（`title`）。已失效的名字划掉，无法访问的大小一行改为琥珀色"无法访问"（文件可能还在）。
- **置顶**：图标右下角一枚薄荷绿小图钉，不再给整个图块描边。
- **拖出**：图块和行的光标是"抓手"，指向时图标上浮 2px 并带影子，像可以拿起来；按下拖动即拖出（默认复制、Shift 移动，和资源管理器一致），底部一行灰字说明。双击打开（或按设置"在文件夹中显示"）。
- **操作**：置顶、复制、在文件夹中显示、移除四个按钮，在指向、键盘聚焦或选中时出现。图块上它们替换"大小"那一行，出现在名字下面，不压住图标；行上它们出现在右端，名字按剩下的宽度重新截断，不叠在文字上。移除按钮指向时变红。
- **多选**：两个以上时，底部一行整行换成淡薄荷绿的"已选 N 个"栏（复制、移除、取消），页面高度不变。
- **拖入**：列表和底部一行退后（变淡、轻微模糊），面板自己的边缘亮成薄荷绿（内侧一圈淡光），中间一个薄荷绿圆形下载箭头（轻轻上下浮动）和"松开鼠标，加入文件中转"。
- **空状态**：直接在面板上，左边三张扇形摆开的文件（图片、空白、文档），右边"把文件拖到岛上，就会暂存在这里"和"只记住位置，不复制文件；移除也不会删掉原文件"。拖入时面板边缘亮成薄荷绿，两侧文件再张开一点，中间那张变成薄荷绿的下箭头。
- **动效**：刚放下的文件从 0.9 倍弹到原大并闪一圈薄荷绿光（520ms）；移除的文件先淡出缩小（180ms）再离开列表。系统要求减少动画时都直接出现、消失，指向也不上浮。
- **页面高度**：空 244px，一排图块 262px，行 = 144 + 行数 × 50 − 6（最多 5 行，`getShelfExpandedHeight`），都不超过"最大面板高度"。
- 收起的岛上的数量标签保持薄荷绿小胶囊，没有改。
- 圆角：面板内边距 12px，图块和行指向时的底色圆角按"面板圆角 − 12px"（`--shelf-item-radius`），图标与缩略图用 `--corner-md` / `--corner-sm` 的连续圆角。
