## 文件中转

- 单独一页「文件中转」，顶部圆点和强调色用薄荷绿（`#6ee7c8` / `110, 231, 200`），与待办蓝、音乐紫、剪贴板粉区分。（用户确认：单独一页；颜色为 Agent 推断）
- 只存路径不复制文件；拖出默认复制、Shift 移动，与资源管理器一致。（用户确认：只存引用）
- 拖入时列表保持原位并变暗，整个面板叠一层带虚线框的薄荷绿覆盖层；空列表时投放区撑满面板。放下后列表回到顶部，新加入的条目高亮约 1 秒；全部是已有文件时标题旁短暂提示「已在列表中」。（用户确认：覆盖层方案）
- 选中条目用薄荷绿底和描边；选中两个以上时标题下方出现一行选择栏。置顶条目在图标外加一圈薄荷绿描边；「已失效」划掉文件名，「无法访问」用琥珀色文字、不划掉，表示文件可能还在。（Agent 推断）
- 折叠态的数量标签是薄荷绿的胶囊，默认关闭。（用户确认：要这个设置项；默认关为 Agent 推断）
- （2026-11-10 起由下方"图块布局"取代）条目是平铺在面板上的行，不再一行一张卡片：指向、选中、刚放下时才出现底色。左侧 40px 图标位：图片为缩略图，其他为资源管理器的系统图标（不加底板，带一点投影）；拿不到系统图标时是按类型着色的图标底板（文件夹黄、文档蓝、表格绿、演示橙、压缩包琥珀、音频紫、视频粉、代码青、程序蓝紫）。名称下方是"PDF · 1.4 MB"，文件夹和失效状态照旧。（Agent 推断，2026-11-09 参考 xiaotang-daozai 的置物架思路，未使用其代码或素材）
- 复制、在文件夹中显示、置顶、移除四个按钮只在指向、键盘聚焦或选中该行时出现；置顶的条目一直显示置顶按钮。指向时图标上浮 1px。（Agent 推断）
- 新放下的条目从上方滑入并短暂发出薄荷绿光。拖入时覆盖层带中心薄荷绿光晕和虚线框，箭头上下轻轻浮动；空列表显示收件盒图标、提示和一行说明"只记住位置，不复制文件；移除也不会删掉原文件"。（Agent 推断）
- 详见 `docs/file-shelf.md`。

## 图块布局（2026-11-10，用户要求"文件中转的 UI 重构一下，相信你的审美"）

- 列表改成置物架上的图块，每排 4 个：48px 图标或缩略图（系统图标 40px）在上，文件名最多两行居中，下面一行"PDF · 1.4 MB"。每个图块有很淡的底，指向时变亮、图标上浮 2px。
- 面板去掉薄荷绿光晕和投影，只留一层很淡的底和细边，让文件本身的颜色成为重点。
- 操作按钮浮在图块顶边：复制、在文件夹中显示、移除在右，置顶在左；指向、聚焦或选中时出现。置顶的图块描一圈淡薄荷绿边，置顶按钮一直显示。
- 底部一行灰色提示："拖到别的窗口就是复制，按住 Shift 是移动 · 双击打开"（双击设置为"在文件夹中显示"时跟着改）。
- 页面高度跟着排数走：一排 315px，两排 463px，再多就在两排里滚动（以前固定 430px，文件少时空一大块）。
