# 翻译界面

全局方向见 [DESIGN.md](../../DESIGN.md)。

## 翻译界面

- 快捷翻译参考 `https://island.flyliu.org/` 展示的翻译 UI。（用户确认：本次请求）
- 使用炭灰表面、紧凑标题和语言方向栏，原文与译文以细分隔线组织；沿用系统字体和 lucide 图标。（Agent 推断，依据参考界面）
- 配色只用中性灰白（2026-11-11 用户反馈：整体偏绿，和岛不搭）：译文用亮白（`#f0f0f3` / `--color-text`），翻译主按钮是浅灰白底、深色字，指向时纯白；聚焦框和输入框聚焦边框用半透明白，不再有任何绿色。独立窗口和岛内翻译页一致。
- 默认窄窗口上下排列，宽度达到 760px 时并排；长文本分别滚动和换行，设置区域可滚动。（Agent 推断）
- 空态提供剪贴板入口，加载显示处理中，复制后原位显示“已复制”；保留全局快捷键和 Windows 凭据管理器的密钥设置。（Agent 推断）
- 翻译服务可选 DeepSeek（默认）、火山方舟、通义千问、Kimi、硅基流动、OpenAI 或自定义 OpenAI 兼容接口。预设服务的接口地址由原生端固定，自定义地址须为 https（本机可用 http://localhost）；每个服务可改模型名（DeepSeek 留空用 deepseek-flash，其余需按服务商文档填写），密钥按服务分开保存。工具栏显示当前服务名。（上游 issue #15，用户确认）
- 打开翻译窗口且原文为空时自动填入最新文字剪贴板（默认开，可关）；可开启「停稳后自动翻译」（默认关，仅窗口打开时、输入停约半秒后发送，没有密钥不发送）。「翻译选中文字」快捷键（默认 Ctrl+Alt+T）临时复制选中内容并还原剪贴板，不记入剪贴板历史，没选中时翻译剪贴板文字；译文在折叠的岛上显示一行约 8 秒，消息预览优先，点击打开翻译窗口查看全文。岛内不做第二套原文框，不在后台监听剪贴板或选区，不把译文自动写回剪贴板。（用户确认）
- 设置 → 翻译可选「打开位置」：独立窗口（默认）或岛内页面。选岛内页面时，顶栏翻译按钮、翻译快捷键和点击岛上的译文都打开岛屿展开后的翻译页（方向栏、原文、译文、粘贴 / 复制 / 翻译一行操作），与窗口共用服务、密钥、剪贴板填入和自动翻译设置；收起再展开时保留原文。（用户确认）
- 设置「基础」分组有「快捷键」页，集中列出所有按键：全局快捷键（打开快捷翻译、翻译选中文字、剪贴板历史，功能关闭时不列）和页面切换在这里录制，注册失败的错误显示在对应行；Esc 收起、Ctrl + 拖动、翻译框的 Enter / Shift+Enter / Tab 只读列出。每个快捷键只有这一个修改入口，翻译、剪贴板页改为一行「前往快捷键」链接。不做首次引导和 `?` 浮层。（用户确认）
- 打开翻译不带动效（2026-11-11 用户反馈：打开翻译页有一下往下"冲"的感觉）：岛内翻译页直接以展开后的高度出现，不再从折叠条往下长、面板也不下滑淡入（`.island--translation.island--expanded` 关掉过渡）；收起照常有动画。独立翻译窗口关掉系统的显示动画（`DWMWA_TRANSITIONS_FORCEDISABLED`），原地出现。
- 自动方向按主导语言判断（2026-11-11 用户反馈：长英文里夹一点中文就原样返回）：比较正文里的汉字数和拉丁单词数（一个汉字约等于 1.5 个英文单词的信息量），反引号里的代码、链接、邮箱不计；中文为主译成英文，否则译成中文。固定方向（中→英、英→中）仍按用户的选择。实现在 `src-tauri/src/translation/direction.rs`。
