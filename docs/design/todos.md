## 深色列表

- 待办与岛屿共用深色背景，移除纸张底色、横线、折痕和投影；取消左侧“回到今天 / 保存 / 历史”三个按钮，继续自动保存。（2026-11-10，用户确认）
- 列表直接铺在岛内，使用细分隔线、浅色文字与透明图标操作；输入和编辑区域保留低对比底色，完成项弱化并加删除线。（Agent 推断）
- 今日笔记和已安排列表使用同一套深色文字、输入、滚动条和焦点样式；原有归档数据及保存格式继续兼容。（Agent 推断）

## 待办日期

- 待办输入框右侧有日期按钮（默认"今天" / "Today"），点开系统日历选日期；选今天以后的日子时按钮变紫色，回车后待办进入"已安排"而不出现在今日列表，日期随之复位为今天。（上游 issue #30，用户确认）
- 有已安排待办时，标题旁出现带数量的日历按钮，进入"已安排"（Upcoming）页按日期分组查看、删除；该页使用归档页的固定高度，不显示输入框。（Agent 推断）
- 到期待办（日期不晚于今天，包括应用关闭期间错过的）在列表代表今天时并入顶部；列表还停在以前某天时先等跨天流程归档旧列表，再并入，避免被归档到旧日期。（Agent 推断）

## 尺寸

- 待办页更紧凑（2026-11-11，用户要求"todo页面可以缩小一点"）：一行待办 32px（原 38px），行距 6px；勾选框 20px，开始 / 删除 / 拖动按钮 22px 高；输入框 32px（原 36px）；本子上下内边距 12px（原 18 / 16），页签行 22px，块间距 8px。两行时展开岛高 258px（原 306px），每多一行加 38px（原 46px），所以默认 490px 的最大面板高度下能放 8 行才开始滚动（原 6 行）。笔记页给一行的余量，296px；归档、复盘、已安排的固定高度不变。高度常量在 `windows/island/layout.ts`，和 `TodoNotebook.css`、`TodoListItem.css` 保持一致。（Agent 推断：具体数值）

- 待办里的圆角比岛内其他卡片小一级（用户要求 2026-11-11：原来太圆）：深色列表不再绘制独立的面板背景；待办行、输入框和每日笔记用 `--corner-xs`，行内的勾选框、拖动柄和标题输入用 `--corner-xs`，日期按钮用 `--corner-sm`。
- 点待办标题原地编辑（2026-11-11 用户要求：折成几行的待办点开编辑只剩一行）：编辑框是随内容长高的多行框，保持原来的行数、整段文字都看得见，文字位置和编辑前一致；Enter 保存，Shift+Enter 不换行（标题仍是一段，粘贴进来的换行变成空格），中文输入法选词的 Enter 不保存，Esc 取消，离开编辑框保存。实现在 `TodoTitleEditor.tsx`，回归页 `tests/regression/todo-edit.html`。

## 历史与日历

- 待办页标题行的笔记按钮右边是"历史"按钮，再右边是"日历"按钮（2026-11-11 用户要求）。三个按钮的规则一样：点开对应页面，按钮高亮并换成列表图标，再点一下回到今天的待办。两页都使用归档页的固定高度（352px），内容在里面滚动。
- 历史页按日期分组列出以前每天的待办，最近的一天在最前，日期旁写"完成 x/y"；完成项打勾、变灰并加删除线。数据就是跨天时写入的归档（`focusd-island-archives`），只读，不新增存储。没完成的待办后面有"加到今天"按钮，加到今天列表顶部；今天已有同名未完成待办时按钮变成勾、不可再点，避免重复。（Agent 推断：恢复按钮的样子与去重规则）
- 日历页左边是固定六周的月历，右边是选中那天的待办。今天用强调色描边加粗；有待办的日子底部有圆点：还有没完成的是强调色，全部完成是灰色，有已安排的是紫色（与已安排待办同色）。默认选中今天；左右箭头切换月份，离开本月或选了别的日子时出现"今天"按钮。周一开头（中文）或周日开头（英文）。（Agent 推断：配色与周首日）
- 点今天或以后的日子，右边底部有输入框，回车后：今天的进今天列表，以后的走"已安排"（与输入框旁的日期按钮同一套逻辑），已安排的待办可以在这里删除。以前的日子只读。日子是在月历上点选的，所以这里不再放 `TodoDatePicker`。（Agent 推断）
