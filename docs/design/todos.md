# 待办

全局方向见 [DESIGN.md](../../DESIGN.md)。

## 深色列表

- 待办与岛屿共用深色背景，移除纸张底色、横线、折痕和投影；取消左侧“回到今天 / 保存 / 历史”三个按钮，继续自动保存。（2026-11-10，用户确认）
- 列表直接铺在岛内，使用细分隔线、浅色文字与透明图标操作；输入和编辑区域保留低对比底色，完成项弱化并加删除线。（Agent 推断）
- 今日笔记和已安排列表使用同一套深色文字、输入、滚动条和焦点样式；原有归档数据及保存格式继续兼容。（Agent 推断）

## 待办日期

- 待办输入框右侧有日期按钮（默认"今天" / "Today"），点开系统日历选日期；选今天以后的日子时按钮变紫色，回车后待办进入"已安排"而不出现在今日列表，日期随之复位为今天。（上游 issue #30，用户确认）
- 有已安排待办时，标题旁出现带数量的日历按钮，进入"已安排"（Upcoming）页按日期分组查看、删除；该页使用归档页的固定高度，不显示输入框。（Agent 推断）
- 到期待办（日期不晚于今天，包括应用关闭期间错过的）在列表代表今天时并入顶部；列表还停在以前某天时先等跨天流程归档旧列表，再并入，避免被归档到旧日期。（Agent 推断）

## 文案

- 中文界面下待办页上的文字也是中文（"待办 / 笔记"标签、"2 项未完成"、"添加 2026-11-10 的待办"、"今天"等）。原来这一分区的中文字典照搬了英文，中文用户会看到一页中英混排。（2026-11-10，Agent 推断）

## 尺寸

- 待办页更紧凑（2026-11-11，用户要求"todo页面可以缩小一点"）：一行待办 32px（原 38px），行距 6px；勾选框 20px，开始 / 删除 / 拖动按钮 22px 高；输入框 32px（原 36px）；本子上下内边距 12px（原 18 / 16），页签行 22px，块间距 8px。两行时展开岛高 258px（原 306px），每多一行加 38px（原 46px），所以默认 490px 的最大面板高度下能放 8 行才开始滚动（原 6 行）。笔记页给一行的余量，296px；归档、复盘、已安排的固定高度不变。高度常量在 `windows/island/layout.ts`，和 `TodoNotebook.css`、`TodoListItem.css` 保持一致。（Agent 推断：具体数值）

- 待办里的圆角比岛内其他卡片小一级（用户要求 2026-11-11：原来太圆）：深色列表不再绘制独立的面板背景；待办行、输入框和每日笔记用 `--corner-xs`，行内的勾选框、拖动柄和标题输入用 `--corner-xs`，日期按钮用 `--corner-sm`。
- 点待办标题原地编辑（2026-11-11 用户要求：折成几行的待办点开编辑只剩一行）：编辑框是随内容长高的多行框，保持原来的行数、整段文字都看得见，文字位置和编辑前一致；Enter 保存，Shift+Enter 不换行（标题仍是一段，粘贴进来的换行变成空格），中文输入法选词的 Enter 不保存，Esc 取消，离开编辑框保存。实现在 `TodoTitleEditor.tsx`，回归页 `tests/regression/todo-edit.html`。

## 四个视图：待办 / 笔记 / 历史 / 日历

- 待办页左上角是一个分段控件，四段依次是待办 / 笔记 / 历史 / 日历，替换原来分散的笔记、历史、日历按钮（2026-11-12 用户要求重新设计切换方式，方案由上层会话确定）。每段一个图标；只有当前一段同时显示文字，其余只有图标（带 `aria-label`），岛缩小时也不挤。底下的高亮块随选中段滑动，用一个短促的回弹，开启"减少动态效果"时直接到位（`base.css` 统一去掉过渡）。控件在每个视图都在，所以任何视图都能一步回到待办。
- 右上角只放当前视图用得上的东西：待办页是已安排数量按钮和"N 项未完成"，已安排页是"N 项已安排"，笔记、历史、日历页不放。日期按钮仍在待办页的输入框旁。已安排页、归档回顾分别算在"待办"和"历史"段下。
- 最后看的视图只在本次运行中记住（React 状态），不写入存储。
- 实现在 `TodoViewSwitch.tsx`、`TodoNotebookTopline.tsx`。

## 历史

- 按天分组，最新的在前，今天的列表也在最上面。每天的标题读作"今天 / 昨天 / 11月9日 周一"（英文 Today / Yesterday / Mon, Nov 9），右边是"3/5 已完成"和一条细进度条。（2026-11-12 用户要求：原来的历史不好读）
- 下面是当天的待办：完成的打勾、文字变灰加删除线；没完成的正常文字，悬停时右边出现淡淡的"移到今天"。移过之后（今天已有同名未完成待办）按钮常驻为"已在今天的列表里"并不可点，避免重复。今天的待办没有这个按钮。
- 最近 7 天（含今天）展开，更早的日子收在一行"更早 · N 天"后面，点开再看。没有任何记录时显示一个图标和"还没有历史记录 / 每天结束时，当天的待办会自动收进这里"。
- 不显示表格、ID 或时间戳；行高宽松，行没有底框，悬停时淡淡提亮，与待办列表同一块深色背景。数据仍是跨天归档（`focusd-island-archives`）加今天的列表，只读，没有新增存储。
- 历史页沿用归档页的固定高度（352px），只有列表滚动。

## 日历

- 月历一周从周一开始，只画这个月需要的周数（4–6 行）。日期数字 13px；今天是实心的强调色圆，选中的日子是一圈描边，两者重合时在实心圆外再加一圈。（2026-11-12 用户要求改进日历）
- 有待办的日子下面最多三个小圆点：没完成的和已安排的用强调色，完成的用灰色，没完成的排在前面。
- 顶部是"‹ 2026年11月 ›"，右边一个"今天"按钮跳回本月并选中今天（已在今天时变灰）。
- 月历下面是选中那天的列表，复用历史的行样式（`TodoDayRow`）；已安排的待办用紫色、虚线框，悬停出现删除按钮。今天和以后的日子在日期标题右边有一个"添加待办"输入框，回车后今天的进今天列表，以后的走"已安排"。以前的日子只读。日子在月历上点选，所以不放 `TodoDatePicker`。
- 日历页有自己的高度 490px（不超过面板高度上限，`layout.ts` 的 `TODO_CALENDAR_EXPANDED_ISLAND_HEIGHT`）：六周的月份下方列表仍有约两行，只有列表滚动。尺寸滑块整体缩放岛，所以比例在最小档也一样。
- 逻辑在 `features/todos/history.ts`、`calendar.ts`（单测 `tests/unit/todo-history-calendar.test.mjs`），组件 `TodoHistoryList.tsx`、`TodoCalendar.tsx`、`TodoDayRow.tsx`，回归页 `tests/regression/todo-history-calendar.html`。
