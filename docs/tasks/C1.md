多显示器：每个屏幕一个岛，或岛跟着鼠标所在的屏幕

**备注**：Notchify、Isle Notch、WinIsland 都有

**实现**：只有一个岛，设置「位置 → 显示在」：主显示器（默认）/ 鼠标所在的显示器 / 前台窗口所在的显示器。`src-tauri/src/island/follow.rs` 每 300 毫秒看一次目标在哪块屏幕，连续两次在另一块屏幕上、岛屿收起且没在拖动时，移到那块屏幕顶部中间，并发 `island-position-cleared` 让主窗口清掉拖动保存的位置。前台是岛屿自己时不算。**没有在真实的多显示器上测过**（本机只有一块屏幕）。「每个屏幕一个岛」没有做。
