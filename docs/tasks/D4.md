对比上游 0.2.15～0.2.20，列出值得移植的修复

**备注**：2026-11-07 用户决定以后再做。上游 `v0.2.14..upstream/main` 共 19 个提交，除发版、文档和我们自己的重构 #45 外值得看的 8 个：`c88af44` 新用户默认经典外观、`9f710f2` 启动时下载更新并在待办提示（+518 行，可能和我们的更新提醒重复）、`3880b00` 恢复重构前的岛外观、`0ac0f13` 离开顶边的收起岛做成对称胶囊、`3ba334c` 设置点恢复灰色、`daeb396` / `b52b13e` 暂停又重开液态玻璃（先查暂停原因）、`7a7f38e` 去掉设置的重置按钮（产品取舍，要问用户）

## 结论（2026-11-08）

上游 `v0.2.14..upstream/main`（到 v0.2.20，`b52b13e`）没有一个提交在我们的 main 里，逐个对照我们现在的代码：

| 上游提交 | 内容 | 结论 |
|---|---|---|
| `c88af44` | 新用户默认经典外观 | **已有**：`settingsDefaults.ts` 的 `appearanceMode` 就是 `classic` |
| `daeb396` / `b52b13e` | v0.2.18 暂停液态玻璃，v0.2.20 又打开 | **不移植**：两个合起来等于没改；我们从没暂停过，代码里没有 `LIQUID_GLASS_ENABLED` |
| `3880b00` | 去掉贴顶圆角（`top_edge.rs`），恢复重构前外观 | **不移植**：贴顶圆角是我们保留并在用的功能（外观 → 圆角 → 贴顶圆角） |
| `7a7f38e` | 去掉设置窗口的重置按钮 | **不移植**：我们的「重置所有设置」在关于页，点了要再确认，是有意保留的 |
| `3ba334c` | 岛顶部的设置按钮从齿轮换回灰色圆点 | **产品取舍，要用户定**：我们用齿轮图标，`docs/design/island.md` 的颜色约定也按齿轮写 |
| `0ac0f13` | 离开顶边的收起岛做成对称胶囊（上下圆角都是高度的一半） | **值得考虑**：我们离开顶边时上角 14、下角按圆角设置，上下不对称；改动小（`state.rs` 的 `top_corner_radius`、命中区域、CSS），但会改变外观，要用户看过再定 |
| `9f710f2` | 启动后静默下载更新，用系统待办提示 | **不整体移植**：我们已有后台检查（启动 20 秒后、每 6 小时）、跳过版本、更新通道和「有新版本」徽标；用待办提示和我们的做法冲突。可以单独考虑「检查到后先静默下载，点更新时直接安装」 |

剩下的是发版、文档和上游自己的重构 #45（我们已以自己的方式完成）。
