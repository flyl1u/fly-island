# 剪贴板容量评估（2026-11-13）

- 容量扩到 500，默认仍为 30；不改变 `clipboard-history.json` 的结构和缩略图字段，兼容现有存档。
- 原图不会进入 JSON。缩略图最长边为 128px，PNG 再编码为 base64；500 张高噪声的 128×128 不透明图片，在回归页样本中合计约 37,903,421 字节（36.15 MiB，含条目字段）。普通截图压缩后通常小很多，不能用纯色样本代替压力场景。
- 每次采集、复制重排、收藏、备注、删除都会重写历史 JSON。容量增加会放大序列化、克隆、IPC 和写盘成本，分批挂载只减少页面布局和图片解码，不减少这些成本。采集及写盘在原生后台服务进行；本次按需求保留已有持久化格式，没有引入新缓存或迁移。
- 回归页 `clipboard-history.html` 使用 500 张含高噪声缩略图的条目，检查初始仅挂载 20 行、接近底部追加 20 行、搜索能够找到第 500 条。Ego 浏览器本机一次首批挂载为 64.8ms；这是开发模式的观察值，不代表所有设备或真实 WebView 的耗时。
- 在真实界面验收时仍应观察 500 张不同截图下的首次快照传输和连续复制。若这部分成为瓶颈，后续应单独设计缩略图按需读取及增量持久化，而不以增加 DOM 批次掩盖写盘成本。
