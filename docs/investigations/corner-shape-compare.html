圆角对比

对比四种圆角：现在的普通圆角、苹果连续曲率圆角（基准 SVG，用 Figma 的平滑构造画，和 iOS 逆向出的曲线相差不到 0.008r）、CSS squircle（同样半径，直接替换的写法）、CSS 候选（superellipse(K) 配放大后的半径，按苹果曲线拟合）。CSS 形状都由浏览器自己渲染，用的就是岛屿 WebView2 的同款内核。

这个浏览器不支持 corner-shape，下面的 CSS 形状会退回成普通圆角。请用 Edge 或 Chrome 139 以上版本打开。

1. 放大 8 倍看一个角

浅色块是浏览器实际渲染出的 CSS 形状，橙线是苹果曲线。两者贴得越紧越接近苹果。下方数字是两条曲线之间的最大距离，按 1 倍屏的像素算。

2. 曲率：真正的差别在这里

横轴是沿边线走过的距离（单位 r，0 是普通圆角开始弯的位置），纵轴是曲率 × r。普通圆角在接缝处曲率从 0 直接跳到 1，这个突变就是"硬"的来源。苹果曲线从直边开始就慢慢弯，曲率从 0 逐渐升高，进入中间圆弧前略有冲高。superellipse（K>1）在接缝处曲率也是 0，但加得很陡。
