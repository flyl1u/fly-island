## 确认的问题

### 1. [P1] #141 分片保存失败会破坏原有账号凭据

位置：[relay_accounts.rs:164](https://github.com/flyl1u/fly-island/blob/96340326f79bc3e2e2e724d3b913cf4fba5f4c1c/src-tauri/src/agent_status/relay_accounts.rs#L164)。

`store()` 直接重写 `chunk-0`、`chunk-1` 等原有条目，最后才更新 index。后续分片写失败时，index 虽然没变，旧分片已经被部分替换；缩减分片时也会先删除旧分片。读取结果可能无法解析，也可能成为仍能解析的混合配置，静默改变账号和令牌。

用 PR 原始 `store()` / `load()` 函数及内存凭据存储注入第二次写入失败，已复现“保存返回失败，但旧配置已经改变”。应写入新一代分片，以 index 切换作为唯一提交点，成功后清理旧代；同时串行化保存、删除和令牌刷新，避免读改写互相覆盖。

### 2. [P1] #141 Sub2API 检查成功后可能保存已经失效的令牌

位置：[RelayAccountSettingsRow.tsx:83](https://github.com/flyl1u/fly-island/blob/96340326f79bc3e2e2e724d3b913cf4fba5f4c1c/src/features/agent-status/RelayAccountSettingsRow.tsx#L83)、[relay_usage.rs:294](https://github.com/flyl1u/fly-island/blob/96340326f79bc3e2e2e724d3b913cf4fba5f4c1c/src-tauri/src/agent_status/relay_usage.rs#L294)。

新增账号的 access token 已过期而 refresh token 仍有效时，检查会刷新令牌并用新 access token 成功查询。但新账号尚无已保存的 id，`rotate_tokens()` 找不到账号就返回成功，刷新后的令牌没有保存或返回给界面。界面紧接着保存的仍是原始 `input`。对会轮换 refresh token 的服务，下一次查询就同时拿着过期 access token 和已消费的 refresh token 失败。编辑时显式输入旧令牌也可能覆盖刚刷新的值。

用 PR 原始 `fetch_sub2api()` 和一次性刷新令牌的模拟服务，已复现“首次检查成功，保存原始输入后下一次查询失败”。应让检查和保存共享刷新后的账号对象，最好合并成一个原生命令事务。

### 3. [P2] #141 编辑账号时丢失 New API 用户 ID

位置：[RelayAccountSettingsRow.tsx:18](https://github.com/flyl1u/fly-island/blob/96340326f79bc3e2e2e724d3b913cf4fba5f4c1c/src/features/agent-status/RelayAccountSettingsRow.tsx#L18)、[relay_accounts.rs:66](https://github.com/flyl1u/fly-island/blob/96340326f79bc3e2e2e724d3b913cf4fba5f4c1c/src-tauri/src/agent_status/relay_accounts.rs#L66)。

保存对象含 `user_id`，但 `RelayAccountView` 不返回它，编辑用的 `draft()` 也不回填。用户只改名称后点“保存并检查”，请求不再带原先的 `New-Api-User`。要求这个头的站点会拒绝检查；若站点允许，后续保存又会清空已有用户 ID。用户 ID 不是密钥，应随 view 返回并回填，或在未修改时保留原值。

### 4. [P2] #98 所有正常的账号地区响应都会回退到中国区

位置：[applemusic.rs:133](https://github.com/flyl1u/fly-island/blob/458086df840aff70897ff2cbd564090c51737a2a/src-tauri/src/lyrics/applemusic.rs#L133)。

代码读取 `data[0].attributes.storefront`，但 Apple 返回地区码的位置是 `data[0].id`，`attributes` 中只有语言等属性。正常的美国、日本等地区响应因此也会进入 `cn / zh-Hans-CN` 回退，接着在错误的曲库中搜索和取歌词，可能找不到账号所属地区的歌曲或歌词。

根据 [Apple 官方 Get a User’s Storefront 示例](https://developer.apple.com/documentation/applemusicapi/get-a-user%27s-storefront)，用美国地区 fixture 执行 PR 原始 `storefront()`，确认实际得到 `cn / zh-Hans-CN`。应从资源对象的 `id` 读地区，继续从 `attributes.defaultLanguageTag` 读语言，并覆盖多个地区的响应测试。

### 5. [P2] #128 将独立截图功能的设置放进插件页

位置：[catalog.ts:27](https://github.com/flyl1u/fly-island/blob/2b196e358404a0fca7240049edd72bef1665d720/src/features/plugins/native/catalog.ts#L27)、[PluginsSettingsPage.tsx:30](https://github.com/flyl1u/fly-island/blob/2b196e358404a0fca7240049edd72bef1665d720/src/windows/settings/PluginsSettingsPage.tsx#L30)。

市场条目声明 `settings: { category: "plugins" }`，插件页又通过截图 id 的专门分支进入完整设置面板。现行规则要求：插件页只保留安装卡片和打开设置入口，独立功能的设置放到侧栏“功能”组末尾的独立栏目，由目录声明驱动。应声明截图自己的独立 category，并接入通用设置导航，移除插件页里的截图专门分支。规范见 [设置归类](../design/settings.md#插件设置归类规范长期) 与 [插件开发规范](../plugins/README.md)。

## #143 实际做了什么

新增可选内置插件“居中时钟”。安装后，折叠小岛可以把时间作为中间的主内容显示，而不是只在一排状态位里显示时钟。支持 12/24 小时、秒、日期、星期、日期格式和时间/日期顺序，并提供单独设置页。

默认优先级是 Agent → 歌词 → 已开始的待办 → 时钟；计时器和通知等仍有自己的覆盖规则。没有这些活动时显示时钟，普通未开始待办的计数会让位给时钟。优先级也可以由用户调整，所以并不是无条件只在空闲时显示。启用居中时钟后，原时间天气插件的时间位隐藏，天气仍可保留。

实现主要在 `src/features/centered-clock/`，只新增本地偏好 key `fly-island-centered-clock`，复用安装状态与折叠优先级；没有新增原生命令、网络请求或原生后台服务。
