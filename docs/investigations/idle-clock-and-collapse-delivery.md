# 折叠提醒、悬停退出与空闲时钟交付记录

## 范围与基线

基于 flyl1u/fly-island 的 `77db7401406fa6f26a5e6384cec44a30375831f4`（v3.2.1）修改。用户已批准实施，并要求时间日期格式可以在设置里选择。

三态命名：折叠＝完整单行小岛；展开＝功能面板；贴边＝露边、细线或隐藏热区。继续使用项目已有的 `mode` 与 `isTucked`，不重写窗口模型、不增加依赖。

## 已实现行为

1. 贴边时，已开启来源的消息、Agent 状态/审批和待办到时提醒唤出完整折叠摘要；点击摘要进入对应页面。通知不抢占已展开的页面。普通消息沿用来源去重及节流，内部提醒保留最新有效摘要。
2. 沿用原生鼠标悬停事件。悬停展开后默认移出 250ms 折叠，快速返回取消；非空可编辑草稿、输入法组合及按住拖动受到保护。折叠后从头等待闲置贴边延时，悬停在折叠岛上也暂停闲置贴边。
3. 消息唤出不再复用旧 peek 的立即回收状态；摘要结束后重新等待闲置计时。用户手动贴边可取消内部摘要，不被该摘要立即唤回。Agent 审批结束不关闭用户随后手动打开的面板。
4. 折叠空闲时显示本地时间日期；消息、Agent、进行中待办/计时和歌词优先。未开始的待办不阻挡空闲时钟；关闭时钟后恢复原来的折叠文字选择。

遵守已有的来源开关、贴边消息唤出开关、Agent 前台过滤、游戏勿扰和托盘隐藏行为。尚未重新定位到用户机器“只变宽、不露出”的原生坐标现场，因此不能将浏览器回归等同于真实桌面复现验证。

## 使用设置

进入 **设置 → 外观 → 空闲时间与日期**：

- 总开关，默认开启。
- 显示内容：时间和日期、仅时间、仅日期。
- 时间：24 小时制或 12 小时制，可显示秒。
- 日期：本地月日、`YYYY-MM-DD`、`YYYY/MM/DD`、`DD/MM/YYYY`、`MM/DD/YYYY`、本地完整日期、自定义。
- 星期：隐藏、简短、完整；仅时间时不追加星期。
- 顺序：时间在前或日期在前。
- 自定义日期支持 `YYYY`、`YY`、`MM/M`、`DD/D`、`ddd/dddd`，其余文字原样显示，最多 80 字符。例如 `YYYY年MM月DD日 dddd`。格式已包含星期时不会重复追加。

沿用 `focusd-island-settings` 保存；缺失或无效字段归一化，恢复默认外观一并重置。新增设置文案有中英文。设置组提供实时预览。

时钟只有叶子组件刷新，默认按分钟、显示秒时按秒对齐更新；展开、贴边或被消息覆盖时停止隐藏时钟的定时器，焦点/可见性恢复后校时。折叠自动宽度按格式预留，长自定义格式省略，不按秒调整原生窗口尺寸。
