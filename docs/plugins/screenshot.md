# 截图插件

基于社区 PR [#128](https://github.com/flyl1u/fly-island/pull/128) 的截图、标注、保存、OCR、贴图能力，由维护者适配现版原生插件目录与设置结构。

## 使用

- 在「设置 → 插件」安装「截图」，卡片开关只控制截图插件。安装后点击「设置」修改全局快捷键（默认 Alt+A）、放大镜、窗口自动框选与操作提示。停用或卸载保留偏好，关闭插件窗口并释放资源。
- 长截图和录屏在同一设置页显示“开发中”，暂不可开启。配置取舍、资源生命周期和预留接口见 [开发规划](screenshot-roadmap.md)。

- `Alt+A` 打开截图覆盖层，在光标所在显示器框选；工具栏支持标注、识别、翻译、贴图、保存和复制。
- `Esc` 结束截图；文字输入时先退出编辑；保存弹窗打开时先关闭弹窗。输入文件名、编辑 OCR 内容时不会触发标注单键快捷键。
- `Ctrl+Q` 或工具栏「翻译」打开独立图文结果窗口。贴图可通过同一快捷键或右键菜单打开翻译。
- 翻译窗口提供「原图与中英对照」「仅中英对照」「仅原图」三种布局。每段原文下方显示译文，按内容自然换行和增长；原图单独显示，文字不覆盖图片。可以编辑原文、调整中英翻译方向，再点击翻译重试；可复制译文或原文/译文对照。图片区 Ctrl+滚轮缩放，文字保持正常字号。
- 贴图支持拖动、文字选择、复制、保存、滚轮调整窗口大小以及原生右键菜单。关闭（含系统关闭）会回收本次贴图的临时文件。
- 保存支持 PNG/JPG；尺寸调整同时适用于这两种格式及系统保存入口。最终由系统对话框确认路径及覆盖行为。
- 「识别文字 · 图文对照」打开独立窗口，左侧原图，右侧依阅读顺序一行一行显示可编辑文字。同一图像行的片段合为普通文字，不保留列、缩进、原字号等格式；长句自动换行，编辑、调整字号或窗口宽度时自动增高，后续文字顺序下移。点击原图行可定位右侧文字；可隐藏原图并复制纯文本。
- 保存预览与尺寸区域支持滚轮按比例缩放，另有百分比滑块；预览大小随导出尺寸同步变化。「桌面贴图」用于悬浮参考，工具按钮提供可见悬停提示；马赛克仅提供颗粒大小。
- 重复截图保持同屏全屏几何不变，退出时先隐藏覆盖层，避免在关闭前重新绘制整屏遮罩。
- 快速退出并再次触发时，关闭中的一次触发会排队到恢复窗口完成后执行；原生窗口与 WebView 控制器均在 UI 线程获得焦点。底图提交后直接激活，不再等待隐藏窗口的动画帧、计时器或字体枚举。
- 识别结果默认统一 16px，可调阅读字号，原图缩放不改变文字大小。截图标注的文字编辑与图像导出均开启字体合成，微软雅黑等无原生斜体的字体也能显示斜体。
- DeepSeek 翻译兼容已填写的 `DeepSeek-V4.1-Flash` 展示名称，发给官方接口时转换为 `deepseek-flash`；自定义网关模型名保持原样。接口失败显示服务端原因与实际模型，密钥不进入诊断输出。

## 翻译与隐私

OCR 默认使用 Windows 离线识别。在独立截图设置中点击“下载模型”后才下载约 30 MB 的增强识别资源，完成后离线使用；固定资源来源、哈希及许可证见 [OCR 资源](screenshot-ocr-resources.md)。下载失败不会影响系统识别。点击翻译后，识别出的文字通过 Fly Island 现有 `translate_text` 命令发送给设置中选择的服务；共用服务商、模型、自定义地址、凭据及翻译方向，没有第二套密钥存储。每次最多两个并行请求，逐行显示结果和错误。关闭结果窗口停止尚未发送的排队请求，已经发出的请求可能仍在服务端完成。

图像写入应用数据目录的 `pinned-images/pin-<时间戳>.png`，仅供本机图像窗口读取；关闭窗口时删除。异常退出的残留文件在下次启动时清理。保存图片写到用户在对话框中选择的 PNG/JPG 路径。没有新增 localStorage key。

## 与 PixPin 的对应和边界

参考 [PixPin 官方截图翻译说明](https://pixpin.cn/blog/articles/screenshot-translation-guide/) 的图文对照与显示模式。按用户反馈，结果采用顺序文字和逐段双语对照。窗口控件沿用 Fly Island 的中英双语和主题变量。

OCR 坐标仅用于阅读顺序和原图定位，识别与译文均采用普通流式文字，不生成覆盖译图。OCR 质量受图片字体、清晰度及内置模型语言覆盖影响。翻译方向沿用主项目现有的自动、中译英和英译中能力，没有另外增加多语种接口。截图一次覆盖一块显示器，不支持跨屏拼接；长截图、录屏也不属于本次合并。

## 接入点

- `src/main.tsx`：`screenshot`、`pinned-image`、`screenshot-translation` 窗口入口。
- `src/features/screenshot/`：类型化 IPC、标注算法、显示器坐标换算和有界翻译队列。
- `src/windows/screenshot/`、`pinned-image/`、`screenshot-translation/`：三个窗口的组合和交互。
- `src/features/translation/index.ts`：向结果窗口公开既有翻译服务和设置读取。
- `src-tauri/src/lib.rs`：命令模块、截图初始化、保存对话框插件、贴图销毁清理。
- `src-tauri/src/screenshot/` 与 `win32/`：全分辨率抓屏、OCR、快捷键、窗口管理及原生菜单。
- `Cargo.toml`、锁文件、资源表与 capability：OCR、资产协议、保存对话框、贴图窗口权限。

插件默认未安装，在设置 → 插件中显式安装。长截图与录屏只是禁用的预留入口，不表示已经可用。
