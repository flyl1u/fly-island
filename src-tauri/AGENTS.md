# 原生模块边界

在根目录规则的基础上遵守以下约定。

- `src/lib.rs` 负责模块声明、插件、初始化和命令注册。
- `island/` 管理岛屿窗口、几何、贴边、玻璃效果和鼠标穿透；`tray.rs` 管理托盘；`settings_window.rs` 管理设置窗口。
- `system/` 管理开机自启、更新配置和 Markdown 导出；其他服务各在自己的领域目录。
- 新增和搬迁命令时保持名称、参数、返回结构及事件名称兼容，同步前端 `api.ts`。
- 窗口创建不能直接在菜单回调中进行。设置入口通过异步/阻塞工作线程调用，并串行创建以避免重复窗口。
- 新增 Win32 底层能力优先封装在 `win32/`，用 RAII 管理句柄；不顺便搬迁或改写无关的 COM/窗口代码。
- 服务状态保持在所属模块，线程有清晰生命周期。错误继续返回可读的 `Result<_, String>`。
- 生产 Rust 文件一般上限 800 行；大测试集放独立 `tests.rs`。
- 修改原生代码后运行 `cargo test --manifest-path src-tauri/Cargo.toml` 与 `pnpm tauri build --no-bundle`；真实窗口、通知和快捷键行为仍需桌面验收。
- 成功更新最终 release 产物后按根目录规则同步桌面快捷方式。
